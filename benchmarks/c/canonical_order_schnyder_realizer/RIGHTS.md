# Rights and provenance

The source is the algorithm description in “Canonical Orders and Schnyder
Realizers,” *Encyclopedia of Algorithms*, Chapter 650,
https://doi.org/10.1007/978-1-4939-2864-4_650, specifically “Schnyder
Realizer,” “Equivalency of Canonical Orders and Schnyder Realizers,” and
Lemma 3. The benchmark uses that source for the mathematical procedure and
root/color roles only. The implementation, ABI profile, references, and
fixtures are clean-room work; no book code or prose has been copied.

The supplied input is a bounded rotation system plus a canonical order. The
output is the three parent assignments for interior vertices, with outer
roots omitted. This package does not include source text, figures, or other
copyrighted chapter material.
