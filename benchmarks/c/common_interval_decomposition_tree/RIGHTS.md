# Rights and attribution

The operation and terminology follow the Library Checker task “Common Interval
Decomposition Tree,” maintained by the Library Checker contributors:

- https://github.com/yosupo06/library-checker-problems/blob/master/tree/common_interval_decomposition_tree/task.md

The relevant decomposition background is Binh-Minh Bui Xuan, Michel Habib, and
Christophe Paul, “Revisiting T. Uno and M. Yagiura’s Algorithm,” ISAAC 2005,
LNCS 3827, pp. 146–155, DOI 10.1007/11602613_16:

- https://doi.org/10.1007/11602613_16

All benchmark ports and oracle code in this package are original clean-room
implementations of the published definitions. No external implementation or
test-case source is copied. The task statement and paper remain subject to their
respective publishers' and project owners' terms.
