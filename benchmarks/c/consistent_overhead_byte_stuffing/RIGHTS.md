# Rights and provenance

The algorithm reference is Cheshire and Baker, “Consistent Overhead Byte
Stuffing,” *IEEE/ACM Transactions on Networking* 7(2), 1999,
[DOI 10.1109/90.769765](https://doi.org/10.1109/90.769765). The benchmark uses
the basic COBS code-block rules from the paper's Section III and excludes the
separate COBS/ZPE variant. The [pinned RosettaCodeData popular-title index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks)
is cited only as discovery provenance.

No RosettaCode task wording, implementation, published source code, tests, or
examples were copied. The code ports and both references were written for this
bounded profile. Fixtures are authored byte patterns with hand-pinned COBS
results. The original paper remains the authoritative algorithm source.
