# Rights and provenance

This package contains clean-room, bounded implementations of the max-min
Euclidean length triangulation algorithm for convex polygons. The method is
described by Shiyan Hu in [“A linear time algorithm for max-min length
triangulation of a convex polygon”](https://doi.org/10.1016/j.ipl.2006.09.014).
The matching objective also appears in Tiow-Seng Tan's Encyclopedia of
Algorithms entry, [“Optimal Triangulation”](https://doi.org/10.1007/978-1-4939-2864-4_715).

Only the published algorithmic ideas and mathematical problem semantics are
used. No third-party code or prose is copied into the ports or reference
implementations. The independent oracle enumerates the bounded family of
triangulations and was written specifically for this repository.
