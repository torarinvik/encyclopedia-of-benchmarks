# Rights and provenance

This package implements a bounded Cornacchia algorithm for the positive
solutions to `x²+2y²=p`, using the Euclidean-remainder characterization
described in the cited mathematical references.

The papers and manuals are used for algorithm descriptions and mathematical
ideas only. All ports, references, workload fixtures, and prose were written
independently; no published implementation or text was copied. The cited
publications and projects retain their own terms. Deutsch's open-access paper
is distributed under CC BY; it is not copied into this package.
