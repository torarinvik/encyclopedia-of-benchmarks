# Rights and reuse

The benchmark is an independent implementation of the algorithm described by
David Hood, *Caverphone Revisited*, Technical Paper CTP150804, University of
Otago (2004), and indexed by NIST's Dictionary of Algorithms and Data
Structures. The primary specification is linked at
<https://caversham.otago.ac.nz/files/working/ctp150804.pdf>.

The Caverphone 2.0 algorithm description is used as a reference; no source
code, examples, fixtures, tests, or prose have been copied. The benchmark
contract, implementation, references, workload, and documentation are
independently written for this repository.
