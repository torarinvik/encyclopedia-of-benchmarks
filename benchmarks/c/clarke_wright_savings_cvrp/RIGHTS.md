# Rights and provenance

The algorithm source is G. Clarke and J. W. Wright, “Scheduling of Vehicles
from a Central Depot to a Number of Delivery Points,” *Operations Research*
12(4), 568–581 (1964), [DOI 10.1287/opre.12.4.568](https://doi.org/10.1287/opre.12.4.568).

This package is a clean-room implementation of the published savings method.
It uses the algorithm description only and does not reproduce the article's
text, code, figures, or data. The bounded input format, strict-positive-saving
rule, tie ordering, route canonicalization, and byte serialization are local
benchmark contract choices.
