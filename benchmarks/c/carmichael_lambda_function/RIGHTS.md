# Rights and provenance

The algorithm source is Richard A. Wilson's Queen Mary University of London
cryptography course notes, Theorem 22
([PDF](https://webspace.maths.qmul.ac.uk/r.a.wilson/MAS335/cn7.pdf)), together
with the definition and initial value summarized by
[Wolfram MathWorld](https://mathworld.wolfram.com/CarmichaelFunction.html).
This package uses the published mathematical rules as algorithm ideas only.
It contains no copied source code, examples, prose, or test data; the bounded
contract, ports, oracles, workload, and documentation were independently
written.
