# Rights and provenance

The algorithm attribution is François, Jérôme, Abdelkader Lahmadi, Valentin
Giannini, Damien Cupif, Frédéric Beck, and Bertrand Wallrich, “Optimizing
Internet Scanning for Assessing Industrial Systems Exposure,” IWCMC 2016,
pp. 516–522, [DOI 10.1109/IWCMC.2016.7577111](https://doi.org/10.1109/IWCMC.2016.7577111).
The [NIST DADS entry](https://xlinux.nist.gov/dads/HTML/CupifGianniniTreeTraversal.html)
identifies that publication and provides pseudocode for the count-XOR leaf
order. The local benchmark pins that explicitly stated order, with a caller
key replacing a random key to make each call reproducible.

No license permitting reuse of the paper's text or the DADS page's prose was
identified. No published code, pseudocode, examples, fixtures, comments, or
prose were copied. The ten language ports and both references are independent
implementations of the described mathematical path order. This note makes no
claim about licensing of the cited article or DADS content.
