# Rights and provenance

The algorithm idea is based on Sabit Zahin's `cactus.cpp` in
[Algovault](https://github.com/sgtlaugh/algovault/blob/bc24742a9b7fba123be5fafca5a93a76bb7f8840/code_library/graphs/cactus.cpp),
an MIT-licensed repository. The repository's method description informed the
DFS cycle-ownership profile and the edge-cactus/vertex-cactus distinction.

All local code, references, contract text, fixtures, and oracle descriptions
were written independently. No upstream source code, tests, sample inputs,
comments, or prose were copied. The benchmark records the packed scalar
classification and does not reproduce the source API's cycle or cactus-tree
serialization.
