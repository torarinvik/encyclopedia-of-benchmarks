# Rights and provenance

This package is a clean-room implementation of the classical CYK context-free
recognition method. It uses the algorithmic ideas described in Younger’s 1967
paper and Kasami’s 1965 report, with the Archive of Formal Proofs entry as an
additional formal reference. It does not copy source code, prose, examples, or
fixtures from those works.

The benchmark ports, Python references, workload cases, and documentation are
originally authored for this repository. No third-party implementation code is
included. The historical algorithm descriptions are cited for provenance; no
copyright license is claimed over those sources.
