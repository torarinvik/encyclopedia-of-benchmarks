# CYK context-free recognition

This bounded clean-room profile recognizes whether a short token sequence is
generated by a supplied context-free grammar in Chomsky normal form. It
benchmarks the Cocke–Younger–Kasami (CYK) dynamic program; it does not transform
grammars into normal form or construct a parse tree.

## Contract

- ABI: `i64_array_scalar`, symbol `cyk_context_free_recognition`.
- Input: `[V,T,L,P,start,tokens..., (kind,lhs,x,y)*P]`.
- `V` is 1–4 nonterminals, `T` is an alphabet size of 1–2, `L` is a word length
  of 1–8, and `P` is 0–12 productions. All symbol IDs are zero-based.
- A production with `kind=0` means `lhs → terminal x` and requires `y=0`. A
  production with `kind=1` means `lhs → nonterminal x nonterminal y`. Epsilon
  and unit productions are invalid. Repeated production rows are accepted and
  have ordinary set-of-productions semantics.
- The frame must contain exactly `5 + L + 4P` signed 64-bit words. The maximum
  valid frame has 61 words; the parser cap is 62 words to make trailing input
  rejection explicit.
- Return `1` if the start symbol derives the entire word, `0` otherwise, and
  `-1` for a null or malformed frame.

The primary reference fills a triangular CYK chart in increasing span length.
The independent reference builds each nonterminal's bounded language by word
length and checks membership in the resulting set. Both use positive-length
productions, so no epsilon or unit closure is needed. See the
[workload](workload.json), [primary reference](primary_oracle.py),
[independent reference](independent_oracle.py), and
[static inventory](verify_workload.py).

## Bounds

For maximum word length `L=8`, at most 12 productions, and at most 4
nonterminals, the chart costs `O(P*L^3)` time and `O(V*L^2)` Boolean cells.
The output is Boolean, so every valid result is in `[0,1]`.

independent Kasami report. Only algorithmic ideas are used; every port and
