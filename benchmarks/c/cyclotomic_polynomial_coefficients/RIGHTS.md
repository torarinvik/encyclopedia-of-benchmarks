# Rights and provenance

This package re-expresses the cyclotomic-polynomial definitions and
algorithms described in the public mathematical references linked in
[`README.md`](README.md). The RosettaCodeData title index is used only as a
discovery index. No task code, implementation text, comments, tests, or
published output tables are copied; small fixture vectors are independently
derived from the definitions.

The Arnold–Monagan article and Encyclopedia of Mathematics entry remain under
their respective publishers' or site terms; this package asserts no license
over those works. The ten native ports, Python references, input/output
contract, and workload fixtures are new clean-room benchmark materials.
