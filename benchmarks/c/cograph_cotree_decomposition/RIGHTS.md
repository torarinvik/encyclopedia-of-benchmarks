# Rights and provenance

This package uses the mathematical description of cographs and cotrees from:

- D. G. Corneil, H. Lerchs, and L. Stewart Burlingham, “Complement Reducible
  Graphs,” *Discrete Applied Mathematics* 3(3), 163–174 (1981),
  <https://doi.org/10.1016/0166-218X(81)90013-5>.
- D. G. Corneil, Y. Perl, and L. K. Stewart, “A Linear Recognition Algorithm
  for Cographs,” *SIAM Journal on Computing* 14(4), 926–934 (1985),
  <https://doi.org/10.1137/0214065>.

The cited publications retain their respective publisher copyrights. This
package reuses no source code, prose, examples, or figures. The bounded
recursive profile, fixtures, clean-room references, and ten language ports
were written independently from the mathematical characterization. No source
license is being asserted for the papers.
