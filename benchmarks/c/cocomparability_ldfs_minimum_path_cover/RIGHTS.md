# Rights and provenance

This package is an independently written bounded implementation of the
LDFS+-then-RMN minimum path-cover method for cocomparability graphs. The
algorithmic description is attributed to Corneil, Dalton, and Habib,
“LDFS-Based Certifying Algorithm for the Minimum Path Cover Problem on
Cocomparability Graphs,” *SIAM Journal on Computing* 42(3), 792–807 (2013),
[DOI 10.1137/11083856X](https://doi.org/10.1137/11083856X). Its 2021
corrigendum [DOI 10.1137/20M1327835](https://doi.org/10.1137/20M1327835)
corrects proof errors without changing the algorithms. The precise LDFS+ and
RMN tie rules are cross-referenced to Mertzios and Corneil, “A Simple
Polynomial Algorithm for the Longest Path Problem on Cocomparability Graphs,”
[DOI 10.1137/100793529](https://doi.org/10.1137/100793529), §2, pp. 5–6.

The Encyclopedia of Algorithms Chapter 685 is the book crosswalk/context:
[DOI 10.1007/978-1-4939-2864-4_685](https://doi.org/10.1007/978-1-4939-2864-4_685).
No source code, examples, figures, or protected prose were copied. The
contract, workload, oracle implementations, and ten language ports are
clean-room work.
