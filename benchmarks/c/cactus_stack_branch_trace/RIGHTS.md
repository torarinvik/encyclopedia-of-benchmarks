# Rights and provenance

The algorithm provenance is NIST DADS's [cactus stack entry](https://xlinux.nist.gov/dads/HTML/cactusstack.html) and Hauck and Dent, “Burroughs' B6500/B7500 Stack Mechanism,” AFIPS Spring Joint Computer Conference (1968), [paper](https://people.eecs.berkeley.edu/~kubitron/cs252/handouts/papers/burroughs.pdf).

The sources are used for algorithm semantics and historical context. No source code, implementation text, examples, or test fixtures were copied. The workload and both references were written for this bounded benchmark profile. NIST DADS is a dictionary entry and does not state a license for the cited historical paper; no license is asserted for that paper.
