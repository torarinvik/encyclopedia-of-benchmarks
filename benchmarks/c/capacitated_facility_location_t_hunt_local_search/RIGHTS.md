This benchmark is based on Arya, Garg, Khandekar, Meyerson, Munagala, and
Pandit, “Local Search Heuristics for k-Median and Facility Location Problems,”
*SIAM Journal on Computing* 33(3), 544–562 (2004), DOI
[`10.1137/S0097539702416402`](https://doi.org/10.1137/S0097539702416402), and
Kamesh Munagala's “Local Search for K-medians and Facility Location,”
Encyclopedia of Algorithms entry 212, DOI
[`10.1007/978-1-4939-2864-4_212`](https://doi.org/10.1007/978-1-4939-2864-4_212).
The source publications' code licenses are not specified here. The ten ports,
references, and fixtures are clean-room implementations based on the published
algorithm descriptions. No source code, examples, or prose are copied. This
file records attribution and does not claim an additional license for the
source publications.
