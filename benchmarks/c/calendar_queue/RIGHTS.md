# Rights and provenance

Algorithm provenance: Randy Brown, “Calendar Queues: A Fast O(1) Priority
Queue Implementation for the Simulation Event Set Problem,” *Communications
of the ACM* 31(10), 1220–1227 (1988), [DOI
10.1145/63039.63045](https://doi.org/10.1145/63039.63045), Sections 2–4. The
NIST DADS [calendar queue entry](https://xlinux.nist.gov/dads/HTML/calendarQueue.html)
also cites Brown's article.

The ACM article is copyrighted; this package asserts no license for its
published source code. The ten ports and two reference models are clean-room
implementations of the mathematical data-structure behavior. No published
source code, comments, sample code, or fixture data are copied. Fixtures are
newly authored for the bounded integer-tick profile. The exact rational width
representation and insertion-order tie rule are documented profile choices.
