# Rights and provenance

The algorithm profile is based on the mathematical description of CORDIC in Jack E. Volder, “The CORDIC Trigonometric Computing Technique,” *IRE Transactions on Electronic Computers* EC-8(3), 330–334 (1959), DOI [10.1109/TEC.1959.5222693](https://doi.org/10.1109/TEC.1959.5222693). NIST DADS' [CORDIC entry](https://xlinux.nist.gov/dads/HTML/cordic.html) was used as a discovery index.

The paper is copyrighted. This package uses the algorithm idea and equations only. No source code, prose, figures, or published example traces were copied. The nanoradian constants, bounded ABI, fixtures, references, and all ten ports were prepared independently for this benchmark.
