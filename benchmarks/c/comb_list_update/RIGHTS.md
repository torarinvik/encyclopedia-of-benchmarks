# Rights and provenance

This package is an independently written bounded implementation of the Comb
list-update policy described by Shahin Kamali in “Online List Update,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_266. The chapter is
used only for algorithm attribution; no book code, prose, or figures were
copied. Supplied random tapes make traces reproducible and keep the source's
Bit/Timestamp mode probabilities explicit. These clean-room implementations
are subject to the repository terms.
