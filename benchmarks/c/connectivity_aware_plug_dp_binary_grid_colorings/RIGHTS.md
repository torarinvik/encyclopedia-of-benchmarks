# Rights and provenance

The benchmark is a clean-room implementation of the general connectivity-aware
frontier-DP method described by the OI Wiki
[Plug DP article](https://en.oi-wiki.org/dp/plug/). UVA 10572 “Black & White”
is cited only as a model/discovery reference. The benchmark contract narrows
that method to fully available rectangles of at most 16 cells and is defined
in this repository. No source code or problem text is included or copied.

All ten ports, both references, fixtures, and documentation in this package
were authored for this repository. Source attribution is mathematical
provenance only; this package does not redistribute article or judge content.
