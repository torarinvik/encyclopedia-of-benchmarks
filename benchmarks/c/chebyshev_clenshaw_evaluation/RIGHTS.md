# Rights and provenance

The source for the algorithm idea is NIST's Digital Library of Mathematical
Functions, [§3.11(ii), Chebyshev-Series Expansions](https://dlmf.nist.gov/3.11).
This package uses the published recurrence as mathematical guidance and
attribution. It does not reproduce DLMF prose, software, examples, or test
data. The finite-field contract, implementations, references, and workload
are independently authored for this repository.
