# Rights and clean-room implementation

The cited sources describe the Commentz–Walter algorithm and its shift-table
definitions. This package contains a new bounded implementation and newly
constructed fixtures. No upstream source code or benchmark instances were
copied. The references and static workload metadata are not part of the
benchmarked language ports.

Primary citation: Beate Commentz-Walter, “A string matching algorithm fast on
the average,” Proceedings of the 6th International Colloquium on Automata,
Languages and Programming, LNCS 71, 118–132, 1979. The NIST DADS entry and
algorithm-B exposition are linked in the README.
