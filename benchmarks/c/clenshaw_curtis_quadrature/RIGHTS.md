# Rights and provenance

The algorithm profile is derived from the mathematical description in NIST Digital Library of Mathematical Functions, §3.5(iv), especially Eqs. 3.5.16–3.5.17: https://dlmf.nist.gov/3.5.iv . The independent Chebyshev coefficient identity is based on DLMF §3.11(ii), Eqs. 3.11.9 and 3.11.11: https://dlmf.nist.gov/3.11.ii .

DLMF is a reference for mathematical facts, not a source-code dependency. No implementation, comments, examples, tests, or protected task material were copied. The finite sample ABI, bounds, ports, workload fixtures, and reference implementations were written independently for this benchmark. DLMF's site terms apply to its content; this package contains only a clean-room mathematical implementation and short formula attribution. The package itself introduces no third-party source dependency.
