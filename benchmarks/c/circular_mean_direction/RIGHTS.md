# Rights and provenance

This package contains independent implementations of the circular mean
direction formula. The RosettaGit task-title index was used only as a discovery
index; no Rosetta Code task text, examples, tests, submissions, or source code
were used.

The algorithm description is attributed to Utrecht University's *Tutorial 2:
Circular descriptives* and the Brigham Young University Center for Remote
Sensing page *True Circular Mean*. Only mathematical ideas and facts are used;
all package documentation, workload fixtures, references, and language ports
were written independently. The cited sources retain their own terms and
rights.
