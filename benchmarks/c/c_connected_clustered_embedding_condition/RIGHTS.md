# Rights and provenance

This package is a clean-room implementation of the c-connected clustered
planarity criterion stated in Theorem 3 of Fabrizio Frati's “Clustered Graph
Drawing,” *Encyclopedia of Algorithms*, Chapter 655,
DOI 10.1007/978-1-4939-2864-4_655. The theorem is attributed there to Feng,
Cohen, and Eades, “Planarity for clustered graphs” (1995), DOI
10.1007/3-540-60313-1_145.

The ports, references, and fixtures were authored independently from the
theorem's algorithmic idea. No source code, figure, example data, or expressive
prose from the book or paper is copied. The package checks a fixed supplied
embedding and does not reproduce the chapter's PQ-tree embedding-search
algorithm.
