# Rights and provenance

This benchmark follows the Colussi algorithm description by [Lecroq](https://igm.univ-mlv.fr/~lecroq/string/node10.html)
and its paper reference: Colussi, Galil, and Giancarlo, “On the exact
complexity of string matching,” FOCS 1990. The sources supplied algorithm
ideas only. The problem contract, language ports, workload, and direct oracle
are independently authored; no code, prose, or examples were copied. The
algorithm is not claimed as original.
