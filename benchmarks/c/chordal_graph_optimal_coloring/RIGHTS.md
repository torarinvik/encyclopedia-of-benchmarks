# Source and reuse

The [graph theory lecture notes](https://www.cs.uoi.gr/~loukas/courses/grad/Algorithmic_Graph_Theory/index.files/GraphTheoreticAlgorithms-TBiedl.pdf)
describe optimal greedy coloring using a perfect elimination ordering. This
package uses the mathematical idea only; its contract, code, and fixtures are
independently authored and do not copy source text or code.
