# Rights and provenance

The fixed-point map is identified from TheAlgorithms/C-Plus-Plus [`successive_approximation.cpp`](https://github.com/TheAlgorithms/C-Plus-Plus/blob/master/numerical_methods/successive_approximation.cpp). That repository's README states that its implementation source is MIT-licensed and its generated algorithm documentation is CC BY-SA 4.0. The recurrence `x_(k+1)=g(x_k)` is also described in standard numerical-analysis references, including [Applied Numerical Analysis, §1.5](https://www.cse.iitm.ac.in/~vplab/downloads/opt/Applied%20Numerical%20Analysis.pdf).

Only the method name, equation, and input-loop semantics were used for discovery and specification. The ten ports, workload, references, and package prose were written independently. No upstream implementation, comments, examples, or prose are included.
