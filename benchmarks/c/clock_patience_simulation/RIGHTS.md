# Rights and provenance

The package contains an independent implementation of the public rules of
Clock Patience and Knuth's mathematical bottom-card characterization. It does
not include or adapt Codewars task text, examples, tests, submissions, or code.
The Codewars public title/tag index was used only to identify the candidate.

Algorithm references:

- Donald E. Knuth, *The Art of Computer Programming*, Volume 1, Exercise 16,
  reproduced in the Stanford-hosted recreational-CS PDF:
  <https://cs.stanford.edu/~knuth/recreational-cs.pdf>
- University College Dublin, “How to play Clock Patience”:
  <https://maths.ucd.ie/openday/97/how2cp.html>

Only the mathematical/rule ideas are used. All benchmark source, fixtures,
oracles, and language ports are original to this repository. No upstream source
code is redistributed.
