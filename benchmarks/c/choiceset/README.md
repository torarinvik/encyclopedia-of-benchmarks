# Choiceset

This benchmark ports the pinned Lua `choiceset` set, which stores elements in a dense list and keeps a hash table from each key to its list position. Add and remove report whether the set changed, membership reports a Boolean, and removal replaces the deleted list element with the last element. A choose operation returns the element at the one-based position drawn by the source's injected random function.

The trace input is `[operation_count, operation, argument, ...]`. Operation 1 adds an integer key, 2 checks membership, 3 removes a key, and 4 chooses the element at the supplied one-based rank. For deterministic cross-language comparisons, the rank is supplied as the choose argument; it stands for the value returned by `self.random(current_size)`. Each operation produces one signed 64-bit result: changed/present as 1, unchanged/absent as 0, or the selected key. Results are little-endian bytes. The benchmark bounds traces to 1,024 operations, the set to 256 distinct keys, and keys to ±1,000,000,000. Choose on an empty set or with an out-of-range rank is invalid. The source's unordered `elements()` iterator and default `new()` without an injected random function are outside this trace contract.

Malformed traces return `-1`; after the trace is validated, insufficient output capacity returns `-2` without writing output. The workload includes duplicate insertion, swap-with-last deletion, deterministic choices, hash collisions and tombstones, empty traces, maximum output, malformed traces, and capacity failure. The pinned Lua source is [TheAlgorithms/Lua `choiceset.lua`](https://github.com/TheAlgorithms/Lua/blob/cedc141018ad48884318fe08a6db278664b17128/src/random/choiceset.lua).
