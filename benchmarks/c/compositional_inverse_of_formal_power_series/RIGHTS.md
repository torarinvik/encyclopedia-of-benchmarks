# Provenance and rights

The task contract and limits come from Library Checker
[`compositional_inverse_of_formal_power_series`](https://github.com/yosupo06/library-checker-problems/blob/master/polynomial/compositional_inverse_of_formal_power_series/task.md)
and its [`info.toml`](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/polynomial/compositional_inverse_of_formal_power_series/info.toml).
The upstream repository declares [Apache-2.0](https://github.com/yosupo06/library-checker-problems/blob/master/LICENSE).

Only the mathematical operation and task metadata informed this profile.
The bounded contract, fixtures, workload, oracles, documentation, and ten
language ports were written independently. No upstream code, prose, test
cases, or expected output files were reused. Local files follow this
repository's license.
