# Rights and provenance

The algorithmic subject is described by Tiow-Seng Tan's “Optimal
Triangulation,” *Encyclopedia of Algorithms*, Chapter 715
([DOI 10.1007/978-1-4939-2864-4_715](https://doi.org/10.1007/978-1-4939-2864-4_715)),
and by G. T. Klincsek, “Minimal triangulations of polygonal domains,”
*Annals of Discrete Mathematics* 9 (1980), 121–123
([DOI 10.1016/S0167-5060(08)70044-X](https://doi.org/10.1016/S0167-5060(08)70044-X)).

This package uses only the high-level additive interval dynamic-programming
idea, specialized to a convex polygon whose internal-diagonal weights are
provided as bounded integers. It does not use coordinates or derive geometric
lengths. All code, oracle formulations, workload fixtures, and explanatory
text were written independently for this repository. No source code, prose, or
fixtures from the cited works were copied. This note attributes the algorithm
idea and does not relicense the cited works.
