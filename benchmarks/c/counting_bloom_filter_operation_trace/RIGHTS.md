# Rights and provenance

The bounded counting Bloom filter follows the position-counter update method
described by Fan, Cao, Almeida, and Broder in “Summary Cache: A Scalable
Wide-Area Web Cache Sharing Protocol,” §4.3. The algorithm description is
used as provenance only. The paper is copyrighted; no source code, prose,
examples, or test fixtures are reproduced. Hash coefficients, bounds,
workload cases, and all language implementations were designed independently.

The NIST DADS Bloom filter page is a title/discovery reference. The counting
extension is attributed to the primary paper, and Yale's randomized-algorithms
notes are an independent technical cross-check.
