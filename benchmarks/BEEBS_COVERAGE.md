# BEEBS benchmark source crosswalk

This inventory audits the benchmark directories under `src/` at BEEBS commit [`049ded9f3aeb5591f553879d3a0376b8614e9422`](https://github.com/mageec/beebs/tree/049ded9f3aeb5591f553879d3a0376b8614e9422/src). The repository README says the suite derives from MiBench, WCET and DSPstone and explicitly licenses its supplied versions under GPL-3.0. Individual source files may carry additional upstream notices; each local package records its selected source and rights. A duplicate disposition means the algorithm core is already represented, regardless of implementation or launcher differences. An excluded row is not a claim that the benchmark has no useful code: it marks test harnesses, whole-library bundles, unverified/no-output kernels, or profiles with no compact contract selected. The directory inventory is based on the pinned `src/` tree; source-specific candidate rows below record the next items that merit deeper review.
