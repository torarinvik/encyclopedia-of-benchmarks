# Rights and provenance

The OI Wiki *Minimal Representation* chapter
([source](https://en.oi-wiki.org/string/minimal-string/)) is identified as
CC BY-SA 4.0 with SATA terms. Its high-level two-candidate elimination method
was used to identify the benchmark operation. The language ports, workload,
and oracle code in this package are clean-room implementations; no upstream
source code, prose, examples, or tests were copied.

This package records the algorithm family and source so that benchmark users
can review provenance. Repository-wide licensing terms continue to apply to
the original material in this package.
