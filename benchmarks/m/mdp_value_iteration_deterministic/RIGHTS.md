# Rights and provenance

This package is an independently written bounded implementation of the value
iteration recurrence described in “Reinforcement Learning,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_341. The chapter is used for
algorithm attribution; no book code, prose, or figures were copied. Exact
integer scaling and deterministic tie handling define the supplied profile.
These clean-room implementations are subject to the repository terms.
