# Mian–Chowla sequence

This package returns one term of the greedy Mian–Chowla B₂ (Sidon) sequence. It is a sequence-construction benchmark: after the initial term 1, each new term is the least integer greater than its predecessor that preserves distinctness of all unordered pairwise sums, including sums of a term with itself.

## Contract

- ABI: `int64_t mian_chowla_sequence(const int64_t *input, size_t length)`.
- Input frame: exactly `[n]`, with `1 <= n <= 30`; the parseable frame cap is two words so a single trailing word is rejected explicitly.
- Return the one-based term `a(n)`. Invalid or null input returns `-1`.
- `a(30)=1312`, so the valid result range is `1..1312`; the largest stored pair sum is `2624`.
- Primary ports maintain a set of used pair sums. For each candidate they check its sums with every existing term and its doubled value before adding those sums.
- The independent oracle recomputes all unordered pair sums, including diagonal pairs, for each tentative candidate prefix.

The sequence begins `1, 2, 4, 8, 13, 21, 31, 45, ...`. The primary reference uses at most 1312 candidate values over this domain, each checked against at most `n` new sums and `n(n+1)/2` stored sums. Thus its bounded comparison count is O(1312·n³), with O(n²) storage. The independent method checks every unordered pair sum for each candidate and uses O(n²) temporary storage.

This is separate from [`golomb_sequence_validator`](../../g/golomb_sequence_validator/README.md), which checks a self-describing sequence generated by a different recurrence; it does not enforce Sidon pair-sum uniqueness.

[`workload.json`](workload.json) includes the initial terms, rejection of candidate 3 while constructing the third term, representative middle terms, the maximum index, malformed frames, null input, and signed-i64 boundary values. Both references use different validity checks: one preserves the old sum set incrementally; the other reconstructs the entire tentative sum multiset.

## Source and provenance

The recurrence is attributed to Abdul Majid Mian and S. Chowla, “On the B₂ sequences of Sidon,” *Proceedings of the National Institute of Sciences of India, Section A* 14 (1944), 3–4. A later [academic review](https://journals.us.edu.pl/index.php/AMSIL/article/download/14110/10834/40240) records the original reference. [OEIS A005282](https://oeis.org/A005282) provides the accepted one-based recurrence and initial terms. The [RosettaGit task title](https://rosettagit.org/tasks/mian-chowla-sequence/) was used to find the candidate. No task text, example data, test cases, or source code was copied.
