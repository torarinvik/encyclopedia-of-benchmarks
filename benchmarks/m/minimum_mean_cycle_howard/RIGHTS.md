# Rights and provenance

The policy-iteration algorithm description is based on Thomas Dueholm Hansen
and Uri Zwick, “Lower Bounds for Howard's Algorithm for Finding Minimum
Mean-Cost Cycles,” *Mathematical Foundations of Computer Science* (2010),
https://doi.org/10.1007/978-3-642-17517-6_37. The paper is copyrighted by its
publisher. This package contains no copied source implementation or paper
prose. The benchmark contract, code, oracles, and workload were independently
written from the algorithm description.
