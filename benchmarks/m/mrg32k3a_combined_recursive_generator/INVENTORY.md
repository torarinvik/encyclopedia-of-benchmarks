# Package inventory

This package includes the MRG32k3a recurrence guide, original workload,
primary rolling-state and independent full-history references, rights note,
and ten native ports. It pins a 7-word valid input frame, one extra parseable
word, 64 output i64 words (512 bytes), and 128 bytes of fixed scratch. The
static inventory and workload reconciliation interfaces are listed in
`INVENTORY.json`; neither has been executed.
