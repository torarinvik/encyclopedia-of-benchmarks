# HJM forward-rate path generation

This package isolates the triangular Heath–Jarrow–Morton (HJM) forward-rate path kernel used by PARSEC's `swaptions` workload. It replays one path with explicit standard-normal factor shocks, so all ten language ports receive identical inputs. The workload does not include PARSEC's portfolio scheduler or the later swaption payoff calculation.

The kernel is algorithmically distinct from [`monte_carlo_simulation`](../monte_carlo_simulation/README.md): that package evolves one geometric-Brownian-motion asset and averages European call payoffs; this package converts an initial yield curve to forward rates, applies factor-derived HJM drifts, and evolves a triangular interest-rate term structure.

## Contract

The `float64_slice_io` input is `[n, factors, years, yield_0, ..., yield_(n-1), sigma_(0,0), ..., sigma_(factors-1,n-2), z_(0,0), ..., z_(n-2,factors-1)]`. `n` is an integer from 2 through 8, `factors` is 1 through 3, and `years` is one of `{1, 2, 3}`. Yields are in `[-0.05, 0.20]`, factor volatilities in `[0, 0.30]`, and supplied standard-normal shocks in `[-3, 3]`. The volatility matrix is factor-major; shocks are time-major and then factor-major. The exact input length is `3 + n + 2*factors*(n-1)`, with a maximum valid length of 53 and a maximum parseable length of 54.

Set `dt = years/n`. Convert the initial yields to forwards using `F[0] = Y[0]` and `F[i] = (i+1)*Y[i] - i*Y[i-1]`. For each factor, reproduce the source's drift recurrence: `D_f[0] = 0.5*dt*sigma[f,0]^2`; for `j > 0`, set `D_f[j] = 0.5*dt*(sum(sigma[f,0..j]))^2 - sum(D_f[0..j-1])`. Add the factor drifts to get `D[j]`. Initialize an `n*n` matrix to zero and place `F` in row zero. For each time row `t=1..n-1` and active maturity `j=0..n-t-1`, compute `H[t,j] = H[t-1,j+1] + D[j]*dt + sqrt(dt)*sum_f(sigma[f,j]*z[t-1,f])`. The `D[j]*dt` multiplication is preserved from the PARSEC implementation. Return the full matrix flattened in row-major order, including its zero-initialized inactive cells.

Invalid framing, values outside the domain, or a null input pointer returns `-1` without writes. A null output pointer or capacity below `n*n` returns `-2` without writes. Successful calls return `n*n`; compare each output with absolute and relative tolerances of `1e-12`.

The independent oracle is [`../../hjm_forward_path_oracle.py`](../../hjm_forward_path_oracle.py), and [`workload.json`](workload.json) records deterministic fixtures and ABI edge cases. The static package checker is [`verify_workload.py`](verify_workload.py).

## Source

PARSEC describes `swaptions` as pricing a swaption portfolio with Monte Carlo HJM paths; each path is generated by `HJM_SimPath_Forward_Blocking`. See the [PARSEC suite characterization, section 2.4.11](https://www.cs.princeton.edu/techreports/2010/890.pdf) and the [PARSEC source mirror's HJM implementation](https://github.com/cirosantilli/parsec-benchmark/tree/master/pkgs/apps/swaptions/src). The ports are clean-room implementations of the algorithm and bounded contract; they do not copy PARSEC source code.
