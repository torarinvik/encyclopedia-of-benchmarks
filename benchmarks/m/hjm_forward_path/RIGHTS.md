# Rights and provenance

This benchmark is a clean-room implementation of the bounded HJM forward-rate path algorithm described by PARSEC. The PARSEC Swaptions source directory includes a `COPYRIGHT` notice naming Intel Corp. (2007), while the PARSEC repository documentation says individual benchmark programs may carry package-specific terms. This package does not copy or adapt that source code. It records the algorithmic source for attribution and implements only the formula-level contract documented in `README.md`.

Primary references:

- [PARSEC suite characterization, section 2.4.11](https://www.cs.princeton.edu/techreports/2010/890.pdf)
- [PARSEC Swaptions source directory](https://github.com/cirosantilli/parsec-benchmark/tree/master/pkgs/apps/swaptions/src)
- [Source `COPYRIGHT` notice](https://raw.githubusercontent.com/cirosantilli/parsec-benchmark/master/pkgs/apps/swaptions/src/COPYRIGHT)

All files in this package and its language ports are newly written for this repository. The upstream notice is not copied into the implementation files.
