# Rights and provenance

The algorithmic reference is Hansen, Kaplan, Tarjan, and Zwick, “Hollow
Heaps,” ACM Transactions on Algorithms 13(3), 2017,
[doi:10.1145/3093240](https://doi.org/10.1145/3093240). The benchmark uses the
multi-root variant described in that work. No implementation, prose, or
fixtures are copied from the paper or other code repositories.
