# Rights and provenance

The algorithm title was found through Rosetta Code's task index. The local comparison was made against the repository's odd-order `magic_square` (Siamese walk) and `magic_square_singly_even_strachey` (quadrant construction). Neither covers orders divisible by four, and neither uses this row-major plus 4×4 diagonal-complement method. No matching local implementation or active reservation was found during source review.

The ports, workload, references, and documentation in this package are original clean-room work. They use the mathematical construction described in the linked references only; no source code, task wording, tests, or example output was copied. The Rosetta Code task is cited as discovery provenance, not as an implementation source. The references are descriptions of the algorithm and carry no source-code licensing into this package.
