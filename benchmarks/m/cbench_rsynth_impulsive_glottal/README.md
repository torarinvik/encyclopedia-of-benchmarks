# RSynth impulsive glottal-source resonator sample

This package isolates `impulsive_source` from pinned `lac-dcc/Benchmarks` commit `5d7b75df749241efa7a6e6f5be613d3fcc5cce38`, `cBench/office_rsynth/src/nsynth.c`. It is distinct from [`cbench_rsynth_natural_glottal_sample`](../cbench_rsynth_natural_glottal/README.md): the natural package uses its open-phase recurrence, while this package filters the impulsive doublet through the source's critically damped second-order resonator.

Input is `[nopen,sample_index]`, both integral binary64 values. `nopen` is 40..263; `sample_index` is 0..299. The profile fixes the launcher source default sample rate at 8000 Hz (`linuxplay.c::SAMP_RATE`) and starts the resonator with `p1=p2=0`, as in source reset. Coefficients reproduce `pitch_synch_par_reset`/`setabc` for `f=0`, `bandwidth=8000/nopen`, including binary32 assignment boundaries and the source gain factor `(nopen*0.00833)^2`. At sample offsets 0, 1, and 2 the input is respectively 0, +13,000,000, and -13,000,000; later input is zero. The generic resonator computes `a*input + b*p1 + c*p2`, updating the two prior outputs each sample. The selected binary32 output is promoted to one binary64 result.

The profile covers only this one resonator trace. It excludes natural-source excitation, period selection and cross-period state, the rest of the voice pipeline, dictionaries, phone lists, speech data, and file/CLI handling. Ports are clean-room and marked as modified. The pinned package notice says the software is public domain from Carnegie Mellon University and excludes certain dictionaries such as `beep`; this package uses no such data. The full notice is in [LICENSE.txt](LICENSE.txt). No runtime verification is claimed.
