# Modified Newton multiple-root inventory

This `float64_pair` profile contains ten native language ports, a binary64
primary reference, a 90-digit Decimal reference, and a bounded workload. The
method is the known-multiplicity correction described by NIST DLMF §3.8(ii).
See [`INVENTORY.json`](INVENTORY.json) for source paths. Static inventory and
workload reconciliation helpers are present; they have not been run.
