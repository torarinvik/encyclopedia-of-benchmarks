# Rights and provenance

The benchmark implementation, input/output contract, documentation, and
fixtures were authored independently. The only external material consulted was
the algorithm description in Charras and Lecroq's
[Morris–Pratt algorithm page](https://www-igm.univ-mlv.fr/~lecroq/string/node7.html),
which explains the longest-border fallback table and its linear bounds. The
page's code was not copied. The historical reference is Morris and Pratt,
“A linear pattern-matching algorithm,” UC Berkeley Technical Report 40 (1970).
