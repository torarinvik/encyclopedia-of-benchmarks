The primary uses the pre-`k` Floyd distance invariant to form cycles through
`k`; the independent reference enumerates canonical simple cycles. The valid
input limit is 110 i64 words, parseable limit 111, output is exactly 8 bytes,
and the workspace cap is 4096 bytes. The workload includes an acyclic valid
payload, weighted cycles, an equal-minimum tie, disconnected input, maximum
complete graph bounds, malformed framing/edges, and output-capacity cases.
