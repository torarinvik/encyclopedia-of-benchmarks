# Rights and provenance

Maximal Shift is a string-matching algorithm attributed to Daniel M. Sunday.
This package uses the method description in Lecroq's
[Maximal Shift page](https://igm.univ-mlv.fr/~lecroq/string/node29.html) and
the adapted good-suffix construction described on the
[Optimal Mismatch page](https://igm.univ-mlv.fr/~lecroq/string/node28.html).
The Maximal Shift page cites Sunday's 1990 paper, “A very fast substring search algorithm,”
*Communications of the ACM* 33(8):132–142. The page's algorithm description
is used for ideas only. No source code, prose, diagrams, or example strings
were copied.

The bounded integer-alphabet contract, code, references, fixtures, and
documentation were independently authored. The algorithm itself is not
claimed as original.
