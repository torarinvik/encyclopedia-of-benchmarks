# Rights and provenance

The benchmark implements the mathematical normal-algorithm model described by
Markov and summarized by the Encyclopedia of Mathematics. These sources provide
algorithm definitions, not source-code licenses for this package. RosettaGit
supplied a discovery lead only. The input frame, bounded rewrite interpreter,
references, fixtures, and ten language ports were independently authored; no
task code, wording, examples, or tests were copied. No third-party source code
is included.
