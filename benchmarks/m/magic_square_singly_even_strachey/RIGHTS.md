# Rights and provenance

The RosettaGit title index lists “Magic squares of singly even order.” That
title and category were used only to identify a coverage gap. No task statement,
example, test, submission, or source code from Rosetta Code or RosettaGit was
read or reused.

The implementations and both local reference programs were authored for this
repository from the mathematical algorithm descriptions cited in the package
README. The historical method is documented in the *Journal of Integer
Sequences* article and its independently presented variant is discussed in the
CUNY–Queensborough paper. No upstream implementation code or comments were
copied. This note does not assert or transfer a license for either paper; the
original publications retain their own terms. Local source files remain under
the repository's applicable terms.
