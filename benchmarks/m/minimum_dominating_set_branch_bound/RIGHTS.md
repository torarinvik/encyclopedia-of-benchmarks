# Rights and provenance

The benchmark uses the minimum dominating set problem and exact branch-and-bound
as described in Hua Jiang and Zhifei Zheng, “An Exact Algorithm for the Minimum
Dominating Set Problem,” *Proceedings of IJCAI 2023*, 5604–5612,
[official proceedings page](https://www.ijcai.org/proceedings/2023/622),
[paper PDF](https://ijcai.org/proceedings/2023/0622.pdf), DOI
[10.24963/ijcai.2023/622](https://doi.org/10.24963/ijcai.2023/622).

This small bounded profile uses its own closed-neighborhood branching rule,
greedy incumbent, and coverage lower bound; it does not reproduce the paper's
EMOS reductions or its branching selection. The paper is an algorithmic
reference only. All ports, references, fixtures, and documentation are
independently written; no implementation, code, or prose is copied. The cited
publication retains its own rights and terms.
