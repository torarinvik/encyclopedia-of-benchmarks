# Rights and provenance

This package is a clean-room implementation of the greedy maximum-heap
approach to the minimum-refueling-stops problem. It uses the problem statement
and editorial as algorithm references, not as source code. The benchmark ports
were written independently for this repository; no third-party implementation
was copied.

The benchmark is inspired by LeetCode 871, “Minimum Number of Refueling
Stops.” The official statement specifies the route, station model, exact-fuel
arrival rule, and minimum-stop result. The official editorial is linked from
the problem page. These references remain the property of their respective
authors and publishers:

- https://leetcode.com/problems/minimum-number-of-refueling-stops/
- https://leetcode.com/problems/minimum-number-of-refueling-stops/editorial/

The benchmark has no bundled third-party code or data. The bounded input
format, fixtures, reference oracles, and language ports in this package were
authored for this repository.
