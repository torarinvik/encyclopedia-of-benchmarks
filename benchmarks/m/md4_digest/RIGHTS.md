# Rights and provenance

The ports are clean-room implementations derived from the mathematical and
procedural description in Ronald L. Rivest, “The MD4 Message-Digest
Algorithm,” [RFC 1320](https://www.rfc-editor.org/rfc/rfc1320). RFC 1320
states that the algorithm is public domain. No RFC appendix source code,
RosettaCode task code, task prose, examples, or tests were copied.

The [pinned RosettaCodeData title index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks)
served only for title discovery. [RFC 6150](https://www.rfc-editor.org/rfc/rfc6150)
obsoletes RFC 1320 and classifies MD4 as Historic due to security weaknesses;
the benchmark is for algorithm coverage and performance comparison only.

The workload messages are locally specified byte patterns, not copied source
examples. All ten language ports, references, metadata, and fixture definitions
were authored for this repository.
