# Rights and attribution

This package is a clean-room implementation of the mathematical unit-disk graph metric and WSPD definition described in Rolf Klein, “Well Separated Pair Decomposition for Unit-Disk Graph,” Encyclopedia of Algorithms, DOI `10.1007/978-1-4939-2864-4_480`, together with the chapter's attribution to Gao and Zhang, “Well-separated pair decomposition for the unit-disk graph metric and its applications,” STOC 2003.

The Springer chapter and cited paper are copyrighted works; no redistribution license for their text or implementation is asserted here. The ports contain no copied source code or extended prose. They implement the stated mathematical operation using an explicitly bounded integer-lattice instance family and deterministic recursive split rule. The benchmark authors should retain the bibliographic attribution above when redistributing this package.
