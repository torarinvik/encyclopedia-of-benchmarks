# Rights and provenance

This package is an independently written bounded implementation of the
iterative-compression feedback vertex set method described in “Undirected
Feedback Vertex Set,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_450. The chapter is attribution, not a code license.
No book text, figures, or pseudocode blocks were copied. Repository code remains
subject to applicable repository terms.
