# Rights and provenance

This package is a clean-room implementation of the UnShuffle sort algorithm
described by the NIST Dictionary of Algorithms and Data Structures and
attributed there to Art S. Kagel's 1985 article. It uses the algorithm
description, name, and bibliographic citation only. No third-party source code,
problem statement, test, or prose has been copied.

Sources:

- [NIST DADS: UnShuffle sort](https://xlinux.nist.gov/dads/HTML/unshufflsort.html)
- Art S. Kagel, “Unshuffle Algorithm, Not Quite a Sort?”, *Computer Language*,
  3(11), November 1985.

The benchmark's contract, fixtures, references, and language ports are
independently authored for this repository. The referenced article is cited as
algorithm provenance; its full text and code are not redistributed here.
