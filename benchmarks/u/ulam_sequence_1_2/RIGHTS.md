# Rights and provenance

This package is a clean-room implementation of the mathematical U(1,2) recurrence. The recurrence is described by [MathWorld's Ulam Sequence entry](https://mathworld.wolfram.com/UlamSequence.html), with the classical U(1,2) terms cross-referenced against [OEIS A002858](https://oeis.org/A002858). The [pinned RosettaCodeData popular-task index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks) was used only to discover the title “Ulam numbers.”

No Rosetta task text, implementation, examples, or tests were copied. The ports, references, workload, and documentation were written independently from the cited mathematical definition and sequence cross-check. The title index's repository license does not apply to this original package content.
