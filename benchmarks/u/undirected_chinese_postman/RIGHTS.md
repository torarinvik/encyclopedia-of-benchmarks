# Rights and provenance

The undirected route-inspection algorithm was selected from the high-level
description in the [NIST Dictionary of Algorithms and Data Structures](https://xlinux.nist.gov/dads/HTML/chinesePostman.html)
and Berkeley IEOR 269 lecture notes. The NIST entry cites Edmonds and Johnson,
“Matching, Euler Tours, and the Chinese Postman,” *Mathematical Programming*
5 (1973), 88–124. No source implementation, task text, or examples were copied.
The ports, workload, and oracle code are clean-room work for this repository.
