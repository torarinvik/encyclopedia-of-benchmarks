# Rights and provenance

This package is a clean-room implementation of the direct discrete Fourier transform. It does not copy source code, prose, examples, or tests from external projects. The Algorithm Archive is used as the discovery and formula reference for the nested-loop DFT; Cooley and Tukey (1965) is cited for the fast factorization that distinguishes the existing FFT method.

- Algorithm Archive, “FFT / Cooley–Tukey”: https://www.algorithm-archive.org/contents/cooley_tukey/cooley_tukey.html
- Cooley, James W.; Tukey, John W. (1965), “An Algorithm for the Machine Calculation of Complex Fourier Series,” Mathematics of Computation 19(90), 297–301. https://doi.org/10.1090/S0025-5718-1965-0178586-1

All package code, fixtures, and documentation are original. They are available under the repository’s project license.
