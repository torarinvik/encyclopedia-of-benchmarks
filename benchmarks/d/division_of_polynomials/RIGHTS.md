# Rights and provenance

The mathematical operation, modulus, and official constraints are attributed
to [Library Checker](https://github.com/yosupo06/library-checker-problems),
whose problem repository is licensed under Apache-2.0. The task definition is
in polynomial/division_of_polynomials/task.md; the official limit and modulus
are in polynomial/division_of_polynomials/info.toml.

This package contains clean-room implementations, documentation, fixtures, and
oracles. It does not copy implementation code or test data from the source
repository. The bounded input/output ABI and the maximum length of 64 are local
profile choices.
