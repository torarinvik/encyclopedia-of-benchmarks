# Rights and provenance

This package is a clean-room implementation of deterministic linear-threshold
spread computation. The algorithm references are Zaixin Lu and Weili Wu,
“Influence Maximization,” *Encyclopedia of Algorithms*, Chapter 710, DOI
`10.1007/978-1-4939-2864-4_710`, and Zaixin Lu, Wei Zhang, Weili Wu, Bin Fu,
and Ding-Zhu Du, “Approximation and Inapproximation for the Influence
Maximization Problem in Social Networks under Deterministic Linear Threshold
Model,” §II, Algorithm 1, DOI `10.1109/ICDCSW.2011.33`.

The cited works are used for bibliographic attribution and mathematical
algorithm semantics. This repository does not copy their source code, prose,
figures, or test data and does not assert a license for those works. The
bounded input profile, exact fixed-point domain, synchronous activation-round
output, workload, references, and language ports were authored for this
repository.
