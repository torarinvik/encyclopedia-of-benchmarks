# Rights and source scope

This package uses the single-source shortest-paths-in-a-DAG algorithm listed
by the [CLRS Algorithmic Reasoning Benchmark](https://github.com/google-deepmind/clrs).
The upstream repository is licensed under Apache-2.0. Only the standard
topological-order relaxation method is used for algorithm attribution; all
implementations, the finite input contract, fixtures, and prose are authored
independently. No code, tests, examples, or explanatory text was copied.
