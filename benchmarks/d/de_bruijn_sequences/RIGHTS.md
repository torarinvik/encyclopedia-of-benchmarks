# Rights and provenance

The benchmark's algorithm was identified through Rosetta Code's
[De Bruijn sequences task](https://rosettacode.org/wiki/De_Bruijn_sequences)
and its [RosettaGit mirror](https://rosettagit.org/tasks/de-bruijn-sequences/).
Rosetta Code task content is described by its copyrights notice as GNU Free
Documentation License 1.2; this package does not reproduce task prose,
examples, submitted code, or page output. See the
[Rosetta Code copyrights page](https://rosettagit.org/drafts/rosetta-code-copyrights/).

The implementations are clean-room ports of the classical Fredricksen–Kessler–
Maiorana necklace-concatenation construction, based on the mathematical
definition and the published algorithm description. The method is attributed
to Fredricksen and Maiorana, “Necklaces of beads in k colors and k-ary de Bruijn
sequences,” *Discrete Mathematics* 23 (1978),
[DOI 10.1016/0012-365X(78)90002-X](https://doi.org/10.1016/0012-365X(78)90002-X).
