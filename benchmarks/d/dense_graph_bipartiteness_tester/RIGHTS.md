# Source and rights

This package is a clean-room implementation of the bounded dense-graph bipartiteness property tester described by Oded Goldreich and Dana Ron, “Testing Bipartiteness in the Dense-Graph Model,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_702`.

The chapter and cited papers remain copyrighted. No source code, prose, or figures are copied, and no upstream source-code license is asserted. The implementation uses only the mathematical sampling/test contract, with explicit bounded draw inputs and deterministic serialization. Preserve the attribution above when redistributing this benchmark.
