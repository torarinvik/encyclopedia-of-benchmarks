# Rights and clean-room note

The benchmark contract is based on the algorithm description in the Dial's
algorithm section of [CP-Algorithms' 0–1 BFS article](https://cp-algorithms.com/graph/01_bfs.html).
That article is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

This repository uses only the algorithmic idea of grouping tentative distances
into a cyclic array of exact-distance buckets for bounded nonnegative integer
weights. All code, input framing, tests, examples, and benchmark documentation
in this package are original clean-room work. No source code or problem text
was copied.
