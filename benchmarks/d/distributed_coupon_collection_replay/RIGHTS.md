# Rights and attribution

This package is a clean-room implementation of the coupon-collection process
described by Leszek Gąsieniec in “Randomized Gossiping in Radio Networks,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_324. The chapter is
copyrighted; no text, figures, or source code are reproduced. The supplied
open/closed tape is a deterministic benchmark replay and does not carry a
probability or performance guarantee.
