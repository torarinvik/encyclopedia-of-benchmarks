# Source and reuse notes

The operation contract is based on the [Library Checker Deque Operate All
Composite task](https://judge.yosupo.jp/problem/deque_operate_all_composite).
The upstream problem repository is Apache-2.0 licensed. This package uses the
task's semantics and algorithm taxonomy only; implementations, workload,
documentation, and oracle are independently written. No submitted source,
tests, or task prose were copied.
