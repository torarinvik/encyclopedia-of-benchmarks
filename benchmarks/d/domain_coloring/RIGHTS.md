# Rights and provenance

The algorithmic source is the [Algorithm Archive Domain Coloring
chapter](https://www.algorithm-archive.org/contents/domain_coloring/domain_coloring.html).
The chapter text is identified there as CC BY-SA 4.0, and its code examples as
MIT. This benchmark uses the high-level method only: evaluate a complex
function on a grid, represent phase by hue, and use magnitude to form contours.
It does not include source code, prose, images, or fixtures from the chapter.

The bounded function, integer phase approximation, contour mapping, RGB
quantization, ten language ports, oracle implementations, workload, and
documentation were independently written for this repository. The package is
not a derivative of the chapter's implementation examples.
