Hirschberg's linear-space LCS reconstruction is attributed to Daniel S.
Hirschberg, “A linear space algorithm for computing maximal common
subsequences,” *Communications of the ACM* 18(6), 1975,
[DOI 10.1145/360825.360861](https://doi.org/10.1145/360825.360861). The paper is
copyrighted by ACM. This package uses the published algorithm description for
discovery and attribution only; it does not reproduce article text, figures,
source code, or example data. The ports, bounded contract, workload, and
oracles are independently written clean-room work.
