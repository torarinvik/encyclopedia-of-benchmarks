# Source and reuse

The incremental clipping method is described in the [CP-Algorithms
half-plane article](https://cp-algorithms.com/geometry/halfplane-intersection.html),
which is licensed CC BY-SA 4.0. This package uses mathematical ideas only;
its interface, code, and fixtures are independently authored. Its independent
reference adapter reuses this repository's own pair-intersection oracle.

The [RosettaCodeData popular-task index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks)
supplies discovery for the Sutherland–Hodgman alias only. Method context is
Sutherland and Hodgman's “Reentrant Polygon Clipping,” [DOI
10.1145/360767.360802](https://doi.org/10.1145/360767.360802). No task text,
implementation, example, test, or fixture was reused.
