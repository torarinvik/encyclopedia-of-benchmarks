# Rights and provenance

The algorithm is independently implemented from the mathematical description in Herlihy, Shavit, and Tzafrir, “Hopscotch Hashing” (DISC 2008), especially §2 and Figure 1. The author-hosted paper is cited in the package README and inventory. No license for the paper text or any accompanying implementation was identified.

The ten language ports and both references were written for this repository. No source code, comments, pseudocode text, diagrams, or paper examples are copied. Workload fixtures were designed independently to exercise the bounded contract. NIST DADS is recorded only as a discovery index.
