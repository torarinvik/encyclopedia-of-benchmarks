# Rights and provenance

This package is a clean-room implementation of a mathematical integer
recurrence. No Rosetta Code task statement, examples, tests, submissions, or
source code were copied. The RosettaGit task-title index
<https://rosettagit.org/tasks/> was used only to discover the candidate title.

Algorithm definition and bounded reference values:

- OEIS Foundation, [A005185: Hofstadter Q-sequence](https://oeis.org/A005185),
  including its recurrence and the public b-file of terms.
- Douglas R. Hofstadter, *Gödel, Escher, Bach: An Eternal Golden Braid*, Basic
  Books, 1979/1980, p. 138, the original popular presentation.
- Nathan Fox, “A New Approach to the Hofstadter Q-Recurrence,” *Journal of
  Integer Sequences* 20 (2017), Article 17.7.3,
  [article PDF](https://cs.uwaterloo.ca/journals/JIS/VOL20/Fox/fox2.pdf).

The recurrence, indexing convention, and published sequence values are
mathematical facts. The contract, references, fixtures, and all language ports
here are independently written. Copyright in cited publications remains with
their respective authors and publishers.
