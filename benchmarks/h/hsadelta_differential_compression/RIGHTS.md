# Rights and source use

This is a clean-room benchmark profile of the HsaDelta algorithm idea. The
official [NIST DADS HsaDelta entry](https://xlinux.nist.gov/dads/HTML/hsadelta.html)
and Agarwal et al., [“An approximation to the greedy algorithm for differential
compression”](https://doi.org/10.1147/rd.501.0149), are cited for identification
and method attribution only.

No upstream source code, tests, examples, figures, or extended prose is
included. The bounded interface, deterministic block fingerprint, tie rules,
workload, references, and all language ports were prepared independently. No
upstream source-code license is asserted.
