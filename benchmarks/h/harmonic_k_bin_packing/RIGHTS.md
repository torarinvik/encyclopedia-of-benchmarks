# Rights and attribution

This package is a clean-room implementation of the algorithmic description in
Leah Epstein, “Harmonic Algorithm for Online Bin Packing,” *Encyclopedia of
Algorithms* (2016), DOI 10.1007/978-1-4939-2864-4_490. The chapter attributes
the HARM(k) family to Lee and Lee (1985). The package contains no copied book
prose or upstream implementation code; this note records provenance and does
not assert a license for the book text.
