# Rights and provenance

The Hough-transform algorithm idea is based on Duda and Hart, “Use of the
Hough Transformation to Detect Lines and Curves in Pictures,”
*Communications of the ACM*, 15(1), 1972,
[DOI 10.1145/361237.361242](https://doi.org/10.1145/361237.361242). The
Rosetta title index was used for discovery only. No Rosetta Code implementation,
prose, test case, or example was copied.

The bounded integer quantization profile, contract, ten language ports,
references, fixtures, and documentation were written independently for this
repository.
