# Rights and provenance

The RosettaGit [Hash join task](https://rosettagit.org/tasks/hash-join/) is
licensed under GFDL-1.3-or-later. It was used only to identify the high-level
two-phase algorithm: build a multimap for one relation, then probe it using
the other relation.

No task prose, sample rows, test cases, or language implementation was copied.
The bounded integer-key ABI, output ordering, open-addressed table, duplicate
posting representation, workload, and two oracles were written independently.
