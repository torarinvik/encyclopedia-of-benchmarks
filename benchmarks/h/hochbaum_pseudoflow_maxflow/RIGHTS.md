# Rights and provenance

The algorithmic source is Dorit S. Hochbaum, “The Pseudoflow Algorithm: A New
Algorithm for the Maximum-Flow Problem,” *Operations Research* 56(4),
992–1009 (2008), [DOI 10.1287/opre.1080.0524](https://doi.org/10.1287/opre.1080.0524).
The author-hosted paper is available at
[hochbaum.ieor.berkeley.edu](https://hochbaum.ieor.berkeley.edu/html/pub/HPF.pdf).

This benchmark uses the paper's normalized-tree pseudoflow ideas, specifically
the §5 full-excess normalization and §7.2 highest-label branch policy. The
separately described §10 pseudoflow-simplex variant is not implemented here.
The package contains independently written implementations and documentation,
with no copied source code or extended text. The paper remains subject to its
publisher's rights; this package does not relicense it. The benchmark's local
code and fixtures follow the repository's license.
