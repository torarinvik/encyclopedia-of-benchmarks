# Source and rights note

Source: “Graph Isomorphism,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_172.

This package independently implements the chapter's hypergraph-to-colored-
bipartite-incidence-graph representation reduction on a bounded indexed
hyperedge-family domain. Equal and empty hyperedges remain distinct edge
objects. No source code, prose, figures, examples, or test data are copied.
The package benchmarks the representation transform only; it makes no claim
to implement nauty, canonical labeling, or an isomorphism decision algorithm.
