# Rights and provenance

This package is a clean-room implementation of the mathematical edge-tester
procedure. The primary method reference is Deeparnab Chakrabarty and C.
Seshadhri, “Optimal Bounds for Monotonicity and Lipschitz Testing over
Hypercubes and Hypergrids,” STOC 2013, DOI `10.1145/2488608.2488661`,
arXiv:1204.0849. It is summarized in Deeparnab Chakrabarty,
“Monotonicity Testing,” *Encyclopedia of Algorithms*, Chapter 699, DOI
`10.1007/978-1-4939-2864-4_699`.

The cited material is used for mathematical attribution and method semantics
only. This repository does not copy source code, prose, tables, figures, or
test data, and does not assert a license for the cited works. The bounded
input profile, fixed sampling tape, workloads, references, and language ports
were authored for this repository.
