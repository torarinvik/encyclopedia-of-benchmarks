# Rights and provenance

This package implements a bounded simple-root form of Hensel lifting. The
mathematical procedure is described in Victor Shoup, *A Computational
Introduction to Number Theory and Algebra*, §12.5.2, and in FLINT's Hensel
lifting algorithm notes.

The source material is used for algorithm ideas and mathematical statements
only. All benchmark ports, workload fixtures, references, and documentation
were written independently; no published source code or prose was copied. The
referenced works retain their own copyright and license terms.
