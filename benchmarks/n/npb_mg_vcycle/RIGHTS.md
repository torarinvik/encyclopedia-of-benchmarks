# Rights and provenance

The algorithm contract is based on NASA Ames Research Center, *The NAS
Parallel Benchmarks*, RNR Technical Report RNR-94-007 (March 1994), §2.2.4,
especially the V-cycle definition and Table 2.4. The report is cited as an
algorithmic reference only. These ports do not copy or adapt implementation
code, comments, or prose from any NPB source distribution.

The package independently expresses the report's operator coefficients and
recursion in a small caller-supplied workload. No third-party source license is
asserted for these new files.

Reference: [NASA official report PDF](https://www.nas.nasa.gov/assets/nas/pdf/techreports/1994/rnr-94-007.pdf)
