# Provenance and rights

the public title “Next Palindromic Number.” No kata statement, example, test,
submission, or code was accessed or reused.

Algorithm provenance is the independent mathematical description in
[Generating palindromic numbers](https://rhyscitlema.estenligne.com/algorithms/generating-palindromic-numbers/),
which defines numeric palindromes and analyzes their increasing order by
digit length and mirrored leading halves. This package implements a bounded
next-greater operation from that general structure. No source code, comments,
test vectors, or prose are copied. No license is asserted for the independent
article; its citation records algorithm provenance only.
