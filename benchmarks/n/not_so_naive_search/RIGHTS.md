# Rights and provenance

The algorithm is based on the descriptions in NIST's [Not So Naive entry](https://xlinux.nist.gov/dads/HTML/notsonaive.html)
and Charras and Lecroq's [Exact String Matching Algorithms page](https://ligm.univ-eiffel.fr/~lecroq/string/node13.html).
The benchmark contains a clean-room implementation from those algorithm
descriptions. It does not copy source code, text, or example inputs. No external
license or implementation was reused.
