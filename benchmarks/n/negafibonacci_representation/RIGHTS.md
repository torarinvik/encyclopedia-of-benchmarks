# Rights and provenance

The representation theorem and constructive-method provenance are M. W.
Bunder, “Zeckendorf Representations Using Negative Fibonacci Numbers,”
*The Fibonacci Quarterly* 30(2), 1992, pp. 111–115,
[paper](https://www.mathstat.dal.ca/FQ/Scanned/30-2/bunder.pdf). OEIS
[A215022](https://oeis.org/A215022) is cited for the definition of
`F_-k`, bit orientation, and public sequence cross-checks.

The ports and references independently implement the documented interval
profile or direct exhaustive decoder. No paper code or prose is reproduced.
The Codewars title was used only as a discovery lead; its task text, examples,
tests, and community implementations were not used.
