# Rights and provenance

The protocol method is described in GPSD's [NMEA Revealed](https://gpsd.gitlab.io/gpsd/NMEA.html),
under “NMEA Encoding Conventions.” The 8-bit XOR rule and maximum sentence
length are used as algorithmic facts. No GPSD implementation code, page prose,
tables, examples, or fixtures are copied.

Codewars's public title/topic labels served only as a discovery index; no kata
statement, examples, tests, submissions, or source code were opened or reused.
All ten ports, references, and fixtures in this package are independently
written for the payload-only contract in the README.
