# Neural network perceptron classifier

This benchmark follows the pinned PHP classifier's public `predict` path: feature-major input, a weighted sum plus bias, sigmoid activation, and a strict `> 0.5` binary decision. Since sigmoid is strictly increasing and `sigmoid(0) == 0.5`, the output is exactly the sign test on the weighted sum. Weights and bias are supplied as milli-units to avoid random initialization; this contract benchmarks inference, not training. Input is `[feature_count, sample_count, bias_milli, weight_milli*, feature_matrix_feature_major*]` with 1–3 features and 1–4 samples. Weights and bias are in `[-10,10]`, features in `[-10,10]`. Output is one byte per sample (0 or 1). Invalid input returns -1. Runtime oracle: `neural_network_perceptron_classifier_oracle.py`.
