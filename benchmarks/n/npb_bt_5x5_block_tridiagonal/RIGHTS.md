# Rights and provenance

This package is a clean-room implementation of the block-tridiagonal line
solve described in NASA Ames Research Center Technical Report RNR-94-007,
"The NAS Parallel Benchmarks,” pp. 63–64. It cites that report as an algorithmic
specification and reproduces no upstream implementation code, comments, tables,
or prose. The bounded input format, dominance checks, checksum, oracle, and
language ports were written for this repository. No third-party implementation
license is asserted for these new files.
