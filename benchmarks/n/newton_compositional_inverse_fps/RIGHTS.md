# Provenance and reuse

The mathematical operation is indexed by [Library Checker](https://github.com/yosupo06/library-checker-problems), whose repository is Apache-2.0. The Newton precision-doubling method is described by [FLINT's polynomial algorithm documentation](https://github.com/flintlib/flint/blob/main/doc/src/algorithms/polynomials/composition.md). These sources provide algorithmic ideas only: the package does not copy their code, prose, or fixtures. The independent reference is the existing local compositional-inversion package's Lagrange-inversion oracle.
