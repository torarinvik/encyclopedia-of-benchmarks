# Rights and provenance

The algorithm was independently specified from the mathematical problem
structure and the high-level line-solving/backtracking approach discussed by
Wu et al., “An Efficient Approach to Solving Nonograms,” IEEE TCIAIG 5(3),
2013, [DOI 10.1109/TCIAIG.2013.2251884](https://doi.org/10.1109/TCIAIG.2013.2251884).
The paper is cited as algorithm provenance only; no source code or prose is
reproduced.

RosettaGit's [“Nonogram solver” title](https://rosettagit.org/tasks/nonogram-solver/)
is a discovery reference only. Its task
text, examples, tests, and community implementations were not used. All ten
ports and both references are clean-room implementations. The local workload
cases are independently constructed for this contract.
