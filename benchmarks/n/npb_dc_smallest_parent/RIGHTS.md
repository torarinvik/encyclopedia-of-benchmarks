# Rights and attribution

This package contains clean-room implementations of a bounded data-cube contract. It does not copy code from the NAS Parallel Benchmarks or from the cited papers.

The algorithm is attributed to the NAS arithmetic data cube material, including [NAS-03-005, *Arithmetic Data Cube as a Data Intensive Benchmark*](https://www.nas.nasa.gov/assets/nas/pdf/techreports/2003/nas-03-005.pdf), and the view-lattice discussion in Harinarayan, Rajaraman, and Ullman, [*Implementing Data Cubes Efficiently*](https://dsf.berkeley.edu/cs286/papers/datacube-sigmod1996.pdf), SIGMOD 1996. NASA NPB attribution is for algorithmic provenance; this package is not an official NASA benchmark distribution.

The package-authored source and documentation are provided under the repository's applicable license. The cited works retain their respective rights and terms.
