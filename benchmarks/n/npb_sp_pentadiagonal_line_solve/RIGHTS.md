# Rights and provenance

The algorithmic basis is NASA Ames Research Center, *The NAS Parallel
Benchmarks*, RNR Technical Report RNR-94-007 (March 1994), Chapter 3,
especially the diagonal form of approximate factorization and the scalar
pentadiagonal matrix description on pp. 64–70. The report is used only as an
algorithmic reference. The new implementations do not copy NPB source code,
comments, or prose.

These files are clean-room implementations of a bounded banded elimination
profile with caller-provided coefficients. No third-party implementation
license is asserted for the new code.

Reference: [NASA official RNR-94-007 PDF](https://www.nas.nasa.gov/assets/nas/pdf/techreports/1994/rnr-94-007.pdf)
