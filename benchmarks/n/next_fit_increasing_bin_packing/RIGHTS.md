This package is an independently written bounded implementation of the
increasing-order bin-packing heuristic described by Leah Epstein in “Bin
Packing, Variants,” *Encyclopedia of Algorithms*, DOI
`10.1007/978-1-4939-2864-4_491`.

The chapter and cited works remain copyrighted. No license to redistribute
their text, figures, or source code is asserted. The ports contain no copied
source code or extended prose and implement the stated sort-and-pack profile
clean-room. Retain this attribution when redistributing the package.
