# Gaussian Naive Bayes

This benchmark follows the pinned Rust `naive_bayes` implementation: class priors, per-class feature means and population variances, a `1e-9` minimum variance, and Gaussian log-density scores. Input is `[sample_count, feature_count, (class_label, feature_milli*)*, query_feature_milli*]`; there are 2–8 samples, 1–3 features, labels 0–2 with at least two represented classes, and scaled feature values in `[-10000,10000]`. Classes are visited in first-seen order, so ties select the first class. The output is the predicted signed 64-bit class label in little-endian bytes. Invalid inputs return -1. The R source is an umbrella containing Gaussian, multinomial, and Bernoulli classes with different variance conventions; the contract is specifically pinned to Rust Gaussian behavior. Runtime oracle: `naive_bayes_oracle.py`.
