# Rights and source scope

This package uses the mathematical description of Newton's divided-difference interpolation from the NIST Digital Library of Mathematical Functions, §3.3: https://dlmf.nist.gov/3.3. The algorithm is a standard mathematical method. The implementations, finite-field specialization, input/output contract, workload, and prose are independently written; no source code or explanatory wording is copied. The DLMF is maintained by the U.S. National Institute of Standards and Technology. The package cites the source for algorithmic provenance only.
