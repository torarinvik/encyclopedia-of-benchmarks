# Rights and provenance

This package is a clean-room implementation of the adaptive mesh rules in
NASA Ames Research Center Technical Report NAS-04-006, §§4.1–4.3. That report
is cited as the algorithmic specification. No upstream implementation code,
comments, figures, or prose were copied. The bounded depth, integer coordinate
format, scalar checksum, workload fixtures, and language ports were written
for this repository. No third-party source implementation license is asserted
for these new files.
