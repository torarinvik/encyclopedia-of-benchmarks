# NBench emulated floating-point arithmetic

This workload implements NBench BYTEmark's software arithmetic on its internal floating-point representation. It executes add, subtract, multiply, and divide using four 16-bit mantissa limbs, an unbiased signed exponent, a sign bit, and a type tag. The operations use integer shifts, carries, borrows, normalization, sticky shifting, and source-style chopping; they do not use host floating-point arithmetic.

The bounded input is [operation_count, records...]. Each 13-integer record is [operation, sign_x, exponent_x, x_word_0..x_word_3, sign_y, exponent_y, y_word_0..y_word_3]. Operation codes are 0 add, 1 subtract, 2 multiply, and 3 divide. Operands must be canonical normal finite values: sign 0 or 1, exponent -8..8, a top mantissa bit set, and four unsigned 16-bit words. Counts range from 1 to 8. Zero results are allowed; other special values are outside this bounded contract.

Each result is a 12-byte record: type and sign bytes, signed little-endian 16-bit exponent, then four little-endian 16-bit mantissa words in most-significant-word first order. The ABI returns the byte count, -1 for invalid input, or -2 for null/short output; errors write nothing.

This is a bounded algorithm-kernel workload, not an official NBench result. It is based on ANSIbench's NBench BYTEmark source nbench/src/emfloat.c (AddSubInternalFPF, MultiplyInternalFPF, DivideInternalFPF, normalize, and RoundInternalFPF) at [nfinit/ansibench commit ef90abd09d7b7bb1f2809f896d6f67fb9724bebe](https://github.com/nfinit/ansibench/blob/ef90abd09d7b7bb1f2809f896d6f67fb9724bebe/nbench/src/emfloat.c), with representation constants from nbench/include/emfloat.h. The source credits Rick Grehan of BYTE Magazine and notes that some routines draw on work by Steve Snelgrove and Neill Graham. The implementation is written independently; no source blocks are copied.
