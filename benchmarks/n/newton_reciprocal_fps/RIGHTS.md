# Provenance and reuse

The mathematical method is described in [FLINT's power-series inversion documentation](https://flintlib.org/doc/nmod_poly/inv_series.html). [Library Checker](https://github.com/yosupo06/library-checker-problems) identifies the operation and field; its repository is Apache-2.0. Only algorithmic ideas and operation semantics are used. Code and fixtures are independently written, while both oracles are references to existing local implementations of the same bounded contract.
