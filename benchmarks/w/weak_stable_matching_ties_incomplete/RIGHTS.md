# Rights and provenance

This package is an independently written bounded implementation of the
proposal-based weak-stability algorithm described in Kazuo Iwama and Shuichi
Miyazaki, “Stable Marriage with Ties and Incomplete Lists,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_805. The chapter is used for
algorithm attribution, not as a source-code license. No book prose, figures,
or code were copied. These clean-room implementations are subject to the
repository terms.
