# Provenance

Francisco Claude and Gonzalo Navarro, [*The Wavelet Matrix*](https://users.dcc.uchile.cl/~gnavarro/ps/spire12.4.pdf)
(2012), describe the levelwise data structure. The implementation uses only
the algorithmic idea. Source code, examples, and prose are independently
written; the bounded input and checksum follow this repository's wavelet-tree
contract for comparable behavior.
