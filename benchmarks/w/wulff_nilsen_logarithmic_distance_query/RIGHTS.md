# Rights and provenance

This package is an independently written implementation of the mathematical
algorithm described in Christian Wulff–Nilsen, “Approximate Distance Oracles
with Improved Query Time,” Sections 2–3 and Figures 2–3,
[arXiv:1202.2336](https://arxiv.org/abs/1202.2336), with chapter context from
the supplied *Encyclopedia of Algorithms*, DOI
[10.1007/978-1-4939-2864-4_568](https://doi.org/10.1007/978-1-4939-2864-4_568).

Only algorithmic ideas and mathematical definitions were used. The package
does not reproduce the paper's source code, examples, tests, or prose. The
sample hierarchy is supplied as benchmark input, and deterministic tie rules
are documented profile choices. The paper and book retain their respective
copyrights and licenses.
