# Rights and provenance

The mathematical algorithm is attributed to the Wynn epsilon recurrence in
the [NIST Digital Library of Mathematical Functions, §3.9(iv), Eq. 3.9.11](https://dlmf.nist.gov/3.9#E11).
The independent even-column identity is DLMF §3.9, Eq. 3.9.9. These sources
provide mathematical descriptions; this package contains a clean-room
bounded implementation and independently authored workload.

No source code, comments, examples, or tests were copied from external
implementations. The NIST DLMF website's own terms govern its text and
presentation; no license for copied prose or code is claimed here.
