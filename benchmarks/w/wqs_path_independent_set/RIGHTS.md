# Provenance

The [OI Wiki WQS overview](https://oi-wiki.org/dp/opt/wqs-binary-search/)
describes cardinality-penalty binary search and the concavity property for
weighted independent sets on a path. OI Wiki lists CC BY-SA 4.0 and SATA
terms; this package uses only the mathematical algorithm idea. Its contract,
implementation, and reference are independently written.
