# Rights and provenance

This package implements the mathematical procedure in Ulrik Wigderson,
[“Improving the Performance Guarantee for Approximate Graph Coloring”](https://doi.org/10.1145/2157.2158),
JACM 30(4), 729–735 (1983), Algorithm A in §2. The *Encyclopedia of
Algorithms*, Chapter 170, [“Graph Coloring”](https://doi.org/10.1007/978-1-4939-2864-4_170),
provides chapter coverage and discovery context.

The sources were consulted to identify and understand the algorithm. No source
code, pseudocode, examples, figures, or protected prose is reproduced. All
ports, fixtures, and documentation in this package are independently authored.
