# Rights and attribution

This is an independently written implementation of the mathematical wire-sizing profile described in Chris Chu, “Wire Sizing,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_483`. The chapter attributes the summarized convex-QP formulation to Chu and Wong (1999).

The chapter and original cited works remain copyrighted; no license to redistribute their text, figures, or source code is asserted. These ports contain no copied source code or extended prose. They implement the displayed Elmore-delay objective and constraints as a bounded clean-room benchmark. Retain the bibliographic attribution above when redistributing this package.
