# Rights and provenance

The bounded profile is inspired by the algorithm description of SPLASH-2
Water-Spatial in the SPLASH-2 characterization paper. The paper describes a
uniform 3-D grid and cutoff-neighbor search. This package does not reproduce
the original force field, integrator, source, input data, or parallel code.

All ten ports, workload fixtures, and oracles are clean-room implementations
of the mathematical contract documented in this package. No upstream source
code or prose has been copied. The original SPLASH-2 source mirror is linked
for provenance; no license grant for its code is claimed here.
