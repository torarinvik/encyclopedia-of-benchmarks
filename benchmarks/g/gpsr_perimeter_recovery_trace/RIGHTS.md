# Rights and provenance

The benchmark is a clean-room implementation of a published routing
algorithm. Its algorithmic source is Brad Karp and H. T. Kung, “GPSR: Greedy
Perimeter Stateless Routing for Wireless Networks,” Proceedings of MobiCom
2000, §§2.2 and 2.4, DOI
[10.1145/345910.345953](https://doi.org/10.1145/345910.345953). The encyclopedia
crosswalk reference is “Geographic Routing,” Chapter 352, DOI
[10.1007/978-1-4939-2864-4_352](https://doi.org/10.1007/978-1-4939-2864-4_352).

Only the algorithm's published ideas, names for packet state, and mathematical
definitions are used. No paper code, benchmark code, prose, or test vectors
are copied. The implementation, input frames, expected outputs, and workload
are independently authored for this repository. Repository source files use
the repository's existing licensing conventions.
