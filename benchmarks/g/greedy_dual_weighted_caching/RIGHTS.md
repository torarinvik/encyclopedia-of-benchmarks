# Rights and provenance

This package is an independently written bounded implementation of the
weighted-caching Greedy Dual policy described by Neal E. Young in “Online
Paging and Caching,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_267. The chapter is used only for algorithm
attribution and the credit rules. No book prose, figures, or code were copied.
These clean-room implementations are subject to the repository terms.
