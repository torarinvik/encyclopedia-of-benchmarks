# Rights and provenance

The two OI Wiki pages linked in the package README were used to identify the
static GBST structure: choose heavy children, split each heavy path at a
weighted midpoint, and connect each local tree root to the parent of its path
head. The English page is an OI Wiki translation mirror; the Chinese page
reports that its material is available under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and
[SATA](https://github.com/zTrix/sata-license) terms.

This package does not reproduce OI Wiki code, examples, diagrams, or prose.
The bounded parent-array contract, deterministic tie rules, structural
checksum, workload, references, documentation, and ten implementations are
clean-room work based on the high-level method description. Source pages:
[English](https://www.timothywang.ca/OI-wiki/ds/global-bst/) and
[Chinese](https://oiwiki.wiki/ds/global-bst/).
