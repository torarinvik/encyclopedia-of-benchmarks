# Rights and provenance

The package is an independently written implementation of an algorithmic
idea described in A. V. Goldberg, *Finding a Maximum Density Subgraph*, UC
Berkeley Technical Report CSD-84-171 (1984):
https://www2.eecs.berkeley.edu/Pubs/TechRpts/1984/Archive/CSD-84-171.pdf

The report is cited as a technical source. This package does not copy its
source code or prose. The benchmark contract, workload, references, and ports
were authored independently. Consult the report and its hosting institution
for any rights applicable to the source document.
