# Rights and provenance

All implementation code, fixtures, and package documentation here are original
clean-room work based on the mathematical transition. The pinned RosettaCodeData
popular-task index is used only to record title discovery; its task wording,
source code, examples, and tests were not reused.

The mathematical source is R. L. Goodstein, “On the Restricted Ordinal
Theorem,” *Journal of Symbolic Logic* 9(2), 1944, pp. 33–41,
[DOI 10.2307/2268019](https://doi.org/10.2307/2268019). Andrew Marks's UCLA
[set theory notes, §5.1](https://www.math.ucla.edu/~marks/notes/set_theory_notes_2.pdf)
give a modern explicit definition of hereditary-base notation and the
base-increase/decrement transition. No third-party implementation is included.

No program, helper, checker, script, test, build, compiler, profiler, or
benchmark was run to author these files.
