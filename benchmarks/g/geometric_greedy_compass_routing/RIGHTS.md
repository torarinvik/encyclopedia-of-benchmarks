# Rights and provenance

This package is a clean-room bounded implementation of the Greedy and Compass
forwarding rules attributed in “Routing in Geometric Networks,” *Encyclopedia
of Algorithms*, DOI 10.1007/978-1-4939-2864-4_352, and “Geographic Routing,”
DOI 10.1007/978-1-4939-2864-4_164. The chapters are used for algorithm
attribution and semantics, not as code licenses. No book prose, figures, or
code were copied. These implementations are subject to repository terms.
