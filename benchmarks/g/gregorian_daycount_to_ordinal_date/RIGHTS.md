# Rights and provenance

All ten implementations and both reference modules in this package were
written independently from algorithm descriptions. No source code, task text,
published examples, or tests were copied.

- RosettaCodeData's pinned popular-task index is used only to discover the task
  title. It does not define this package's epoch, calendar, bounds, or output.
- Howard Hinnant's author-hosted civil-date article and U.S. Naval Observatory
  calendar-conversion notes were consulted for the Gregorian conversion ideas.
- The workload fixtures are hand-derived boundary and calendar-transition
  cases authored for this contract.
