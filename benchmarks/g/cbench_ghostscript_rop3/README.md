# cBench Ghostscript ROP3 truth-table operation

This bounded profile evaluates one of Ghostscript's three-input raster Boolean operations on a single 32-bit pixel word. Input is `[D, S, T, code]`, where destination, source, and texture are unsigned 32-bit values represented as nonnegative signed 64-bit integers, and `code` is 0 through 255. For each pixel bit, the table index is `(T_bit << 2) | (S_bit << 1) | D_bit`; bit `index` of `code` selects the output bit. The return value is the resulting unsigned 32-bit word represented as `i64`. Input length must be exactly four; invalid input returns `-1`.

The pinned Ghostscript source enumerates all 256 ROP3 Boolean functions in `gsroptab.c`; `gsropt.h` defines the D/S/T truth-table encoding. The cBench launcher compiles and runs the full Ghostscript program, so this package isolates only the per-pixel Boolean core. It does not cover raster traversal, transparency behavior, clipping, memory-device dispatch, or PostScript interpretation.
