# Rights and provenance

Algorithm attribution: Harold N. Gabow, “Path-based depth-first search for
strong and biconnected components,” *Information Processing Letters* 74
(2000), 107–114, [doi:10.1016/S0020-0190(00)00051-X](https://doi.org/10.1016/S0020-0190(00)00051-X).
An author-hosted copy is linked at
<https://www.cs.princeton.edu/courses/archive/spr09/cos423/Lectures/bi-gabow.pdf>.
The paper is published by Elsevier; its copyright and terms remain with the
publisher. This repository uses the algorithm description for attribution
only. No paper prose, source code, or test data is reproduced. All ports and
both oracles were written independently.

The package normalizes SCC partition output to the repository's bounded
directed-graph byte-output contract. The local input/output contract, workload,
and implementation are original to this package.
