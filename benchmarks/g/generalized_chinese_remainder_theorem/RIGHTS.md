# Rights and provenance

The method was identified from the “Solution for not coprime moduli” section of the [CP-Algorithms Chinese Remainder Theorem article](https://cp-algorithms.com/algebra/chinese-remainder-theorem.html#solution-for-not-coprime-moduli), licensed CC BY-SA 4.0. This package uses the mathematical algorithm description and independently defines its bounded contract, fixtures, references, and code. No upstream code, prose, examples, or tasks were copied.

The primary reference consolidates constraints by prime powers. The independent reference merges original congruences using extended Euclid, providing a separate correctness path.
