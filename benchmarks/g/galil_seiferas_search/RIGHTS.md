# Rights and provenance

This clean-room benchmark follows the Galil–Seiferas algorithm description in
[Charras and Lecroq’s exact string matching reference](https://igm.univ-mlv.fr/~lecroq/string/node25.html)
and the original Galil–Seiferas paper, “Time-space-optimal string matching,”
Journal of Computer and System Sciences 26(3), 280–294 (1983). The references
are used for algorithmic and bibliographic provenance only. No implementation
code or example text is copied.
