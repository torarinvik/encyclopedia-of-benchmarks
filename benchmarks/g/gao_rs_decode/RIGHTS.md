# Rights and provenance

This benchmark is a clean-room implementation of the Gao Reed–Solomon
decoding method described in Shuhong Gao, “A New Algorithm for Decoding
Reed-Solomon Codes,” available from the [author's Clemson page](https://www.math.clemson.edu/~sgao/papers/RS.pdf).
Only the mathematical algorithm description was consulted. No source code,
examples, problem text, fixtures, or prose were copied. The bounded contract,
references, test vectors, and language ports are independently authored.
