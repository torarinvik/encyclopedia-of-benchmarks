# Rights and attribution

This package is a clean-room implementation of the Greedy-2 algorithm described in Piotr Krysta and Berthold Vöcking, “Utilitarian Mechanism Design for Single-Minded Agents,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_454`, Figure 3. The chapter text and figure are copyrighted; no source-code license is asserted. The implementation uses only the algorithm's mathematical definitions and independently chosen bounds, data representation, tie rule, tests, and code. No chapter prose or figure artwork is included.
