# Gram matrix and Gram loss

This benchmark follows the pinned [TheAlgorithms/Python `gramian.py`](https://github.com/TheAlgorithms/Python/blob/e1a2a8b016001309a73d5fec4818c35cca139795/computer_vision/gramian.py) `gram_matrix` and `gram_loss` functions. A feature map has shape `(channels, height * width)`; its normalized Gram matrix is the row dot-product matrix divided by `channels * height * width`. Gram loss is the sum of squared elementwise differences between two normalized Gram matrices.

Input starts with `[operation, channels, pixels]`, where operation 0 returns the row-major Gram matrix and operation 1 returns its Gram loss against a second feature map. Channels are 1–3, pixels are 1–4, and feature values are thousandths in [-1.000, 1.000]. Operation 0 then carries one flattened channel-major map; operation 1 carries two. Outputs are little-endian binary64 vectors, with loss represented by a one-element vector. The maximum workspace is 72 bytes for a 3×3 Gram matrix. Invalid input returns -1; a null output buffer or insufficient capacity returns -2, with input validation checked first. The contract excludes NumPy shape errors and the image/style-transfer caller. Runtime oracle: `gramian_oracle.py`.
