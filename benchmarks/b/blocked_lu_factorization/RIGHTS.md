# Rights and provenance

The package was written from algorithm descriptions, not copied source code.

- The SPLASH-2 characterization is cited as motivation for a bounded blocked LU benchmark and for discussing block locality and no-pivot operation. Its historical BLAS-1 update schedule is not reproduced here. DOI: [10.1145/223982.223990](https://doi.org/10.1145/223982.223990).
- The blocked right-looking equations are described using the FLAME educational material: [Blocked right-looking LU factorization](https://www.cs.utexas.edu/~flame/laff/alaff/chapter05-blocked-lu-factorization.html).

No SPLASH-2, FLAME, or other upstream source implementation, task text, or sample data is included in this package. The ports, oracle, fixtures, and documentation are original benchmark materials.
