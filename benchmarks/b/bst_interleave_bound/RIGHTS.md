# Rights and provenance

This package is an independently written bounded implementation of the
interleave lower bound described by Chengwen Chris Wang and Daniel Sleator in
“O(log log n)-Competitive Binary Search Tree,” *Encyclopedia of Algorithms*,
DOI 10.1007/978-1-4939-2864-4_263. The chapter is attribution, not a code
license. No book text, figures, or code were copied. Repository code remains
subject to applicable repository terms.
