# Rights and provenance

The algorithm idea follows the [NIST Dictionary of Algorithms and Data
Structures entry](https://xlinux.nist.gov/dads/HTML/BondSeqSearch.html) and
the description in [Abu El Haija and Alazzam, “Bond-Sequential Search”](https://www.iaeng.org/publication/WCECS2012/WCECS2012_pp194-198.pdf).
Only the algorithmic idea is used. No upstream code, pseudocode, tests,
examples, or prose was copied; all implementation code and benchmark material
were written independently.
