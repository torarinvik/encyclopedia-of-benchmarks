# Source and reuse

The [Allison–Dix paper](https://www.cantab.net/users/mmlist/ll/Publications/1986IPL/)
describes the bit-string LCS algorithm. Its linked source code is separately
licensed GPL-2.0; this package uses the mathematical method only and does not
copy the paper's prose, examples, source code, or fixtures. The contract and
implementations are independently authored.
