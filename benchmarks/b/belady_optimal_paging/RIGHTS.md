# Rights and provenance

This profile uses the offline optimal paging rule associated with L. A.
Belady's “A Study of Replacement Algorithms for a Virtual-Storage Computer,”
*IBM Systems Journal* 5(2), 1966, [DOI 10.1147/SJ.52.0078](https://doi.org/10.1147/SJ.52.0078).
The paper is cited for algorithm provenance only. The contract, fixtures,
oracles, and implementations are independently authored; no paper text or code
is reused.
