# Rights and provenance

The input/output semantics and official limits are adapted from the
`bitwise_xor_convolution` task in `yosupo06/library-checker-problems`, whose
repository is licensed under Apache-2.0. Links to the task and limits appear
in the package README and workload metadata.

The language ports, direct oracle, and verifier oracle are clean-room
implementations of the task definition and XOR Walsh–Hadamard convolution.
No upstream source code or test-generator code is included.
