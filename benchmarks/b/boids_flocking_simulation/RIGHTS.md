# Rights and provenance

The algorithm idea is attributed to Craig Reynolds, [“Flocks, Herds, and
Schools: A Distributed Behavioral Model”](https://www.red3d.com/cwr/papers/1987/SIGGRAPH87.pdf),
published in *Computer Graphics* 21(4), 1987. The paper is copyrighted by ACM.
This repository uses only its high-level descriptions of localized flock
behaviors and prioritized acceleration allocation. No paper prose, figure,
source code, or sample input is copied.

The Rosetta Code [“Boids” task title](https://rosettacode.org/wiki/Boids) was a
discovery lead only. The task page, its text, examples, and community solutions
were not consulted. Rosetta Code task content is generally licensed
GFDL-1.3-or-later; no task content is incorporated here.

The ten language ports, integer specialization, ABI contract, fixtures,
references, inventory, and documentation were authored for this repository.
