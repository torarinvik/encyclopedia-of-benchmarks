# Rights and provenance

This package is an independent implementation of the discrete Baum–Welch
re-estimation method. NIST's [Baum Welch algorithm
entry](https://xlinux.nist.gov/dads/HTML/baumWelch.html) identifies the HMM
parameter-estimation task. Lawrence R. Rabiner's “A Tutorial on Hidden Markov
Models and Selected Applications in Speech Recognition,” *Proceedings of the
IEEE* 77(2), 1989, pp. 257–286, [DOI
10.1109/5.18626](https://doi.org/10.1109/5.18626), describes the forward–backward
recurrences and re-estimation equations. The candidate title was found in
NIST's [unified index](https://xlinux.nist.gov/dads/ui.html).

Only mathematical algorithm descriptions and bibliographic details are used.
No source code, examples, prose, or test data were copied. The bounded
contract, workload, references, and ten language ports were authored for this
repository.
