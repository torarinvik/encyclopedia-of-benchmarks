# Rights and provenance

The RosettaGit “Brownian tree” title was used to identify a candidate task. Its broad idea is a seed and moving particles that become fixed when they collide with the growing aggregate. The profile semantics are grounded in Witten and Sander's 1981 DLA paper, which describes random-walking particles that join when they reach a site adjacent to the cluster and are removed on touching the lattice boundary.

All code, PRNG framing, input and output contracts, workload fixtures, references, and documentation in this package are clean-room work. No Rosetta Code implementation, task wording, test, example, image, or output was reused. No upstream source-code license is claimed for the mathematical algorithm description.

The local duplicate review found no Brownian-tree or diffusion-limited-aggregation benchmark or active reservation. The existing geometric-Brownian-motion financial simulations have different state transitions and outputs.
