# Rights and provenance

This package is a clean-room implementation of the BLR linearity test's
mathematical procedure. The primary reference is Manuel Blum, Michael Luby,
and Ronitt Rubinfeld, “Self-testing/correcting with applications to numerical
problems,” *Journal of Computer and System Sciences* 47(3), 1993, DOI
`10.1016/0022-0000(93)90044-W`. The algorithm is summarized in *Encyclopedia
of Algorithms*, Chapter 202, DOI `10.1007/978-1-4939-2864-4_202`.

The test rule is also stated in Arora, Lund, Motwani, Sudan, and Szegedy,
“Proof Verification and the Hardness of Approximation Problems,” Section 4,
available at <https://madhu.seas.harvard.edu/papers/1992/almss-journ.pdf>.
References are used for attribution and mathematical semantics only. This
repository does not copy their code, prose, tables, figures, or test data, and
does not assert a license for those works. The bounded input format, random
choice tape, fixtures, references, and language ports were authored for this
repository.
