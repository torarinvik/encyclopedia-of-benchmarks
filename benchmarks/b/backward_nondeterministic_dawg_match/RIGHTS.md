# Provenance

The BNDM idea is attributed to Gonzalo Navarro and Mathieu Raffinot,
[*A Bit-parallel Approach to Suffix Automata: Fast Extended String Matching*](https://users.dcc.uchile.cl/~gnavarro/abstracts/cpm98.html)
(1998). This package uses the algorithmic idea and bibliographic information;
its code, description, contract, and workload were independently written.
No upstream source code, problem statement, or tests were copied.
