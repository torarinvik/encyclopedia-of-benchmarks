# Rights and provenance

The algorithm is based on the descriptions in KACTL's
[`MinimumVertexCover.h`](https://github.com/kth-competitive-programming/kactl/blob/main/content/graph/MinimumVertexCover.h)
and [`DFSMatching.h`](https://github.com/kth-competitive-programming/kactl/blob/main/content/graph/DFSMatching.h).
The repository headers label their snippets CC0. This package does not copy
their source code or prose. Its contracts, fixtures, references, ports, and
documentation are clean-room work using the matching and alternating-path
ideas, with an explicit bounded lexicographic certificate refinement.

The independent reference uses exhaustive subset enumeration rather than the
primary matching procedure.
