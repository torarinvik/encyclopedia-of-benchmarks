# Rights and provenance

This clean-room benchmark uses the algorithm description in the
[Charras–Lecroq Berry–Ravindran entry](https://igm.univ-mlv.fr/~lecroq/string/berryravindran.html),
which cites Berry and Ravindran’s 1999 paper, “A fast string matching
algorithm and experimental results,” Prague Stringology Club Workshop’99,
Collaborative Report DC-99-05, pp. 16–26. The source is used for the method
and bibliographic provenance only. No implementation code or sample text is
copied. The benchmark ports and fixtures are original clean-room work.
