# Rights and provenance

This benchmark is a clean-room implementation of the buddy-system allocation
method. NIST DADS is used as an algorithm discovery and terminology source; the
method is cross-checked against the summary of Knuth's buddy system in Pinto et
al., “A Hardware Buddy System for Fast Allocation,” §3.1. These references are
cited for algorithm behavior only. No source code, comments, fixtures, or
example traces were copied. The ports and workload are newly written for the
bounded contract in this package.

The source references retain their own copyright and licensing terms. No
upstream implementation is incorporated into this package.
