# Rights and provenance

The public Codewars title and catalog tags served only as an algorithm
discovery index. No problem statement, task examples, tests, submissions, or
source code were used or copied.

The three-state remainder automaton is supported by Dexter Kozen's
[Cornell CS 4810 lecture notes](https://www.cs.cornell.edu/kozen/Papers/481.pdf).
That source provides method context. The bounded ABI, implementation ports,
independent alternating-sign reference, and workload fixtures are written
clean-room for this repository. No upstream implementation text or code is
included.
