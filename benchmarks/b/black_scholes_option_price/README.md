# Black-Scholes Option Price

This package ports the European call and put pricing methods from the pinned [TheAlgorithms/R implementation](https://github.com/TheAlgorithms/R/blob/f65344fabeea0ae33c1ca321af709447c1a8a4c2/quantitative_finance/black_scholes_option_pricing.r). The operation selector is `0` for a call and `1` for a put. The source's Greeks and implied-volatility estimator are separate operations and are not included in this package.

The `i64_array_float64` ABI accepts exactly `[option_kind, spot_milliunits, strike_milliunits, maturity_milliunits, volatility_milliunits, rate_milliunits]`. The five financial values are decoded by dividing their integer representation by `1000.0`; inputs therefore use a three-decimal grid. Spot and strike must be in `[0.010, 1,000,000.000]`, maturity in `[0.001, 100.000]` years, volatility in `[0.001, 5.000]`, and the continuously compounded risk-free rate in `[-1.000, 1.000]`. These bounds are a finite benchmark domain within the source method's positive-input contract. Unsupported option kinds, out-of-range values, and incorrect array lengths return `-1e300`.

For `sigma_sqrt_time = volatility * sqrt(maturity)`, the implementation computes `d1 = (log(spot / strike) + (rate + volatility^2 / 2) * maturity) / sigma_sqrt_time` and `d2 = d1 - sigma_sqrt_time`. A call returns `spot * N(d1) - strike * exp(-rate * maturity) * N(d2)`. A put returns `strike * exp(-rate * maturity) * N(-d2) - spot * N(-d1)`. `N(x)` is evaluated as `0.5 * erfc(-x / sqrt(2))`, matching the source's normal CDF while avoiding cancellation in the put tails.

The source class defaults the risk-free rate to `0.05`; this ABI makes the rate explicit so each workload case is self-contained. Runtime and auxiliary space are O(1). The workload includes the standard at-the-money example for both option kinds, a zero-rate case, boundaries, and invalid inputs. Binary64 results are compared with absolute and relative tolerances of `1e-12`.
