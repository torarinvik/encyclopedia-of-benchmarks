# Rights and provenance

This package is a clean-room, deterministic profile of the multi-layer
annealed particle-filter update attributed to PARSEC Bodytrack. It does not
include PARSEC source code, image assets, input sequences, or copied test data.
The benchmark's rational likelihood, fixed-point tape format, and bounds are
original choices documented in [`README.md`](README.md) and
[`workload.json`](workload.json).

Algorithm attribution:

- [PARSEC 2.0 workload paper](https://pages.cs.wisc.edu/~markhill/restricted/757/mbs09_parsec2.pdf).
- [Deutscher, Blake, and Reid, CVPR 2000](https://www.robots.ox.ac.uk/~lav/Papers/deutscher_etal_cvpr2000/deutscher_etal_cvpr2000.html).

The cited paper is copyrighted by its authors/publisher. This package contains
only independently written benchmark descriptions and implementations.
