# Rights and provenance

The algorithm idea comes from David Pisinger's “Linear Time Algorithms for
Knapsack Problems with Bounded Weights,” *Journal of Algorithms* 33(1), 1999,
DOI [10.1006/jagm.1999.1034](https://doi.org/10.1006/jagm.1999.1034). The paper
is the primary source; no license is asserted for it. KACTL's
[`FastKnapsack.h`](https://github.com/kth-competitive-programming/kactl/blob/main/content/various/FastKnapsack.h)
is marked CC0 and cites the same paper. Only the algorithmic idea and
high-level operation were consulted; all package code, fixtures, and wording
were written independently.

No third-party implementation code or test data is included.
