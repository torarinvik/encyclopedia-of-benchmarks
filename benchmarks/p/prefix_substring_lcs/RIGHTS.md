# Rights and provenance

This package implements the bounded Prefix-Substring LCS operation in clean
room form. The task statement and constraints are used only to identify the
operation and validate the input/output contract. No upstream implementation,
test data, or task prose is copied.

The semi-local LCS boundary method is attributed in the problem proposal to
C. E. R. Alves, E. N. Cáceres, and S. W. Song, “An all-substrings common
subsequence algorithm,” *Discrete Applied Mathematics* 156(7), 2008,
1025–1035, DOI [10.1016/j.dam.2007.05.056](https://doi.org/10.1016/j.dam.2007.05.056).
The task contract is from [Library Checker Prefix-Substring LCS](https://github.com/yosupo06/library-checker-problems/tree/master/string/prefix_substring_lcs).
Library Checker identifies its problem repository as Apache-2.0; this package
does not incorporate repository code.

All language ports, oracles, and workloads here were written independently for
this repository.
