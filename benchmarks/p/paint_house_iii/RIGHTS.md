# Rights and provenance

The official [LeetCode 1473 page](https://leetcode.com/problems/paint-house-iii/)
was consulted for the problem's high-level state formulation and used to
confirm the intended operation. Its prose, examples, tests, editorial text,
and implementation code are not reproduced here. The workload fixtures and
all reference and language implementations were written clean-room for this
repository.

No third-party implementation code is included. The method is a standard
dynamic-programming formulation expressed independently, with a separate
exhaustive assignment oracle for the bounded profile.
