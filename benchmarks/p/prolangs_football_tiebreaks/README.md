# Prolangs-C football standings tie-breaks

This package isolates the source's recursive ranking kernel for an already tied group of teams. It models the ordered tie-break path used by `Prolangs-C/football`: head-to-head record for same-division or two-team ties; a head-to-head sweep for larger cross-division ties; division record when applicable; conference record; common-opponent record when every team has at least four common games; division or conference net points; overall net points; and finally the incoming order.

The benchmark contract accepts 2–8 teams. The input is a signed 64-bit array: `[n, 12 fields per team, head_to_head_wins[n*n], head_to_head_ties[n*n]]`. Each team's 12 fields are unique team ID (0–31), conference (0–1), division (0–2), division record points, division games, conference record points, conference games, common-opponent record points, common games, division net points, conference net points, and overall net points. Record points mean `2*wins + ties`, so their percentage is `points / (2*games)`; zero games gives a percentage of zero. Net points are bounded to ±4096. Head-to-head matrices are row-major; wins are directional and ties must be symmetric. A loss against a team is the reciprocal cell's win count. Diagonal entries must be zero. Team IDs are unique. The source comparator orders the input tie group by ascending conference, then ascending team ID; a workload fixture distinguishes this order from ID-only sorting. The result packs the full best-to-worst team-ID sequence as base-32 digits into an i64. Malformed input returns `-2`.

The contract fixes one unresolved overall-record tie group and starts from the source's post-sort order. Whenever a criterion strictly separates teams, the source restarts the criterion chain at head-to-head for each remaining multi-team subgroup; the `strict_division_split_restarts_head_to_head_for_remaining_three` fixture exercises that behavior. It does not parse the original 28-team schedule or reproduce the surrounding standings report, playoff labels, league-wide ranking tables, or interactive prompts. Bounded records are supplied directly; common-opponent data represents fully scored games, and the four-game threshold follows the source's criterion eligibility rule. Fraction comparisons use exact integer cross-products, which preserve the source's rational win-percentage ordering on this bounded domain.
