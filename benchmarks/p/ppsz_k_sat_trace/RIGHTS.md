# Rights and provenance

This package is a clean-room implementation of the bounded PPSZ trace described in Timon Hertli, “Unique k-SAT and General k-SAT,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_680`.

The chapter and summarized papers remain copyrighted. This package reproduces no chapter prose, source code, or figures and asserts no license over the source material. The implementation covers only the specified bounded 3-CNF profile and supplied random choices.
