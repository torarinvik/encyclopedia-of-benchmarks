# Rights and provenance

This package is an independently written bounded implementation of the
unit-value SGR policy described by Markus Schmidt in “Packet Switching in
Multi-queue Switches,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_274. The chapter is attribution, not a code license.
No book text, figures, or code were copied. Repository code remains subject to
applicable repository terms.
