# Source and rights notice

The algorithm profile is based on the Ψ-based compressed suffix-array access
description in “Compressed Suffix Array,” by Djamel Belazzougui, Veli Mäkinen,
and Daniel Valenzuela, *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_82. The chapter is copyrighted by Springer and grants
no source-code license. This is a clean-room bounded implementation of the
explicit Ψ access relation and sampled-value traversal; it contains no copied
chapter prose, figures, or source code. The package's own code is provided
under the repository's project license.
