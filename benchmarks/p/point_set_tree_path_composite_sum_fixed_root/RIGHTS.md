# Provenance and rights

This benchmark was discovered from Library Checker's
[`point_set_tree_path_composite_sum_fixed_root` task](https://github.com/yosupo06/library-checker-problems/blob/master/tree/point_set_tree_path_composite_sum_fixed_root/task.md),
its [official parameter file](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/tree/point_set_tree_path_composite_sum_fixed_root/info.toml),
and the upstream repository's [license](https://github.com/yosupo06/library-checker-problems/blob/master/LICENSE),
which declares Apache-2.0.

Only the operation contract, modulus, and parameter limits informed this
package. Its bounded ABI and workload, fixtures, primary and independent
oracles, documentation, and ten implementations are clean-room work derived
from the mathematical definition. No upstream code, problem prose, generated
tests, or expected outputs were copied. Local artifacts follow this
repository's license.
