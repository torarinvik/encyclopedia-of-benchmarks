# Rights and source notes

The method reference is CP-Algorithms' [Point location in O(log n)](https://cp-algorithms.com/geometry/point-location.html).
That page is available under CC BY-SA 4.0. It describes an offline x-sweep,
an active y-ordered set of nonvertical edges, and lookup of the nearest edge
below a query. The benchmark fixes small integer bounds and makes the endpoint
event order and face labels explicit. No source code, prose, examples, or
fixtures were copied.

The bounded contract, sweep and direct-scan oracles, workload, static package
reviewer, and ten language ports are clean-room work for this repository. This
note does not claim ownership of the referenced algorithmic ideas.
