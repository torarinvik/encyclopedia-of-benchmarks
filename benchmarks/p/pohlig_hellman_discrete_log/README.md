# Pohlig–Hellman discrete logarithm

This package solves `g^x = h (mod p)` by factoring the order of `g`, solving
prime-power logarithm components by digit lifting, and joining them with the
Chinese remainder theorem. It is distinct from
[`baby_step_giant_step`](../../b/baby_step_giant_step/README.md)'s one-shot
coprime BSGS search and [`discrete_logarithm_mod`](../../d/discrete_logarithm_mod/README.md)'s
gcd-stripping generalized BSGS. The fixed-modulus profile
[`discrete_logarithm_fixed_mod`](../../d/discrete_logarithm_fixed_mod/README.md)
uses a direct table for repeated targets rather than prime-power reduction.

## Contract

- ABI `i64_array_scalar`; symbol `pohlig_hellman_discrete_log`.
- Input `[p,g,h]`: `p` must be prime in `3..=1009`, `1<=g<p`, and `0<=h<p`.
  Exact frame length is three (maximum parseable length four).
- Return the least `x` in `0..ord_p(g)-1` for which `g^x=h mod p`. Return
  `-2` if no such exponent exists, including every `h=0` case. In particular,
  `g=1,h=1` returns zero and `g=1,h!=1` returns `-2`.
- Null, malformed, composite-modulus, and out-of-range inputs return `-1`.

## Primary and independent methods

The primary factors `p-1`, then reduces it to the exact order `N=ord_p(g)` by
repeatedly testing `g^(N/q) mod p` for each prime factor `q`. For each
prime-power component `q^e` of `N`, it lifts the base-`q` digits of the
logarithm. Each digit search is a baby-step/giant-step lookup in the
order-`q` subgroup generated by `g^(N/q)`. A CRT reconstruction combines the
resulting residues into the least exponent modulo `N`. This order reduction
allows any nonzero base, including bases that are not primitive roots.

The independent oracle scans `1,g,g^2,...` directly and returns the first
matching exponent. Its `O(p)` bound is small enough for the maximum modulus.
The primary uses `O(sqrt(p) + Σ e_q sqrt(q))` modular operations and
`O(sqrt(p))` temporary storage; the direct reference uses `O(p)` operations
and constant auxiliary storage.

The algorithm follows Pohlig and Hellman's 1978 paper, [*An improved
algorithm for computing logarithms over GF(p) and its cryptographic
significance*](https://doi.org/10.1109/TIT.1978.1055817) (an
[author-hosted copy](https://ee.stanford.edu/~hellman/publications/28.pdf)),
and the digit-lifting and CRT description in [FLINT's discrete-log
documentation](https://flintlib.org/doc/algorithms/number-theory/discrete-log.html).
These sources provide algorithm descriptions only; all code and fixtures are
clean-room.

[`workload.json`](workload.json) covers smooth and less-smooth `p-1` values,
primitive and proper-subgroup bases, order one, subgroup non-members, zero
target, maximum prime modulus, and null/malformed cases. References are
[`primary_oracle.py`](primary_oracle.py) and
[`independent_oracle.py`](independent_oracle.py). The static package inventory
is [`check_inventory.py`](check_inventory.py), with `static_issues()` and
`verify()` entry points.
