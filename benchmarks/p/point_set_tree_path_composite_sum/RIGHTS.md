# Rights and provenance

The operation contract, affine-map definition, modulus, and official limits are
from Library Checker
[`Point Set Tree Path Composite Sum`](https://github.com/yosupo06/library-checker-problems/blob/master/tree/point_set_tree_path_composite_sum/task.md)
and its
[`info.toml`](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/tree/point_set_tree_path_composite_sum/info.toml).
The upstream problem repository declares Apache-2.0. This package uses the
task description and constraints only; its bounded profile, top-tree cluster
summaries, implementations, fixtures, and oracles are independently written.
No upstream solution code or generated tests are copied.
