# Rights and provenance

This package is an independently written, bounded implementation of the local
angle-based decision described in “Probabilistic Data Forwarding in Wireless
Sensor Networks,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_301. The source is used for algorithm attribution;
no book code, prose, or figures were copied. A supplied finite draw index makes
the local decision reproducible. The package does not implement the network
protocol or claim its continuous-randomness guarantees. These clean-room
implementations are subject to the repository terms.
