# Rights and provenance

The algorithm is attributed to J. Francon, G. Viennot, and J. Vuillemin,
“Description and Analysis of an Efficient Priority Queue Representation,”
19th Annual Symposium on Foundations of Computer Science, 1978,
https://www.xavierviennot.org/xavier/articles_files/FrViVu78.pdf. NIST DADS
provides a concise independent description of the pagoda links and meld:
https://xlinux.nist.gov/dads/HTML/pagoda.html.

This package uses the published algorithmic ideas and defines its own bounded
trace contract. All references, ports, and fixtures are independently authored.
No implementation source, source comments, prose passages, or published test
fixtures are copied. The original paper's unique-priority simplification is
used as an explicit profile constraint.
