# Rights and provenance

The operation and square-zero set-series model are based on Library Checker’s
`power_projection_of_set_power_series` task. The upstream repository is
Apache-2.0. This package uses only the mathematical operation, modulus, and
input/output concepts. Its bounded profile, ports, workloads, oracles, and
documentation are clean-room work; no upstream code, tests, fixtures, or prose
were copied.
