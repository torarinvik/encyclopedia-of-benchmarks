# Rights and provenance

This package is an independently written bounded profile of additive-tree
reconstruction described in “Phylogenetic Tree Construction from a Distance
Matrix,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_292. The chapter is used for algorithm attribution
and semantics, not as a code license. No book prose, figures, or code were
copied. These clean-room implementations are subject to repository terms.
