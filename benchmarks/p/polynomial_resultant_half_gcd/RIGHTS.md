# Provenance and reuse

The [Library Checker proposal](https://github.com/yosupo06/library-checker-problems/issues/1407)
was used to identify a resultant workload; it is an idea index, not a source
of copied problem text, implementation code, or fixtures. The mathematical
half-GCD and resultant recurrences are described in [FLINT's algorithm
overview](https://flintlib.org/doc/algorithms/polynomials/half-gcd.html) and
in the [computer algebra notes](https://perso.ens-lyon.fr/bruno.salvy/data/poly-CA.pdf).
The implementations, input contract, references, and cases in this package
were written for this repository from the mathematical descriptions. No
third-party source code, problem statement, or test fixtures are incorporated.
