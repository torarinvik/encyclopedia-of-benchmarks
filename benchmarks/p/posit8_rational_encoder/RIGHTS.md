# Rights and provenance

This package contains clean-room implementations of the posit8 rational
rounding procedure. The source references define the number format and
rounding semantics; the native ports, Python references, and workload were
written independently for this repository. No source implementation, task
description text, source example, or source test was copied.

Normative algorithm source:

- Posit Standard (2022), §§3.2–3.3 and 4.1: <https://posithub.org/docs/posit_standard-2.pdf>
- Gustafson and Yonemoto, “Beating Floating Point at its Own Game: Posit Arithmetic” (2017), DOI <https://doi.org/10.14529/jsfi170206>
