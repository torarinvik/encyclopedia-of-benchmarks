# Rights and provenance

This package is a clean-room bounded implementation of the radix
priority-search-tree algorithm described by Edward M. McCreight in
“Priority Search Trees,” *SIAM Journal on Computing* 14(2), 1985,
[DOI 10.1137/0214021](https://doi.org/10.1137/0214021).

The paper is used as an algorithmic reference. This package does not copy its
source code, prose, figures, or examples. The workload, bounded input/output
contract, tie policy, references, and language ports were authored
independently. Consult SIAM and the paper's hosting page for the source
document's rights and permissions.
