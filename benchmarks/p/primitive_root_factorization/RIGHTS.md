# Rights and provenance

The ports, contract, fixtures, documentation, and oracle implementations were
authored independently. The source consulted was the algorithm description in
[CP-Algorithms' Primitive Root article](https://cp-algorithms.com/algebra/primitive-root.html),
which is published under CC BY-SA 4.0. It describes factoring the group order
and testing candidate orders with modular exponentiation. No source code,
examples, or prose were copied.
