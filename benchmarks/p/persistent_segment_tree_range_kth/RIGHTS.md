# Rights and provenance

The algorithm was selected from CP-Algorithms' “Segment Tree” article, in the
section on finding the k-th smallest value in a range:

- https://cp-algorithms.com/data_structures/segment_tree.html

CP-Algorithms text is licensed CC BY-SA 4.0. This package uses only the
high-level algorithm description: path-copy the frequency tree for each input
prefix, then descend the difference of the roots bracketing a query interval.
All contract text, fixtures, oracles, and ten language implementations here
were written independently; no source code or examples were copied.
