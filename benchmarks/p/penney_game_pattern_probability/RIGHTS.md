# Rights and provenance

This package contains clean-room implementations of a bounded probability calculation for which of two equal-length binary patterns first appears in a fair-coin stream. The input contract, references, fixtures, native ports, and documentation were independently authored. No Rosetta task text, code, examples, or tests were copied or adapted.

Brofos, [“A Markov Chain Analysis of a Pattern Matching Coin Game”](https://arxiv.org/abs/1406.2212), is cited for mathematical method context. The pinned [RosettaCodeData popular-task index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks) was used only to discover the title `Penneys-game` and its popularity score of 49; it was not used as an implementation or specification source.
