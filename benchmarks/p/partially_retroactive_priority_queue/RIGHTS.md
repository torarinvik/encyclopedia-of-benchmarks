# Rights and provenance

The discovery source is the open Library Checker proposal
[Partially Retroactive Priority Queue, PR #1411](https://github.com/yosupo06/library-checker-problems/pull/1411),
derived from [issue #1213](https://github.com/yosupo06/library-checker-problems/issues/1213).
The task and method notes are pinned to commit
`494ddf7a14d6e49759047a270aa37a1302592cbc` in the upstream repository.
The repository is distributed under Apache-2.0. This package uses only its
algorithm idea, public operation contract, and parameter metadata; it does not
copy source code, statements, examples, tests, or generated inputs.

The method's primary reference is Erik D. Demaine, John Iacono, and Stefan
Langerman, “Retroactive Data Structures,” ACM Transactions on Algorithms,
3(2), 2007, [DOI 10.1145/1240233.1240236](https://doi.org/10.1145/1240233.1240236).
The ten language ports, references, fixtures, and prose in this directory are
new clean-room work. No third-party implementation code is included.
