# Rights and provenance

This package is an independently written bounded implementation of the
Frequency Count list-update algorithm described by Shahin Kamali in “Online
List Update,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_266. The chapter is used only for algorithm
attribution. No book prose, figures, or code were copied. These clean-room
implementations are subject to the repository terms.
