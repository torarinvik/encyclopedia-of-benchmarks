# Rights and provenance

The algorithm source is D. Hugh Redelmeier, “Counting Polyominoes: Yet Another
Attack,” *Discrete Mathematics* 36(2), 191–203 (1981),
[DOI 10.1016/0012-365X(81)90237-5](https://doi.org/10.1016/0012-365X(81)90237-5).
An accessible copy is hosted by the Technion at
[1981-Redelmeier.pdf](https://barequet.cs.technion.ac.il/poly-papers/math-cs/1981-Redelmeier.pdf).
The alternative fixed-shape description is also discussed in
[arXiv:1106.1078](https://arxiv.org/abs/1106.1078).

The ports use a clean-room canonical-growth algorithm, and the independent
reference uses a separately structured restricted fixed-shape traversal.
Only mathematical algorithm ideas are used. No RosettaGit task text, examples,
tests, or code are copied. The cited paper remains subject to its publisher's
rights; this package does not relicense it. Local source and workload files
follow the repository license.
