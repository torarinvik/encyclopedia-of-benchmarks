# Rights and provenance

The algorithmic method is referenced from OI Wiki's
[Fenwick Tree of Segment Trees](https://www.timothywang.ca/OI-wiki/ds/seg-in-bit/)
article. The article describes combining an outer Fenwick decomposition with
weighted value segment trees to support dynamic range order statistics. The
source is published under CC BY-SA 4.0 with an additional SATA notice; consult
the linked page for its current terms.

Only the algorithmic idea and data-structure invariant informed this package.
No source code, article prose, examples, or fixtures were copied. The input
contract, bounded workload, references, and ten implementations were written
for this repository. The dynamic replacement workload differs from the local
static persistent-segment-tree range-k-th profile.
