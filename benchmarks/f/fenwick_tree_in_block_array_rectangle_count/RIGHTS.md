# Rights and provenance

The [OI Wiki Fenwick Tree in Block Array article](https://www.timothywang.ca/OI-wiki/ds/bit-in-block-array/)
describes online rectangle counting for points with unique x-coordinates,
using a Fenwick tree over x-blocks and a value Fenwick tree in each node.
The source page is marked CC BY-SA 4.0 with the SATA additional terms. This
package records that reference and uses the algorithmic idea only; it does not
copy source code, examples, or prose.

The bounded input contract, direct-scan reference, workload, documentation,
and ten language ports were authored for this benchmark suite.
