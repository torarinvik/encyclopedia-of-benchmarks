# Rights and provenance

The package contains new implementations of the Apéry-set method for the
Frobenius number. The mathematical definition and theorem are not source code.
No code, task prose, or fixtures were copied from RosettaCodeData or from the
algorithm references.

RosettaCodeData was used only as a title index. The algorithm description is
based on the published Apéry-set characterization and Frobenius-number formula
by Ramírez Alfonsín and Rødseth (“Numerical Semigroups: Apéry Sets and Hilbert
Series,” *Semigroup Forum* 79(2) (2009), 323–340) and the result of Brauer and
Shockley.

- [Ramírez Alfonsín and Rødseth paper](https://imag.umontpellier.fr/~ramirez/Frobenius-Hilbert.pdf)
- [Ramírez Alfonsín publication record](https://doi.org/10.1007/s00233-009-9133-5)
- [Brauer and Shockley article record](https://doi.org/10.1515/crll.1962.211.215)
- [RosettaCodeData popular-tasks index](https://raw.githubusercontent.com/acmeism/RosettaCodeData/main/popular-tasks)

No third-party implementation or nontrivial code excerpt is included.
