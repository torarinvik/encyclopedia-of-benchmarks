# Rights and provenance

Algorithm provenance: Jittat Fakcharoenphol and Satish Rao, “Planar graphs,
negative weight edges, shortest paths, and near linear time,” *Journal of
Computer and System Sciences* 72 (2006), 868–889,
[DOI 10.1016/j.jcss.2005.05.007](https://doi.org/10.1016/j.jcss.2005.05.007).
The source was consulted for the recursive dense-distance-graph construction,
feasible-potential reweighting, Monge block partition, and online Dijkstra
state machine. The bounded direct-scan data structure is independently
specified here. No paper code, prose, figures, or examples are reproduced.

The Encyclopedia of Algorithms entry is used only to identify the candidate:
Fakcharoenphol and Rao, “Shortest Paths in Planar Graphs with Negative Weight
Edges,” DOI
[10.1007/978-0-387-30162-4_372](https://doi.org/10.1007/978-0-387-30162-4_372).
Recursive decomposition background is attributed to Henzinger, Klein, Rao,
and Subramanian, “Faster Shortest-Path Algorithms for Planar Graphs,” DOI
[10.1006/jcss.1997.1493](https://doi.org/10.1006/jcss.1997.1493).

The bounded workload, primary reference, independent oracle, and language-port
drafts are clean-room work. No source code or task-specific examples were
copied.
