# Rights and provenance

The port sources in this package are newly written clean-room implementations.
No SPLASH-2 source code, comments, constants, or test data were copied. The
package uses the published mathematical fast multipole algorithm and its
high-level distinction from Barnes–Hut, with attribution to the sources below.

The SPLASH-2 repository mirror does not present an explicit software license
in its top-level documentation. No license grant for that source code is
assumed here. This package does not redistribute that code.
