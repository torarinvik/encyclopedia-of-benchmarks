# Rights and provenance

The native ports, references, fixtures, and documentation are original
clean-room work based on the topological algorithm description in Zabran's
CESCG 2018 paper. The paper is cited as method context and is identified as a
non-peer-reviewed proceedings publication. The pinned RosettaCodeData
popular-task index is used only to discover the task title.

No Rosetta task wording, source code, examples, or tests are included. No
third-party implementation or fixture is redistributed.

No program, helper, checker, script, test, build, compiler, profiler, or
benchmark was run to create or validate this package.
