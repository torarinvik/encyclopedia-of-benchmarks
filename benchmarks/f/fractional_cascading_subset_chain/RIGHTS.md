# Rights and provenance

The algorithmic idea is attributed to Bernard Chazelle and Leonidas J. Guibas, “Fractional Cascading: I. A Data Structuring Technique,” *Algorithmica* 1, 133–162 (1986), DOI [10.1007/BF01840440](https://doi.org/10.1007/BF01840440). The companion applications paper is “Fractional Cascading: II. Applications,” *Algorithmica* 1, 163–191 (1986), DOI [10.1007/BF01840441](https://doi.org/10.1007/BF01840441). The authors' [Part I copy](https://www.cs.princeton.edu/~chazelle/pubs/FractionalCascading1.pdf) and [Part II copy](https://www.cs.princeton.edu/~chazelle/pubs/FractionalCascading2.pdf) are public references.

The papers are copyrighted publications. This package contains independently written code for a narrow nested-catalog path profile based on their published algorithmic description. It does not copy code, prose, figures, examples, or test data from either paper, and does not claim to reproduce the general catalog-graph or dynamic algorithms.

This note records algorithm provenance; it is not legal advice.
