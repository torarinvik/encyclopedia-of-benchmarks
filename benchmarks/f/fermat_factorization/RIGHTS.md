# Rights and provenance

The algorithm was identified from the Fermat factorization section of the [CP-Algorithms integer factorization article](https://cp-algorithms.com/algebra/factorization.html#fermats-factorization-method), which is licensed CC BY-SA 4.0. This package uses the mathematical algorithm description and independently defines its bounded input contract, fixtures, and implementations. It does not reproduce upstream code, prose, examples, or problem statements.

All ten language ports and both reference implementations were written for this repository. The independent reference uses bounded divisor enumeration rather than the ports' difference-of-squares scan.
