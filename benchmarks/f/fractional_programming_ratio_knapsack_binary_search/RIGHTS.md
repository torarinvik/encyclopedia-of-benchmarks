This package uses only the
algorithm ideas of binary-searching a ratio threshold, transforming it into an
additive score, and solving a minimum-denominator feasibility instance with
0/1 knapsack. No source code, prose, worked examples, or tests are copied.

The independent subset-enumeration reference, bounded contract, workload,
and ten language ports are independently authored for this repository.
