# Rights and provenance

The Codewars kata title is an idea-index lead only. No task statement, tests,
examples, submissions, or code were used. Codewars authoring guidance is
available at <https://docs.codewars.com/authoring/guidelines/kata/>.

Pollack and Treviño's paper provides mathematical context for Lagrange's
four-square theorem and constructive representations:
<https://pollack.uga.edu/finding4squares.pdf>. This package uses only the
theorem and independently specified bounded enumeration; it does not reuse
paper code, wording, examples, or test material.

The benchmark package contents are clean-room original descriptions,
implementations, and fixtures.
