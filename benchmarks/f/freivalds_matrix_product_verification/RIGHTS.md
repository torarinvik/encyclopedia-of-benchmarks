# Source and rights note

Source: Rūsiņš Freivalds, “Fast Probabilistic Algorithms,” in *Mathematical
Foundations of Computer Science 1979*, Lecture Notes in Computer Science 74,
pp. 57–69, DOI 10.1007/3-540-09526-8_5.

This package independently implements the matrix-product verification trace
from the paper's Section 3 on bounded exact integer inputs. It uses supplied
sign vectors and makes no probability claim for a fixed trace. No source code,
prose, examples, figures, or test data are copied.
