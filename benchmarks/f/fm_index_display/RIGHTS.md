# Rights and attribution

This is an independently written, clean-room bounded implementation of the
FM-index substring-display procedure described in Veli Mäkinen and Gonzalo
Navarro, “Compressed Text Indexing,” *Encyclopedia of Algorithms* (2016), DOI
10.1007/978-1-4939-2864-4_83. The copyrighted chapter grants no source-code
license. This package contains no copied chapter prose, figures, or code.
