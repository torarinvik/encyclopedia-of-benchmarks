# Rights and provenance

This package is an independently written bounded implementation of the KMP
`Jump`/`Output` compressed-pattern-matching recurrence described in Masayuki
Takeda and Ayumi Shinohara, “Pattern Matching on Compressed Text,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_81. The chapter is
used for algorithm attribution, not as a source-code license. No book prose,
figures, or code were copied. These clean-room implementations are subject to
the repository terms.
