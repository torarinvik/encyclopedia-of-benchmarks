# Rights and provenance

This package is an independently written bounded implementation of the
nonadaptive stochastic-knapsack greedy rule described by Viswanath Nagarajan
in “Stochastic Knapsack,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_537. The chapter is attribution, not a code license.
No book text, figures, or code were copied. Repository code remains subject to
applicable repository terms.
