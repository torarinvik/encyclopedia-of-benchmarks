# Rights and provenance

The KmpSkip Search algorithm was developed by Christian Charras, Thierry
Lecroq, and Joseph D. Pehoushek. The package uses the algorithm descriptions
in [Lecroq's reference](https://igm.univ-mlv.fr/~lecroq/string/node32.html)
and their [1998 paper](https://doi.org/10.1007/BFb0030780), with the NIST
[DADS entry](https://xlinux.nist.gov/dads/HTML/kmpskipsrch.html) serving as an
index and source pointer. Only the algorithm idea was consulted. No source
code, prose, example, or fixture was copied; all benchmark code, contract,
documentation, and workload data here are independently authored. The
algorithm is not claimed as original.
