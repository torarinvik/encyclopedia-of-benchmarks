# Rights and provenance

The LeetCode public title was used only to discover the algorithm family. No challenge statement, examples, tests, submissions, editorial, or site code is reproduced.

The mathematical idea is the Mahonian inversion distribution. The package's contract, recurrence implementation, direct coefficient-expansion reference, factorial helper, and fixtures are independently authored from the mathematical descriptions in Knuth, *The Art of Computer Programming*, volume 3, section 5.1.1, and [OEIS A008302](https://oeis.org/A008302). No source implementation was copied. See the repository-level license for this package's original code.
