# Provenance and rights

The k²-tree was discovered through the NIST Dictionary of Algorithms and Data
Structures entry:
<https://xlinux.nist.gov/dads/HTML/k2tree.html>. The structural description
and navigation rule are cross-referenced with Nieves R. Brisaboa, Susana
Ladra, and Gonzalo Navarro, “k²-trees for Compact Web Graph Representation”
(SPIRE 2009):
<https://lbd.udc.es/Repository/Publications/Drafts/K2treforCom.pdf>.

These sources provide algorithm provenance and terminology. The bounded row
mask contract, packed bitmaps, fixtures, Python references, and ten language
ports are independently written; no source code, article prose, or published
example is copied. Licenses for the cited paper and NIST entry are not
reassigned to this package.
