# Rights and provenance

This package is a clean-room implementation of the MaxCliqueDyn algorithm
profile. It does not copy source code, pseudocode, examples, or prose from
KACTL or the paper. It uses the mathematical ideas described by Konc and
Janežič in [their 2007 paper](https://insilab.org/articles/match2007.pdf) and
KACTL's public [`MaximumClique.h` description](https://github.com/kth-competitive-programming/kactl/blob/main/content/graph/MaximumClique.h)
to identify and distinguish the algorithm.

KACTL labels its header GPL-3.0-or-later. No KACTL implementation text is
used in this package. The source paper remains under its publisher's terms;
only the algorithmic method is summarized here. Workload data is hand-derived
from small graphs and contains no copied problem statement or fixture text.
