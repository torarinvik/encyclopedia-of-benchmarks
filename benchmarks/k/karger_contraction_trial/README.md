# Karger contraction cut trial

This in-progress benchmark executes one contraction trial on a connected undirected multigraph. It returns the number of original edges crossing the two surviving supervertices. A particular trial need not find the global minimum cut.

The `i64_array_scalar` input is `[n,m,(u,v)*m,ranks*(n-2)]`, where `2<=n<=8`, `1<=m<=24`, vertices are in `0..n-1`, loops are invalid, and parallel edges are allowed. The graph must be connected. At each step, scan original edges in input order, retain those whose endpoints are in distinct current supervertices, and select the zero-based `rank` among them. A negative or out-of-range rank makes the whole input invalid. Contract the selected endpoints, retaining parallel edges and discarding self-loops for future selections. Exactly `n-2` ranks are required. Success returns the final cut size in `1..24`; malformed or null input returns -1. Maximum valid and parseable input lengths are 56 and 57 i64 words.

The rank tape makes a single trial reproducible; it does not imply a probability distribution or guarantee a minimum cut. Uniformly random valid ranks in independent trials would model the randomized edge choices of Karger's algorithm. A bounded disjoint-set representation with repeated edge scans takes O(n*m*n) time with uncompressed parent paths and O(n+m) storage.

This is distinct from the [`randomized_contraction_edge_sampling`](../../r/randomized_contraction_edge_sampling/README.md) phase, which contracts a supplied subset simultaneously, and [`stoer_wagner`](../../s/stoer_wagner/README.md), which computes an exact global minimum cut by a different deterministic method. The mathematical method comes from [Karger's work](https://people.csail.mit.edu/karger/Papers/contract.pdf); no source code or text is copied. The primary oracle validates and replays using disjoint sets; the independent reference validates connectivity by traversal and replays using component labels. Drafts are present for all ten languages, with a workload, package checker, and scalar suite wiring. Nothing has been run; integration and implementations need verification.

The scalar verifier includes all nonempty simple graphs up to four vertices with bounded rank tapes, plus malformed, null, and maximum-size cases. The package checker confirms source paths and symbol names, workload metadata, and fixture agreement with both calculations; it does not compile implementations. These checks are written but have not been run.
