# Rights and provenance

The k-ary operation was discovered and specified from Paul E. Black’s NIST
Dictionary of Algorithms and Data Structures entry, [“k-ary Huffman
coding”](https://xlinux.nist.gov/dads/HTML/karyHuffman.html). The entry
describes joining k lowest-frequency trees and using k symbols per code
level. The binary method’s historical attribution is David A. Huffman,
[“A Method for the Construction of Minimum-Redundancy Codes,”
*Proceedings of the IRE* 40(9), 1098–1101 (1952)](https://doi.org/10.1109/JRPROC.1952.273898).

The cited materials were consulted for algorithm semantics and attribution.
No license grant for their prose or published code was identified. No code,
comments, prose, examples, or fixtures were copied. The domain is deliberately
restricted to full-tree-compatible symbol counts; it adds no padding symbols.
The ten ports, references, and fixtures are independently authored from the
bounded mathematical contract.
