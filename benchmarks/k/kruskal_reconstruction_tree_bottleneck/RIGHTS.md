# Rights and provenance

This benchmark is a clean-room implementation of the Kruskal reconstruction
tree and its bottleneck-query property described in the [OI Wiki minimum
spanning-tree chapter](https://oi-wiki.org/graph/mst/#kruskal-%E9%87%8D%E6%9E%84%E6%A0%91),
with Kruskal's method cross-referenced against Carnegie Mellon's [algorithm-design
lecture notes](https://www.cs.cmu.edu/~yangp/15-451/lecture12.pdf). Only
mathematical algorithm descriptions were consulted. No source code, examples,
problem statements, fixtures, or prose were copied. The bounded contract,
references, workload, and language ports are independently authored.
