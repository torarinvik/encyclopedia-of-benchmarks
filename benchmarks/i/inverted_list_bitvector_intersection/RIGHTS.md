“Intersections of Inverted Lists,” in *Encyclopedia of Algorithms*, chapter
DOI [10.1007/978-1-4939-2864-4_628](https://doi.org/10.1007/978-1-4939-2864-4_628).
The chapter is copyright Springer Science+Business Media New York (2016). It
was consulted for algorithm discovery and its high-level bitvector procedure
only. No chapter prose, figure, example, or implementation code is reproduced.

The ten ports, bounded contract, workload, and two references are independently
written from the mathematical operation: AND corresponding words of all query
bitvectors and enumerate set positions in ascending domain order. Existing
sorted-array intersection packages were used only for local duplicate review;
their code and fixtures are not copied.
