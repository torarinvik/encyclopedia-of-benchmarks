# Rights and provenance

The interval-heap algorithm is attributed to Jan van Leeuwen and Derick Wood. The package is a clean-room implementation of the published data-structure idea and operation behavior. It contains newly written language ports, workload cases, and oracle code; it does not reproduce upstream source code, comments, source prose, or fixtures.

The primary article is “Interval Heaps,” *The Computer Journal* 36(3), 209–216 (1993), DOI [10.1093/comjnl/36.3.209](https://doi.org/10.1093/comjnl/36.3.209). The primary-author technical report [CS-1987/1987-01](https://ics-archive.science.uu.nl/research/techreps/repo/CS-1987/1987-01.pdf) supplies the accessible detailed definition and operation discussion. No separate license for the article/report was identified; only algorithmic behavior and attribution are used.

NIST DADS is cited as a discovery/index source. The modern [interval-heap pseudocode page](https://algorithm.tamnd.com/interval-heap/) is a behavior cross-check only; neither its implementation nor its sample traces are reused.
