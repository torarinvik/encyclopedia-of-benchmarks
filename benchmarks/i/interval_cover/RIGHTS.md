# Rights and provenance

This package is a clean-room implementation of greedy interval covering. The
algorithm was identified from KACTL's public content index and cross-checked
against the interval-covering description in NYU's CSCI-UA.0380 class notes.
No third-party code, prose, examples, or tests are
copied.

- KACTL, [IntervalCover entry](https://github.com/kth-competitive-programming/kactl/blob/main/content/various/IntervalCover.h)
  and [various chapter index](https://raw.githubusercontent.com/kth-competitive-programming/kactl/main/content/various/chapter.tex).
- Sean McIntyre, NYU CSCI-UA.0380, [Class 04: Greedy and Binary Search](https://cs.nyu.edu/courses/summer13/CSCI-UA.0380-001/slides/Class05.pdf).

The bounded input contract, fixtures, exhaustive-subset oracle, and ten
language ports were authored for this repository. No third-party code or data
is bundled.
