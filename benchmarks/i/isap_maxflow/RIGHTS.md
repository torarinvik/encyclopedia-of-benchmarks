# Rights and provenance

The ISAP algorithm selection and high-level description are based on the ISAP section of [OI Wiki, Maximum Flow](https://oi-wiki.org/graph/flow/max-flow/#isap). OI Wiki content is published under CC BY-SA 4.0 and SATA. This package records that source as provenance for the algorithm idea and uses no source code, sample input, tests, or copied explanatory prose from it.

All implementation files, workload fixtures, and oracle code in this package were written independently for this benchmark. The independent oracle enumerates directed cuts and does not implement ISAP.
