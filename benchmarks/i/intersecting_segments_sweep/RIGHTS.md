[CP-Algorithms, “Search for a pair of intersecting segments”](https://cp-algorithms.com/geometry/intersecting_segments.html).

package uses the geometric sweep idea only; it does not copy source code,
prose, figures, or source examples. The bounded input contract, exact integer
predicates, array-backed status list, references, workload, and language ports
