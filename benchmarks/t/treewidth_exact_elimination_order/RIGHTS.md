# Rights and attribution

This package is a clean-room implementation of exact treewidth minimization via the elimination-order characterization in Hans L. Bodlaender, “Treewidth of Graphs,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_431`.

The chapter and cited papers remain copyrighted. This package asserts no license to redistribute their text, figures, or implementations; it contains no copied code or prose. Its exhaustive enumeration is explicitly bounded to eight vertices and does not claim to implement the cited Fomin–Villanger algorithm. Retain the bibliographic attribution above when redistributing this package.
