# Source and rights note

The source is Samir Khuller and B. Raghavachari, “Improved Approximation
Algorithms for Uniform Connectivity Problems,”
§3.1: <https://www.cs.du.edu/~snarayan/sada/research/docs/p1-khuller.pdf>.

This package independently implements a bounded `k=3` version from the
published algorithm description. It does not copy code, prose, figures,
examples, or test data. The root, input-record order, and tie rules are local
deterministic profile choices.
