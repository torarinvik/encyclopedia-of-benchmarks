# Source and reuse

The [CP-Algorithms Hungarian article](https://cp-algorithms.com/graph/hungarian-algorithm.html)
provides a weighted tree-coloring lead. Its text is licensed under CC BY-SA 4.0.
This package independently specifies ordinary proper coloring and its tree DP;
no external text, code or fixtures are copied. The article's suggested
sibling-distinct assignment is not used for this contract.
