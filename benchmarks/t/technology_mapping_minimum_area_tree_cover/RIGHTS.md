# Source and rights

This package is a clean-room implementation of the minimum-area tree-covering dynamic program described by Kurt Keutzer and Kaushik Ravindran, “Technology Mapping,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_420`.

The chapter and cited papers remain copyrighted. No source code, prose, or figures are copied, and no upstream source-code license is asserted. The package uses a bounded, explicitly supplied gate tree and pattern-cost library. Preserve the bibliographic attribution above when redistributing this benchmark.
