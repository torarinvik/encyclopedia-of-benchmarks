# Source and reuse

The [tree path-cover research paper](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/5F80A57D0F4918546ECDFFC4E32E874B/S1446181100013894a.pdf/div-class-title-optimal-hamiltonian-completions-and-path-covers-for-trees-and-a-reduction-to-maximum-flow-div.pdf)
studies vertex-disjoint path covers of trees. This package uses the
mathematical problem only. Its degree-two dynamic program, contract, code,
and fixtures are independently authored; no source text or code is copied.
