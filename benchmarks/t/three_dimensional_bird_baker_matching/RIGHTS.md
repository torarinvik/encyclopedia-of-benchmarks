# Rights and provenance

The algorithm description comes from *Encyclopedia of Algorithms*, Chapter
247, “Multidimensional String Matching,” which attributes the 2D row-marking
and KMP method to Bird and Baker and describes repeated reduction for higher
dimensions.

All package code, ten language ports, the bounded 3D contract, independent
references, workload fixtures, and serialization choices are clean-room work.
Only the algorithm description was used. No source code, prose, examples,
figures, or test data were copied. No license or permission for the book's
content is asserted.
