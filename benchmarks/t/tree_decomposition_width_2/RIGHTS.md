# Rights and provenance

The input/output contract and official maximum limits are adapted from the
`tree_decomposition_width_2` task in `yosupo06/library-checker-problems`.
That repository is licensed under Apache-2.0. The task statement and limits
are linked in the package README and workload metadata.

All benchmark ports, the primary oracle, and the certificate checker are
clean-room implementations from the task definition and the standard
degree-at-most-two elimination characterization of partial 2-trees. No
upstream source code or test-generator code is included.
