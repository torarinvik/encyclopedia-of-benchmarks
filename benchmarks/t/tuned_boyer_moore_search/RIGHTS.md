# Rights and provenance

This benchmark independently implements the Tuned Boyer–Moore search
algorithm described by Andrew Hume and Daniel Sunday in [“Fast String
Searching”](https://doi.org/10.1002/spe.4380211105), *Software: Practice and
Experience* 21(11), 1991, pp. 1221–1248. The ESMAJ [Tuned Boyer–Moore
description](https://igm.univ-mlv.fr/~lecroq/string/tunedbm.html) specifies
the sentinel-based three-shift loop, and its [Boyer–Moore
description](https://igm.univ-mlv.fr/~lecroq/string/node14.html) describes
the bad-character table.

Only algorithm descriptions and bibliographic details are used. No source
code, examples, prose, or test data were copied. The bounded contract,
workload, references, and ten language ports are independently authored for
this repository.
