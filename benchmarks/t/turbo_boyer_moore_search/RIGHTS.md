# Rights and provenance

The benchmark implements the Turbo Boyer–Moore algorithm described by
Crochemore, Czumaj, Gąsieniec, Jarominek, Lecroq, Plandowski, and Rytter in
[“Speeding Up Two String-Matching Algorithms”](https://doi.org/10.1007/BF01185427),
*Algorithmica* 12(4/5), 1994, pp. 247–267. The ESMAJ [Turbo-BM description](https://igm.univ-mlv.fr/~lecroq/string/node15.html)
and [Boyer–Moore preprocessing description](https://igm.univ-mlv.fr/~lecroq/string/node14.html)
provide the state and table definitions.

Only algorithm descriptions are used. No ESMAJ code, prose, examples, or test
data were copied. The bounded contract, workload, references, and all ten
language ports are independently authored for this repository.
