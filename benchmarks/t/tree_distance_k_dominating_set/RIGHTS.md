# Source and reuse

The [distance-k tree-domination paper](https://ftp.gwdg.de/pub/misc/EMIS/journals/JGAA/accepted/2015/TurauKoehler2015.19.1.pdf)
describes the sequential greedy method and its optimality as well as a
distributed method. This package independently authors its contract, source and fixtures; no paper text, code or
examples are copied, and the distributed protocol is not reproduced.
