# Rights and provenance

The algorithmic source is Mucha and Sankowski, “Maximum Matchings via
Gaussian Elimination,” FOCS 2004, §3 Algorithm 2, DOI
[`10.1109/FOCS.2004.40`](https://doi.org/10.1109/FOCS.2004.40). The
Encyclopedia crosswalk is Marcin Mucha, “Maximum Matching,” Chapter 225, DOI
[`10.1007/978-1-4939-2864-4_225`](https://doi.org/10.1007/978-1-4939-2864-4_225).

The bounded code, references, fixtures, and docs were independently authored
for this repository. The paper supplies the algorithmic ideas and matrix
identities; no source code, examples, tests, figures, or expressive prose were
copied. The independent reference uses recursive determinant/cofactor
expansion rather than the primary's modular inverse and elimination updates.
