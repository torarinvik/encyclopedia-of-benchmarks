# Source and rights note

The algorithm source is Deıneko, Hoffmann, Okamoto, and Woeginger, “The
Traveling Salesman Problem with Few Inner Points,” §4, available at
<https://dopal.cs.uec.ac.jp/okamotoy/PDF/2006/FINALfewTSP.pdf> and included in
the *Encyclopedia of Algorithms*, Chapter 426.

The implementation is a clean-room bounded profile based on the published
recurrence. No source code, prose, figures, or test data were copied. Hull
order, deterministic fixed-point edge rounding, and ABI framing are explicit
local profile choices.
