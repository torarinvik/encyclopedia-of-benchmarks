# Turnstile one-sparse fingerprint recovery

This in-progress profile maintains a linear fingerprint of signed coordinate updates and applies a singleton-recovery test. It is the one-sparse primitive described in [Cormode and Firmani's framework](https://dimacs.rutgers.edu/~graham/pubs/papers/l0journal.pdf), not a complete ℓ0 sampler or a dynamic-connectivity sketch. The paper is used for the mathematical method only; no source code, prose, or fixtures are copied.

The `i64_array_scalar` input is `[N,Q,z,(index,delta)*Q]`. `1<=N<=64`, `0<=Q<=128`, `1<=z<1000000007`, each index is in `0..N-1`, and each signed delta is in `[-1000,1000]`. Exact length is `3+2Q`: maximum valid and parseable lengths are 259 and 260 words. Null or malformed input returns `-1`.

Initialize `mass = weighted = fingerprint = 0`. For each update `(i,d)`, add `d` to `mass`, add `d*i` to `weighted`, and add `d*z^i` modulo prime `1000000007` to `fingerprint`. At the end, return `i+1` when `mass != 0`, `weighted` is exactly divisible by `mass`, the quotient `i` is in `0..N-1`, and the fingerprint equals `mass*z^i` modulo the prime. Otherwise return `0` (no candidate). Signed modular residues are normalized to `0..p-1`. The encoded positive result avoids ambiguity between candidate index zero and no candidate.

These conditions accept every nonzero one-sparse vector but can accept a multi-sparse vector through a fingerprint collision. The caller supplies a deterministic base; this profile makes no randomness, uniformity, or failure-probability guarantee. In particular, zero total mass yields no candidate even if the vector is nonzero. Input bounds keep exact sums in signed 64-bit range. With modular exponentiation per update the time is `O(Q log N)` and auxiliary storage is `O(1)`; precomputed powers are a valid `O(N+Q)` variant only if the measured contract explicitly chooses that variant.

The primary oracle replays the three linear accumulators. The reference reconstructs the bounded vector and recomputes the three sums from final coordinates. Both model the fingerprint test, including false positives, rather than replacing it with exact support inspection. Drafts are present in all ten languages, and a workload covers signed updates, cancellation, rejection, malformed input, null pointers at zero and maximum parseable lengths, and a deliberate base-one collision. A package checker and scalar-suite wiring are written. Nothing has been run; all integration and ports require verification.
