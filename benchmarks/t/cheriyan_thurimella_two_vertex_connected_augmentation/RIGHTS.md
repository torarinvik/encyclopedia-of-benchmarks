# Source and rights note

The source is Joseph Cheriyan and Ramakrishna Thurimella, “Approximating
Minimum-Size k-Connected Spanning Subgraphs via Matching,” SIAM Journal on
Computing 30(2), 528–560 (2000), §3.1:
<https://www.cs.du.edu/~ramki/papers/spanSubgraphs.pdf>.

This package independently implements the mathematical procedure with a
small deterministic contract. It does not copy source code, prose, figures,
examples, or test data. The input edge order, bounded matching tie rule, and
output representation are profile choices documented in the package guide.
