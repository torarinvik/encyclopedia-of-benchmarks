# Rights and provenance

This package is a clean-room implementation of the ternary search trie
algorithm described in Section 5.2 of Algorithms, 4th Edition. The published
algs4 Java repository identifies its code as GPLv3; no Java source, book prose,
tests, or fixtures were copied. The local ports, oracles, and workload were
written independently from the algorithm description. The upstream license
does not apply to this independently authored package. Repository terms
continue to govern these files.
