This package is an independently written implementation of the minimum-degree elimination heuristic described in Hans L. Bodlaender, “Treewidth of Graphs,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_431`.

The chapter and cited papers remain copyrighted; this package asserts no license to redistribute their text, figures, or implementations. Its nine ports use no copied source code or extended prose and implement only the stated mathematical heuristic with documented deterministic tie rules.
