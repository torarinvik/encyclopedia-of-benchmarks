# Rights and provenance

This package is an independently written, bounded implementation of the
time-dependent earliest-arrival shortest-path model described in Riko Jacob,
“Shortest Paths Approaches for Timetable Information,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_371. The chapter is used for
algorithm attribution, not as a source-code license. No book prose, figures,
or code were copied. These clean-room implementations are subject to the
repository terms.
