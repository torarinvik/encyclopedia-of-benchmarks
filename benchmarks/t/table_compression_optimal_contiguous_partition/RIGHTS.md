# Rights and attribution

This package is an independently written implementation of the contiguous table-partition dynamic program described in Raffaele Giancarlo and Adam L. Buchsbaum, “Table Compression,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_418`. The chapter summarizes the 2003 work of Buchsbaum, Fowler, and Giancarlo.

The chapter and cited works are copyrighted; no license to redistribute their prose, figures, or implementations is asserted. The package contains no copied code or extended prose. It instantiates the source's parameterized compressor cost with a clearly specified byte-pair RLE codec and implements the mathematical recurrence clean-room. Retain the bibliographic attribution above when redistributing this package.
