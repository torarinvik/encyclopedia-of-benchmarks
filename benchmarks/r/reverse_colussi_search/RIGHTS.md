# Rights and provenance

Reverse Colussi was developed by Luigi Colussi. The package uses the
algorithm description in [Lecroq's reference](https://igm.univ-mlv.fr/~lecroq/string/node17.html),
which cites “Fastest pattern matching in strings,” *Journal of Algorithms*
16(2), 163–189 (1994). The source was consulted for the algorithm idea only.
No source code, prose, examples, or fixtures were copied. The benchmark code,
contract, workload, and documentation are independently authored; the
algorithm is not claimed as original.
