# Rights and clean-room implementation

The references in the README describe the S-ARD algorithm and its mathematical
properties. This package contains a new bounded implementation and newly
constructed fixtures. No upstream implementation, code, or benchmark instance
was copied. The primary and independent references are included for local
workload review and are not part of the benchmarked language ports.

Primary source: Shekhovtsov and Hlaváč, “A Distributed Mincut/Maxflow Algorithm
Combining Path Augmentation and Push-Relabel,” linked in the README. This record
documents provenance; it does not claim ownership of the paper's method or text.
