# Provenance and rights

The algorithm is based on Construction A' in Joseph B. Kruskal, Jr., “On the
Shortest Spanning Subtree of a Graph and the Traveling Salesman Problem,”
*Proceedings of the American Mathematical Society* 7(1), 48–50 (1956). The
paper's public scan is hosted by Yale at
<https://www.cs.yale.edu/homes/lans/readings/routing/kruskal-1956.pdf>. The
NIST Dictionary of Algorithms and Data Structures [minimum spanning tree
entry](https://xlinux.nist.gov/dads/HTML/minimumSpanningTree.html) and the
Codewars [“Make a spanning tree” title](https://www.codewars.com/kata/5ae8e14c1839f14b2c00007a)
were used as index/discovery sources only. No Codewars task wording, examples,
tests, submissions, or code informed the profile. Kleinberg and Tardos,
*Algorithm Design*, §4.5,
provide an independent description at
<https://www.cs.princeton.edu/~wayne/kleinberg-tardos/pdf/04GreedyAlgorithmsII.pdf>.

The source descriptions inform the descending-edge deletion rule. The input
contract, deterministic tie rule, references, fixtures, and ten native ports
were authored independently. No source code, prose, examples, or tests were
copied. The original paper's license was not identified; it is cited for
algorithm provenance only.
