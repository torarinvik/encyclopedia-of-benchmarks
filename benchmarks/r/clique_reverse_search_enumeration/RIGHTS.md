# Rights and provenance

This package is an independently written bounded implementation of the
clique reverse-search example described by Masashi Kiyomi in “Reverse Search;
Enumeration Algorithms,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_731. The chapter is used only for algorithm
attribution and the mathematical parent rule. No book prose, figures, or code
were copied. These clean-room implementations are subject to the repository
terms.
