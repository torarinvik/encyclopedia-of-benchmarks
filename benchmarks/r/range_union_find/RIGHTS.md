# Rights and provenance

The package's algorithmic source is Nyaan's [range-union-find.hpp](https://github.com/NyaanNyaan/library/blob/master/data-structure/range-union-find.hpp). The repository is distributed under [CC0 1.0](https://github.com/NyaanNyaan/library/blob/master/LICENSE). This benchmark uses only the high-level right-boundary DSU invariant and operation semantics. No upstream source code, comments, prose, examples, or tests were copied.

All ten ports, both oracles, workload values, and documentation were independently authored. The primary oracle uses component right boundaries; the independent oracle uses explicit adjacency sets and breadth-first search.
