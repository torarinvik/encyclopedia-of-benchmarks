# Rights and provenance

This package is an independently written bounded implementation of the
permutation reverse-search algorithm described by Katsuhisa Yamanaka in
“Permutation Enumeration,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_735. The chapter is used only for algorithm
attribution and mathematical rules. No book prose, figures, or code were
copied. These clean-room implementations are subject to the repository terms.
