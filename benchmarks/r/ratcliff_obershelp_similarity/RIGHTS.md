# Rights and provenance

The Ratcliff/Obershelp method is specified from the NIST DADS definition and
Ratcliff and Metzener's article, both cited in the README and workload. The
article's algorithm description was used; its assembly and C example code were
not copied. The input contract, deterministic tie rule, reference
implementations, language ports, and fixtures are original bounded benchmark
work.

References:

- [NIST DADS: Ratcliff/Obershelp pattern recognition](https://xlinux.nist.gov/dads/HTML/ratcliffObershelp.html)
- [Ratcliff and Metzener: Pattern Matching: The Gestalt Approach](https://jacobfilipp.com/DrDobbs/articles/DDJ/1988/8807/8807c/8807c.htm)
