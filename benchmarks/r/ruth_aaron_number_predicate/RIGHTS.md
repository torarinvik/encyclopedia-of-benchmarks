# Rights and provenance

This package contains clean-room implementations of a bounded adjacent-integer predicate based on repeated prime-factor sums. The benchmark contract, references, fixtures, ports, and documentation were independently authored; no task code, task prose, examples, or tests were copied.

The mathematical definition and convention are attributed to Eric Weisstein, [“Ruth-Aaron Pair,” MathWorld](https://mathworld.wolfram.com/Ruth-AaronPair.html). The pinned RosettaCodeData popular-task title index was used only to discover the task title, not as an algorithm or code source: https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks.
