# Rights and provenance

This benchmark independently implements the algorithm described by Timo
Raita in [“Tuning the Boyer–Moore–Horspool String Searching Algorithm”](https://doi.org/10.1002/spe.4380221006),
*Software: Practice and Experience* 22(10), 1992, pp. 879–884. ESMAJ's
[Raita algorithm description](https://igm.univ-mlv.fr/~lecroq/string/node22.html)
specifies the comparison order and Horspool shifts. Its [Boyer–Moore
description](https://igm.univ-mlv.fr/~lecroq/string/node14.html) describes
the bad-character preprocessing used by Raita.

Only algorithm descriptions and bibliographic details are used. No source
code, examples, prose, or test data were copied. The contract, workload,
references, and ten language ports are independently authored for this
repository.
