# Rights and provenance

This package is an independently authored bounded implementation of the
Ruf–Schöbel branch-and-bound method for weighted set cover with almost
consecutive ones. Its primary academic source is Nikolaus Ruf and Anita
Schöbel, “Set covering with almost consecutive ones property,” *Discrete
Optimization* 1(2), 215–228 (2004),
[DOI 10.1016/j.disopt.2004.07.002](https://doi.org/10.1016/j.disopt.2004.07.002).
The method is summarized in Michael Dom's *Encyclopedia of Algorithms* entry
368, [DOI 10.1007/978-1-4939-2864-4_368](https://doi.org/10.1007/978-1-4939-2864-4_368).

The sources provide algorithm attribution and mathematical ideas, not a code
license for this package. No source code, figures, examples, or prose have
been copied. The bounded contract, fixtures, references, and language ports
are independently authored and subject to repository terms.
