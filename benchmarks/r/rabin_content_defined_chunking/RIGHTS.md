# Rights and provenance

The profile is independently written from the high-level method described by
the [PARSEC technical report](https://www.cs.princeton.edu/techreports/2010/890.pdf)
and the [USENIX storage study](https://www.usenix.org/legacy/events/usenix04/tech/general/full_papers/policroniades/policroniades_html/index.html).
These publications are cited as algorithm references, not source-code licenses.
No publication text, examples, test data, or code are copied. The four-byte
window and polynomial are choices for this bounded profile.
