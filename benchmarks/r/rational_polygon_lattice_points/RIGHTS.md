# Rights and provenance

The bounded contract and high-level edge-wise floor-sum method are based on
CP-Algorithms, [Lattice points inside non-lattice polygon](https://cp-algorithms.com/geometry/lattice-points.html).
The CP-Algorithms text is available under CC BY-SA 4.0. This package uses the
mathematical algorithm description only; all implementations, references, and
fixtures are independently written for this benchmark. No upstream source code
or prose has been copied.
