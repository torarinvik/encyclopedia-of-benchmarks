# Rights and provenance

This package is an independently written bounded implementation of the
randomized Marking page-caching algorithm described by Neal E. Young in
“Online Paging and Caching,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_267. The chapter is used for algorithm attribution;
no book code, prose, or figures were copied. The supplied choice tape makes
each bounded trace reproducible while leaving the source algorithm's uniform
victim choice set explicit. These clean-room implementations are subject to
the repository terms.
