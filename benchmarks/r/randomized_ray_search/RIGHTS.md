# Rights and provenance

This package is an independently written bounded implementation of the
RaySearch strategy described by Stephen R. Tate in “Randomized Searching on
Rays or the Line,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_328. The chapter is attribution, not a code license.
No book text, figures, or code were copied. Repository code remains subject to
applicable repository terms.
