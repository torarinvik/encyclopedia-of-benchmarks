# Provenance

Rajeev Raman, Venkatesh Raman, and Srinivasa Rao Satti describe the underlying
succinct dictionary in [*Succinct Indexable Dictionaries with Applications to
Encoding k-ary Trees, Prefix Sums and Multisets*](https://arxiv.org/abs/0705.0552).
This bounded block-class profile uses algorithmic ideas only; its code and
contract adaptation are independently written, with no copied source or tests.
