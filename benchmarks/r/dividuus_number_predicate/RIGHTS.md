# Rights and provenance

This package is an independently authored, clean-room implementation of the bounded Dividuus predicate. The contracts, references, fixtures, ports, and documentation were written from mathematical definitions; no external code, task prose, examples, or tests were copied.

[OEIS A118575](https://oeis.org/A118575) supplies the named sequence definition and published examples. The [MathWorld digital-root](https://mathworld.wolfram.com/DigitalRoot.html) and [multiplicative-digital-root](https://mathworld.wolfram.com/MultiplicativeDigitalRoot.html) entries provide component definitions. The pinned RosettaCodeData popular-task index was consulted only for title discovery: https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks.
