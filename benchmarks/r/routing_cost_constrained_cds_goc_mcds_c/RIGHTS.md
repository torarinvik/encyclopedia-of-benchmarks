# Source attribution and rights

This clean-room implementation follows the algorithmic description of
GOC-MCDS-C in “Routing-Cost Constrained Connected Dominating Set,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_621, and the
centralized construction and unique-ID MISI description in H. Du et al.,
“CDS-based virtual backbone construction with guaranteed routing cost in
Wireless Sensor Networks,” DOI 10.1109/TPDS.2012.177. No book or paper prose,
source code, figures, or images are included in this package. The bounded
encoding, deterministic tie rules, workload, and implementations were written
for this repository.
