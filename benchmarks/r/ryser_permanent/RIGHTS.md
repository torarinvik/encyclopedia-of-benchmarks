# Rights and provenance

The package implements mathematical algorithm descriptions independently.
No Rosetta Code task statement, example, test, submission, or implementation
was copied. The public RosettaGit title index was consulted only to discover
the task title “Determinant and permanent.”

The primary method is Ryser's inclusion-exclusion formula, described by Eric
W. Weisstein in [Wolfram MathWorld's Ryser Formula entry](https://mathworld.wolfram.com/RyserFormula.html).
The mathematical permanent definition used by the independent oracle is
described in [MIT lecture notes on computing permanents](https://people.csail.mit.edu/rrw/presentations/DHMTW12final.pdf).
The language ports are clean-room implementations of those algorithm ideas;
no source code or prose from the cited materials is redistributed.
