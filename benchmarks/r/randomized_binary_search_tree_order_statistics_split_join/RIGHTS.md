# Rights and provenance

The randomized binary search tree method is attributed to Martínez and Roura
and cited to their journal article. Its split, join, insertion, and deletion
properties are independently documented in the Archive of Formal Proofs.
Suisen's MIT-licensed Java library README was used only for title/index
discovery. No code, tests, fixtures, task prose, or implementation details
from that library were copied. The ports, references, workload, and package
documentation are original clean-room work.

References:

- [Martínez and Roura, JACM 45(2), DOI 10.1145/274787.274812](https://doi.org/10.1145/274787.274812)
- [Eberl, Archive of Formal Proofs: Randomised Binary Search Trees](https://isa-afp.org/entries/Randomised_BSTs.html)
- [Suisen Java library README](https://github.com/suisen-cp/java_competitive_programming_library) (discovery only)
