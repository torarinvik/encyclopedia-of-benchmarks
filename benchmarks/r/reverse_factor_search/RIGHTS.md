# Rights and provenance

Reverse Factor is a string-matching method described by Maxime Crochemore,
Andrzej Czumaj, Leszek Gasieniec, Stefan Jarominek, Thierry Lecroq,
Wojciech Plandowski, and Wojciech Rytter. This package uses the algorithm description in
[Lecroq's reference](https://igm.univ-mlv.fr/~lecroq/string/node23.html) and
the [1994 analysis](https://doi.org/10.1007/BF01185427) for algorithm ideas
only. No source code, prose, examples, or fixtures were copied. The benchmark
code, contract, workload, and documentation are independently authored; the
algorithm is not claimed as original.
