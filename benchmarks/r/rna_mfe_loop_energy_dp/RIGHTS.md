# Rights and provenance

This package is an independently written bounded implementation of the
minimum-free-energy recurrence described in “RNA Secondary Structure
Prediction by Minimum Free Energy,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_347. The chapter is used for algorithm attribution;
no book code, prose, or figures were copied. The supplied integer loop-energy
table makes scoring deterministic. These clean-room implementations are
subject to the repository terms.
