# Rights and provenance

The rank-maximal matching method is described in Telikepalli Kavitha,
“Ranked Matching,” *Encyclopedia of Algorithms*, Chapter 331
([DOI 10.1007/978-1-4939-2864-4_331](https://doi.org/10.1007/978-1-4939-2864-4_331)),
and Irving, Kavitha, Mehlhorn, Michail, and Paluch, “Rank-maximal matchings,”
*ACM Transactions on Algorithms* 2(4), 602–610 (2006)
([DOI 10.1145/1198513.1198520](https://doi.org/10.1145/1198513.1198520)).

This package uses the high-level per-rank reduced-graph method and the
even/odd/unreachable decomposition. The small bounded profile uses explicit
assignment enumeration as its maximum-matching subroutine. All language
ports, oracle implementations, workload fixtures, and explanatory text were
written independently for this repository. No source code, article prose, or
fixtures were copied; this note attributes the algorithm idea and does not
relicense the cited works.
