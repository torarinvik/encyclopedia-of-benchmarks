# Rights and provenance

This package is an independently authored, bounded implementation of the
strong-C1P weighted set-cover shortest-path algorithm. Its primary source is
Anita Schöbel, “Set covering problems with consecutive ones property,”
Preprint 2005-03, Institute of Numerical and Applied Mathematics, University
of Göttingen:
[author-hosted preprint PDF](https://num.math.uni-goettingen.de/bibi/preprintserie/preprints/schoebel/paper.pdf).
The method also supplies a concrete strong-C1P optimization procedure for
Michael Dom's *Encyclopedia of Algorithms* entry 368:
[DOI 10.1007/978-1-4939-2864-4_368](https://doi.org/10.1007/978-1-4939-2864-4_368).

The sources provide algorithm attribution and mathematical ideas, not a code
license for this package. No source code, examples, figures, or prose have
been copied. The contract, workload, references, and language ports are
independently authored and subject to repository terms.
