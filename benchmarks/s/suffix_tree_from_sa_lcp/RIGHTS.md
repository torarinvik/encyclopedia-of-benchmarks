# Rights and provenance

This package is an independently written bounded implementation of the
suffix-array/LCP rightmost-path suffix-tree construction described by Paolo
Ferragina in “Suffix Tree Construction in Hierarchical Memory,”
*Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_413. The chapter is attribution, not a code license.
No book text, figures, or code were copied. Repository code remains subject to
applicable repository terms.
