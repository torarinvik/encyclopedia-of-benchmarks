# Rights and provenance

The benchmark is an independent implementation of the skew-binomial-queue
algorithm described by Gerth Stølting Brodal and Chris Okasaki in “Optimal
Purely Functional Priority Queues,” *Journal of Functional Programming* 6(6),
1996, [doi:10.1017/S095679680000201X](https://doi.org/10.1017/S095679680000201X).

The article is cited as an algorithmic reference only. No source listing,
benchmark code, fixture text, or prose has been copied. The workload, contract,
and language ports are independently authored. No third-party code is included.
