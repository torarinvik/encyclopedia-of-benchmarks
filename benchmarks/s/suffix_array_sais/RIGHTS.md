# Rights and provenance

SA-IS is attributed to Ge Nong, Sen Zhang, and Wai Hong Chan, “Linear Suffix
Array Construction by Almost Pure Induced-Sorting,” *2009 Data Compression
Conference*, pp. 193–202, DOI
[10.1109/DCC.2009.42](https://doi.org/10.1109/DCC.2009.42). The clean-room
implementation was informed by the algorithm description in that paper and
the [OI Wiki suffix-array chapter](https://oi-wiki.org/string/sa/), which is
licensed CC BY-SA 4.0 with the SATA restriction.

This package uses only the algorithmic ideas and attribution. It does not
reproduce source code, figures, or prose from either source. The ten ports,
bounded contract, workload, and oracles are independently written.
