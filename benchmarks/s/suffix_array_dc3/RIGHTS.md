# Rights and provenance

This package is an independently written bounded implementation of the DC3
suffix-array algorithm summarized in “Suffix Array Construction,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_412. The chapter is
used for algorithm attribution, not as a code license. No book prose, figures,
or code were copied. The implementations in this package are clean-room
benchmark ports; repository terms apply to them.
