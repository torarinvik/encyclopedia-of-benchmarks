# Self-number count sieve

This benchmark counts the positive base-10 self-numbers from 1 through a supplied inclusive endpoint N. For positive x, its digit-addition generator is `g(x) = x + sum_of_base10_digits(x)`. A positive y is a self-number when no positive x has `g(x) = y`.

## Contract

- ABI: `i64_array_scalar`; symbol: `self_number_count_sieve`.
- Input is exactly `[N]`, with `1 <= N <= 100000`. The parseable frame cap is two words so a trailing word is rejected. Null or malformed input returns `-1`.
- Return the count of self-numbers in `[1,N]`; valid results are in `[1,100000]` because 1 is always self.
- The generator domain is positive x. Zero is not a generator.
- The primary initializes a 100001-bit bitmap, marks each in-range `x + digit_sum10(x)`, and counts unmarked values from 1 through N.
- The independent reference tests each y by scanning the complete possible predecessor interval `[max(1,y-9*d),y-1]`, where d is the number of decimal digits in y.

For any generator x of y, `x < y`; because x has at most as many decimal digits as y, `digit_sum10(x) <= 9*d`, so `x >= y-9*d`. The independent interval therefore includes every possible positive generator. At N=100000 the 1563-word bitmap uses 12,504 bytes; scalar state keeps native scratch below the 16,384-byte workspace cap. The primary runs in O(N log10 N) digit operations and O(N) bitmap scanning. The independent reference checks at most `9*d` predecessor values per y, with `d<=6`.

The workload includes the initial A003052 values, the published count of 13 below 100, the generated value 101, and count checkpoints at N=1000, 10000, and 100000 (102, 983, and 9784), plus malformed framing and signed-i64 limits. The sequence source lists the 102nd self-number as 995 and the 103rd as 1006, establishing a count of 102 through 1000; a published self-prime analysis supplies the two larger count cross-checks.

## Distinction from local benchmarks

`lucky_number_sieve` eliminates positions using a changing step schedule. Divisor-count sieves factor values or count divisor contributions. This profile marks values generated by decimal digit addition, `x + sum_digits(x)`, and counts those with no such predecessor.

## Source and provenance

The definition follows Eric Weisstein's [MathWorld “Self Number” entry](https://mathworld.wolfram.com/SelfNumber.html), which identifies a self-number as having no digitaddition generator and gives initial terms. The [CMU ACM self-numbers problem](https://www.cs.cmu.edu/~eugene/teach/acm03/prob/self.html) gives the same generator definition and the count below 100. Numeric sequence cross-checks come from [OEIS A003052](https://oeis.org/A003052), its [term table](https://oeis.org/A003052/b003052.txt), and the counting sequence [A282711](https://oeis.org/A282711); the published [self-number count cross-check](https://www.primepuzzles.net/puzzles/puzz_373.htm) reports counts through 1,000, 10,000, and 100,000. The pinned [RosettaCodeData popular-task index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks) supplied title discovery only. No Rosetta task text, code, examples, or tests were copied.
