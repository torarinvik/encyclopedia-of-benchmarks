# Rights and provenance

This benchmark independently implements the Smith string-search method
described by P. D. Smith in [“Experiments with a very fast substring search
algorithm”](https://doi.org/10.1002/spe.4380211006), *Software: Practice and
Experience* 21(10), 1991, pp. 1065–1074. The ESMAJ [Smith
description](https://igm.univ-mlv.fr/~lecroq/string/node21.html) specifies the
maximum of the Horspool and Quick Search shifts; the ESMAJ [Horspool
description](https://igm.univ-mlv.fr/~lecroq/string/node18.html) and [Quick
Search description](https://igm.univ-mlv.fr/~lecroq/string/node19.html)
describe the component tables.

Only algorithm descriptions and bibliographic details are used. No source
code, examples, prose, or test data were copied. The bounded contract,
workload, independent references, and ten language ports are independently
authored for this repository.
