# Rights and provenance

The package contains original benchmark code, workload data, and explanatory text. The pointer-reversal algorithm follows the public description in [NIST DADS](https://xlinux.nist.gov/dads/HTML/SchorrWaiteGraphMarking.html) and the correctness properties summarized by [Why3/Toccata](https://toccata.gitlabpages.inria.fr/toccata/gallery/schorr_waite.en.html). No implementation code, specification text, problem statement, or fixtures were copied. The algorithm itself is not claimed as original.
