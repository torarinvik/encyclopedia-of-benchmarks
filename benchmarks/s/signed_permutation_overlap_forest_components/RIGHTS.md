# Rights and provenance

The source algorithm is Bader, Moret, and Yan, “A Linear-Time Algorithm for
Computing Inversion Distance between Signed Permutations with an Experimental
Study,” Journal of Computational Biology 8(5), 2001, sections 4–5 and Figure 2,
DOI [10.1089/106652701753216503](https://doi.org/10.1089/106652701753216503).
The Encyclopedia crosswalk is David Bader, “Sorting Signed Permutations by
Reversal (Reversal Distance),” Chapter 383, DOI
[10.1007/978-1-4939-2864-4_383](https://doi.org/10.1007/978-1-4939-2864-4_383).

Only the algorithmic method and bibliographic facts are used. All language
ports, references, fixtures, and docs were authored independently. The
independent reference uses an explicitly materialized overlap graph instead
of the paper's stack-based forest construction. No source implementation,
figure, test, example, or expressive prose is redistributed.
