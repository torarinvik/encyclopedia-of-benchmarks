# Rights and provenance

The source algorithm is Algorithm SUPER2 in David F. Manlove, “Stable
Marriage with Ties and Unacceptable Partners,” University of Glasgow Technical
Report TR-1999-29 ([author-hosted report](https://www.dcs.gla.ac.uk/~davidm/pubs/6497.pdf)).
The Iwama–Miyazaki Encyclopedia entry, [DOI
10.1007/978-1-4939-2864-4_805](https://doi.org/10.1007/978-1-4939-2864-4_805),
was also consulted for algorithm ideas.

No source code, prose, examples, or tests were copied. The bounded input/output
contract, all ten implementations, exhaustive direct-stability oracle,
workload, and package documentation were independently authored.
