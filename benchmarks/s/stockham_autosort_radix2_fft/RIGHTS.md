# Rights and provenance

Algorithm reference: Thomas G. Stockham, Jr., “High-speed convolution and
correlation,” *AFIPS '66 Spring Joint Computer Conference*, pp. 229–233
(1966), [DOI 10.1145/1464182.1464209](https://doi.org/10.1145/1464182.1464209).
The source paper is copyrighted. This package uses the algorithm description
for attribution and does not copy source code, examples, comments, or protected
prose. All implementations and workload fixtures are clean-room bounded
reconstructions of the radix-2 autosort stage mapping.
