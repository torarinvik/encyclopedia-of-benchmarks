# Rights and provenance

The algorithm profile follows the layer-assignment description in Nikola S.
Nikolov, “Sugiyama Algorithm,” *Encyclopedia of Algorithms*, Chapter 649,
DOI 10.1007/978-1-4939-2864-4_649, and its cited longest-path method. The
chapter cites Kurt Mehlhorn, *Data Structures and Algorithms 2: Graph
Algorithms and NP-Completeness* (1984), DOI 10.1007/978-3-642-69897-2. The
operational sink-removal description is also documented in Hoi-Ming Wong,
*Upward Planarization and Layout*, §3.1.2 “Layer Assignment” (2011).

No source-code license is asserted for either reference. The language ports,
references, fixtures, and package prose are clean-room work based on the
algorithm descriptions. The 32-vertex and 128-edge limits, duplicate-edge
rejection, ascending-ID layer order, framing, and error results are bounded
benchmark choices.
