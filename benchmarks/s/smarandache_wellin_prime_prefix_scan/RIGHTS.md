# Rights and provenance

The implementation files in this package are original clean-room benchmark ports. They encode the mathematical operation—forming the base-10 concatenation of the first `k` primes and classifying each bounded prefix as prime—without copying Rosetta Code source, task wording, examples, or tests.

The RosettaCodeData popular-task index at revision `1d475861d7141ef2fafff293d9339f56e4b0f5db` is cited only as the discovery source for the task title. The mathematical definition is sourced from OEIS [A019518](https://oeis.org/A019518), its prime-valued subsequence from [A069151](https://oeis.org/A069151), and the bounded Miller–Rabin base guarantee from Forisek and Jančina, [Theorem 3](https://ceur-ws.org/Vol-1326/020-Forisek.pdf). The fixtures are independently authored from the bounded profile.

No third-party implementation code is incorporated. No program, test, helper, checker, build, compiler, profiler, or benchmark was run to produce or validate these files.
