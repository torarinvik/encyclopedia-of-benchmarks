# Rights and provenance

The algorithm idea is based on Robert W. Irving, “An efficient algorithm for
the stable roommates problem,” *Journal of Algorithms* 6(4), 1985,
https://doi.org/10.1016/0196-6774(85)90033-1. The paper is copyrighted by its
publisher. This package contains no copied source implementation or paper
prose. The benchmark contract, code, oracles, and workload were independently
written from the algorithm description and examples.
