# Rights and provenance

This package implements a new bounded rational pair law and all-pairs
accumulation contract. It does not reproduce SPLASH-2's force field, timestep
integrator, source text, or source code. SPLASH-2 Water-Nsquared is cited only
for the high-level molecular pair-interaction and cutoff workload context.

The 1994 Stanford `interf.C` source carries a non-commercial-use permission and
forbids redistribution of the original software without prior written
permission. No original source file or copied source fragment is included here.
The implementation, oracle, fixtures, and documentation were written
independently.

- [SPLASH-2 paper](https://pages.cs.wisc.edu/~markhill/restricted/isca95_splash2.pdf)
