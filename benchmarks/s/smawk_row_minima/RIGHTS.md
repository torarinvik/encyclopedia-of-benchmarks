# Rights and provenance

The SMAWK matrix-searching algorithm is attributed to Alok Aggarwal, Maria M.
Klawe, Shlomo Moran, Peter Shor, and Robert Wilber, “Geometric applications of
a matrix-searching algorithm,” *Algorithmica* 2, 195–208 (1987),
[DOI 10.1007/BF01840359](https://doi.org/10.1007/BF01840359). The paper is
copyrighted by Springer. This package uses the algorithm description and
citation for discovery and attribution only; it does not reproduce article
text, figures, source code, or example data. The ports, contract, workload, and
oracles are independently written clean-room work.
