# Rights and provenance

This package is an independently written bounded implementation of the
weighted greedy spanner procedure summarized in “Simple Algorithms for
Spanners in Weighted Graphs,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_10. The chapter is used for algorithm attribution,
not as a code license. No book prose, figures, or code were copied. These
clean-room implementations are subject to repository terms.
