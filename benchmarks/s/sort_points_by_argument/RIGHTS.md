# Provenance and rights

The task semantics are based on Library Checker's
[Sort Points by Argument task](https://github.com/yosupo06/library-checker-problems/blob/master/geo/sort_points_by_argument/task.md).
The Library Checker problem repository is licensed Apache-2.0. It is credited
for the task and angle semantics.

Only the task contract informed this package. Its exact comparator, explicit
tie rule, bounded workload, fixtures, oracles, prose, and ten language ports
were independently written. No upstream source code or task prose was copied.
Local artifacts follow this repository's license.
