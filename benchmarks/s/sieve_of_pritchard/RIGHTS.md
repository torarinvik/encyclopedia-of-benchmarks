algorithm name; no task description, code, example, or test was reused. The
implementation and fixtures in this package are original clean-room work.

Algorithm provenance is Paul Pritchard, “A Sublinear Additive Sieve for
Finding Prime Numbers,” *Communications of the ACM* 24(1), 1981,
[doi:10.1145/358527.358540](https://doi.org/10.1145/358527.358540), with the
wheel derivation in “Explaining the Wheel Sieve,” *Acta Informatica* 17,
1982, [doi:10.1007/BF00264164](https://doi.org/10.1007/BF00264164). The paper
citations provide algorithm provenance, not a license to source code. No
published implementation, code comments, or test fixtures were copied.
