# Moser–de Bruijn sequence

This package adapts the pinned Go `MoserDeBruijnSequence` routine, which generates the first `number` terms by recursively applying the even/odd Moser–de Bruijn recurrence.

## Contract

- ABI: `i64_array_bytes_output`. Input is exactly `[number]`, with `number` in `[-64, 64]`. Invalid framing, range, or a null input pointer returns `-1`.
- A nonpositive count produces an empty sequence and returns `0`, matching the source's empty slice for nonpositive counts.
- For a positive count, output the first `number` terms as consecutive signed 64-bit little-endian integers. Return the output byte count (`8 * number`). A null output pointer or insufficient capacity returns `-2` when the output is nonempty; an empty result needs no output pointer or capacity.
- Maximum output/workspace is 512 bytes. Terms are generated by the source recurrence: `T(0)=0`, `T(1)=1`, `T(2k)=4*T(k)`, and `T(2k+1)=4*T(k)+1`.

## Workload and source

[`workload.json`](workload.json) covers empty and nonempty requests, recurrence boundaries, the maximum request, malformed framing/ranges, and output capacity/null-pointer behavior. The independent [oracle](../../sequence_oracle.py) computes terms from the recursive recurrence and encodes them as little-endian signed 64-bit values.

Pinned source: [TheAlgorithms/Go `sequence.go`](https://github.com/TheAlgorithms/Go/blob/5ba447ec5ff3d1213de65b92e726ee74c5d5cc19/math/moserdebruijnsequence/sequence.go), function `MoserDeBruijnSequence` and helper `generateNthTerm`.
