# Rights and provenance

The operational algorithm description is based on Kurt Mehlhorn, “A Faster
Approximation Algorithm for the Steiner Problem in Graphs,” *Information
Processing Letters* 27(3), 125–128 (1988), DOI
[10.1016/0020-0190(88)90066-X](https://doi.org/10.1016/0020-0190(88)90066-X).
Chapter context is Weili Wu and Yaocun Huang, “Steiner Trees,” *Encyclopedia of
Algorithms*, Chapter 403, DOI
[10.1007/978-1-4939-2864-4_403](https://doi.org/10.1007/978-1-4939-2864-4_403).
The original Kou, Markowsky, and Berman algorithm is cited in the workload as
the method family Mehlhorn refines.

The cited publications retain their respective copyrights. This repository
uses only the mathematical procedure and bibliographic facts. The ABI,
bounded contract, fixtures, references, and language ports were independently
written; no source code, prose, examples, or test cases were copied.
