# Rights and provenance

The ordered region-merge method is described in Nock and Nielsen's 2004
[research paper](https://www.lix.polytechnique.fr/~nielsen/pdf/2004-StatisticalRegionMerging-PAMI.pdf).
The [PARSEC technical report](https://www.cs.princeton.edu/techreports/2010/890.pdf)
identifies it as a Ferret segmentation kernel. These publications are algorithm
references, not licenses for copying. This package uses independently written
code, contract and fixtures; the supplied-bound profile is an explicit bounded
adaptation and does not reproduce source text, code, examples or images.
