# Rights and provenance

The operation, constraints, and task name follow Library Checker’s
[`sum_of_exponential_times_polynomial`](https://github.com/yosupo06/library-checker-problems/tree/master/other/sum_of_exponential_times_polynomial).
The Library Checker problem repository identifies its license as Apache-2.0.
This package contains clean-room implementations derived from the mathematical
problem statement and identities; it does not copy reference source code.

The finite-block binomial shift, rational-tail identity, Eulerian polynomial
identity, and Stirling/falling-factorial identity are mathematical techniques
used to implement and independently verify the operation. Local metadata,
workload fixtures, documentation, and source files are original to this
benchmark repository.
