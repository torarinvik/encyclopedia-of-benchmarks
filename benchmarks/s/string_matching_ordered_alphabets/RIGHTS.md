# Rights and provenance

The algorithm is due to Maxime Crochemore. This package consults the
[String Matching on Ordered Alphabets description](https://igm.univ-mlv.fr/~lecroq/string/node27.html)
and Crochemore's 1992 paper, “String-matching on ordered alphabets,”
Theoretical Computer Science 92(1):33–47,
[DOI 10.1016/0304-3975(92)90134-2](https://doi.org/10.1016/0304-3975(92)90134-2).
Only the algorithm idea was used. No source code, prose, example, or fixture
was copied; the contract, benchmark sources, documentation, and workload are
independently authored. The algorithm is not claimed as original.
