# Rights and provenance

This package is a clean-room instantiation of a generic deque aggregate using
2×2 matrix multiplication modulo 97. Its stack orientation and midpoint
rebalance follow the high-level algorithm description for
NyaanNyaan/library's
[`slide-window-aggregation-deque.hpp`](https://github.com/NyaanNyaan/library/blob/master/data-structure/slide-window-aggregation-deque.hpp).
The upstream repository declares CC0 1.0 Universal in its
[`LICENSE`](https://github.com/NyaanNyaan/library/blob/master/LICENSE).
No upstream code, prose, tests, or fixtures are included. The ports, oracles,
and workload are original repository material and follow the repository's
license.
