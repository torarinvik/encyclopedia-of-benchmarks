# Provenance and rights

The task definition and official limits are from the Library Checker
[`sqrt_of_formal_power_series` task](https://github.com/yosupo06/library-checker-problems/blob/master/polynomial/sqrt_of_formal_power_series/task.md)
and its [`info.toml`](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/polynomial/sqrt_of_formal_power_series/info.toml).
The upstream repository declares [Apache-2.0](https://github.com/yosupo06/library-checker-problems/blob/master/LICENSE).

Only task metadata and the mathematical specification informed this profile.
The bounded ABI contract, deterministic root selection, fixtures, workload,
oracles, docs, and ten ports were written independently; no upstream source,
prose, test cases, or expected outputs were copied. Local artifacts follow
this repository's license.
