# Rights and provenance

The [OI Wiki shortest-path modulo article](https://www.timothywang.ca/OI-wiki/graph/mod-shortest-path/)
describes a residue graph for minimizing the digit sum of a positive multiple
whose decimal digits are zero or one. Its source page is marked CC BY-SA 4.0
with the SATA additional terms. This package records that reference and uses
the algorithmic idea only; it does not copy source code, examples, or prose.
The benchmark profile selects the article's [ARC084B Small Multiple task](https://atcoder.jp/contests/arc084/tasks/arc084_b).

The bounded `n <= 16` contract, independent exhaustive reference, workload,
documentation, and ten language ports were authored for this benchmark suite.
