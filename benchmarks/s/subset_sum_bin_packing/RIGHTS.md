# Rights and provenance

This benchmark is a clean-room implementation of the repeated subset-sum
bin-packing heuristic described by Julián Mestre in the 2016 [Encyclopedia of
Algorithms, pp. 2126–2129](https://link.springer.com/referencework/10.1007/978-1-4939-2864-4?page=29).
An earlier online edition is available at [DOI
10.1007/978-3-642-27848-8_496-1](https://doi.org/10.1007/978-3-642-27848-8_496-1).
Only the mathematical algorithm description was consulted. No source code,
examples, fixtures, problem statements, or prose were copied. The bounded
contract, tie-breaking rule, workload, references, and language ports are
independently authored.
