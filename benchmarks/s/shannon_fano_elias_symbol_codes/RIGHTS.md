# Rights and provenance

This package is a clean-room implementation of the algorithmic construction
described by Gilbert and Moore in “Variable-Length Binary Encodings,” *Bell
System Technical Journal* 38(4), 1959, DOI
[10.1002/j.1538-7305.1959.tb01583.x](https://doi.org/10.1002/j.1538-7305.1959.tb01583.x).
NIST DADS's [Shannon–Fano entry](https://xlinux.nist.gov/dads/HTML/shannonFano.html)
was used as a discovery index. No source code, prose, tests, examples, or
fixtures were reused. The input profile, byte framing, reference implementations,
and fixtures were authored for this benchmark.

The paper is cited for provenance and method only; this repository does not
assert or grant a license to the paper. Source files in this benchmark use the
repository's applicable licensing terms.
