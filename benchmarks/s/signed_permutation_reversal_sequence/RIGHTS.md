# Rights and provenance

This package is an independently written bounded profile of the
self-reduction attributed to Eric Tannier in “Sorting Signed Permutations by
Reversal (Reversal Sequence),” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_384. The chapter is used for algorithm attribution
and semantics, not as a code license. No book prose, figures, or code were
copied. These clean-room implementations are subject to repository terms.
