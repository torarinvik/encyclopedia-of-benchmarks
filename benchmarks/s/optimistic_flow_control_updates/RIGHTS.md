# Rights and provenance

This package is an independently written bounded implementation of the
optimistic update operation and scheduler policies attributed to Panagiota
Fatourou in “Schedulers for Optimistic Rate Based Flow Control,”
*Encyclopedia of Algorithms*, DOI 10.1007/978-1-4939-2864-4_356. The chapter is
used for algorithm attribution and semantics, not as a code license. No book
prose, figures, or code were copied. These clean-room implementations are
subject to repository terms.
