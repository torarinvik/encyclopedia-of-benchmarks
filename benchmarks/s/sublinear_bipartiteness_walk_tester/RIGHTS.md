# Rights and attribution

This package is an independently written implementation of the lazy random-walk parity-collision tester described by Oded Goldreich and Dana Ron, “Testing Bipartiteness of Graphs in Sublinear Time,” *Encyclopedia of Algorithms*, DOI `10.1007/978-1-4939-2864-4_701`.

The chapter, figures, and cited research remain copyrighted. No license to redistribute those materials is asserted. This package contains no copied source code, prose, or figures and only implements the stated mathematical transition and parity test with explicit bounded input choices. Preserve the bibliographic attribution above when redistributing this package.
