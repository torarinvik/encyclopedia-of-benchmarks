# Rights and provenance

This package is a clean-room implementation of the algorithmic idea described
in the “Cyclic Case” subsection of Seokhee Hong's “Symmetric Graph Drawing,”
*Encyclopedia of Algorithms*, Chapter 654, DOI
10.1007/978-1-4939-2864-4_654. It uses a supplied plane embedding and supplied
rotational automorphism to extract one symmetric wedge. The later CYN convex
drawing algorithm and geometric wedge-merging step are outside the profile.

No source code, example data, or expressive text from the book is copied. The
ports, references, and fixtures were written independently from the described
algorithm. The source is cited for provenance and algorithm description only.
