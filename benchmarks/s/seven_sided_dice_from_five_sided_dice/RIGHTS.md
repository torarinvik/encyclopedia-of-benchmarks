# Rights and provenance

The task is listed by [Rosetta Code](https://rosettacode.org/wiki/Seven-sided_dice_from_five-sided_dice)
and [RosettaGit](https://rosettagit.org/tasks/seven-sided-dice-from-five-sided-dice/).
The source page is marked GFDL-1.3-or-later. This package takes only the
algorithmic problem idea: convert independent uniform five-sided-die draws
into uniform seven-sided-die faces by splitting accepted states and rejecting
the excess tail.

The finite input tape, quotient-entropy recycling contract, exact bounds,
output format, references, workload cases, package documentation, inventory
checker, and all ten ports were authored for this benchmark. No source code,
tests, examples, or prose from Rosetta Code is copied.
