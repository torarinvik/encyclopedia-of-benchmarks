# Source and rights

The algorithmic description is attributed to Weili Wu and Yaocun Huang,
“Steiner Trees,” Encyclopedia of Algorithms, DOI
10.1007/978-1-4939-2864-4_403 (`OEBPS/AChap403.html`). The chapter is used only
to identify the gain-greedy procedure and its full-component families. No
source-code license grant is asserted. All implementations in this package
are independently written clean-room ports; no chapter prose or code is
reproduced beyond short mathematical names and formulas needed to identify the
algorithm.
