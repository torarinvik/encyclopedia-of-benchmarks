# Rights and provenance

This package was written from the algorithm description in [OI Wiki's segment-tree merge and split chapter](https://oi-wiki.org/ds/seg-merge-split/). OI Wiki labels the page CC BY-SA 4.0/SATA. The benchmark uses a bounded clean-room adaptation of the sparse multiset merge and interval split procedures; it does not copy source code, examples, tests, or text from the page.

All ten language ports, workload fixtures, and oracles are original benchmark materials. The oracle implementations are independently structured and do not import a language port.
