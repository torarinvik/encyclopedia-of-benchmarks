# Rights and provenance

Skip Search is attributed to Christian Charras, Thierry Lecroq, and Joseph D.
Pehoushek. This package consults Lecroq's
[algorithm description](https://igm.univ-mlv.fr/~lecroq/string/node31.html)
and the cited paper, “A very fast string matching algorithm for small
alphabets and long patterns,” DOI
[10.1007/BFb0030780](https://doi.org/10.1007/BFb0030780). Only the algorithm
idea was used. No implementation, prose, sample, or fixture was copied; the
contract, benchmark sources, documentation, and workload are independently
authored. The algorithm is not claimed as original.
