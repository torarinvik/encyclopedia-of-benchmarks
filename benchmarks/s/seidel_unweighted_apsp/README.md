# Seidel unweighted all-pairs distances

This in-progress profile computes all-pairs distances for a connected, simple, undirected, unweighted graph using Seidel's adjacency-squaring and distance-recovery method.

The `i64_array_bytes_output` input is `[n,A]`, with `1<=n<=8` and a row-major `n*n` adjacency matrix. Entries are 0 or 1, the diagonal is zero, the matrix is symmetric, and all vertices are connected; a singleton is valid. The exact length is `1+n*n` (maximum valid 65, maximum parseable 66). Success writes the row-major distance matrix as little-endian i64 words and returns `8*n*n`, at most 512 bytes. Invalid or null input returns -1; valid input with null or short output returns -2 without writes. Connectivity is checked before output errors.

The algorithm forms the graph connecting pairs at distance at most two, recursively computes its distances, and recovers each original distance by comparing a neighbor-distance sum with the corresponding degree-scaled coarse distance. The complete graph is the base case. Schoolbook integer matrix multiplication gives O(n³ log n) time and O(n² log n) recursive storage; this bounded implementation does not claim the paper's fast-matrix complexity. No path witnesses are returned.

This differs from [`floyd_warshall`](../../f/floyd_warshall/README.md), [`johnson_shortest_paths`](../../j/johnson_shortest_paths/README.md), and [`apsp_min_plus_repeated_squaring`](../../a/apsp_min_plus_repeated_squaring/README.md), whose graph domains or underlying operations differ. The method comes from [Seidel's paper](https://www.mimuw.edu.pl/~mucha/teaching/alp2006/seidel92.pdf); only the mathematical description is used, with independently written code and fixtures. The primary oracle validates connectivity by bitset expansion and uses Seidel's method; the independent reference validates and computes distances by breadth-first search. Drafts in all ten languages, workload, package checker, and byte-output suite registration are present. Nothing has been run; further review remains necessary.
