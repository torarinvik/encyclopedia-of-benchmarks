# Provenance

The algorithmic idea is described in Raimund Seidel's [all-pairs distances paper](https://www.mimuw.edu.pl/~mucha/teaching/alp2006/seidel92.pdf). The benchmark uses mathematical ideas only and independently written code, contract, and fixtures; no paper text or code is reproduced. The reference oracle uses breadth-first search rather than Seidel's method.
