# Rights and provenance

This clean-room profile follows the algorithm description in
[Charras and Lecroq’s Simon entry](https://igm.univ-mlv.fr/~lecroq/string/node9.html).
That entry cites Hancart’s 1993 paper “On Simon’s string searching algorithm”
and Simon’s 1993 paper “String matching algorithms and automata.” The sources
are used for the method and bibliographic provenance only. No code or example
text is copied; the ports and fixtures are original.
