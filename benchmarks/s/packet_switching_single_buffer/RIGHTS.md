# Rights and provenance

This package is an independently written bounded implementation of the
Natural Greedy, Preemptive Greedy, and Modified Preemptive Greedy packet
policies described in “Packet Switching in Single Buffer,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_275. The chapter is attribution,
not a code license. No book text, figures, or code were copied. Repository
code remains subject to applicable repository terms.
