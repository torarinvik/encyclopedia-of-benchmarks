# Rights and provenance

This package is an independently written bounded implementation of the
algorithm attributed to Zoltán Király in “Simpler Approximation for Stable
Marriage,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_676. The chapter is used for attribution and
algorithmic semantics, not as a code license. No book prose, figures, or code
were copied. These clean-room implementations are subject to repository
terms.
