# Rights and provenance

This package contains clean-room implementations of the Aho–Corasick failure-tree occurrence-counting method. The algorithm was derived from descriptions in:

- [CP-Algorithms: Aho–Corasick algorithm](https://cp-algorithms.com/string/aho_corasick.html)
- [OI Wiki: Aho–Corasick automaton](https://oi-wiki.org/string/ac-automaton/)

The cited pages are available under CC BY-SA 4.0 (OI Wiki also records SATA terms). They were consulted for algorithm discovery and high-level method descriptions only. No source code, task text, or prose was copied. The benchmark contract, workload, oracles, and ports were written independently. The upstream theorem/method itself is not claimed as project-owned intellectual property.
