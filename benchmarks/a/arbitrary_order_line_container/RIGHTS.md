# Rights and provenance

This package is a clean-room implementation of an arbitrary-order line
container using slope ordering, integer intersection breakpoints, active-line
pruning, and breakpoint search. Its behavior is based on NyaanNyaan/library's
public [`line-container.hpp`](https://github.com/NyaanNyaan/library/blob/master/data-structure/line-container.hpp).
The upstream repository declares CC0 1.0 Universal in its
[`LICENSE`](https://github.com/NyaanNyaan/library/blob/master/LICENSE).
No upstream code, prose, tests, or fixtures are included. The ports, oracles,
and workload are original repository material and follow the repository's
license.
