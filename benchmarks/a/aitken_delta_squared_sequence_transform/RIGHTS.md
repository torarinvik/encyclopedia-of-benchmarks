# Rights and provenance

The method is specified from NIST's [Digital Library of Mathematical
Functions §3.9(iii)](https://dlmf.nist.gov/3.9#E7), which gives Aitken's
three-term Δ² sequence transformation. This package contains original
bounded-contract decisions, metadata, workload fixtures, references, and
native implementations. No source code, task text, prose, figures, examples,
or tests are copied.

The special output for a zero second difference is part of this benchmark's
exact-rational contract: constant triples remain defined, while nonconstant
arithmetic triples use the `(0, 0)` undefined marker.
