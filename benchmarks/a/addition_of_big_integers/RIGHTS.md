# Provenance and rights

The high-level operation was identified through the Library Checker
[`addition_of_big_integers` task](https://github.com/yosupo06/library-checker-problems/blob/master/big_integer/addition_of_big_integers/task.md),
its [`info.toml`](https://github.com/yosupo06/library-checker-problems/blob/master/big_integer/addition_of_big_integers/info.toml),
and the [official problem-category inventory](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/categories.toml).
The upstream problem repository declares Apache-2.0 in its
[license file](https://github.com/yosupo06/library-checker-problems/blob/master/LICENSE).

This benchmark uses the task name, mathematical operation, and parameter
metadata only for algorithm discovery. The bounded input encoding, fixtures,
oracle implementations, documentation, and ten language ports are newly
written from the operation's mathematical definition. No upstream source code,
problem statement wording, generated cases, or expected-output files were
copied. The ports and local artifacts are offered under this repository's
license.
