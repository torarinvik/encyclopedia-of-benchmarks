# Rights and provenance

This benchmark is a clean-room implementation of unrestricted addition-chain
search and enumeration of all shortest chains. The algorithm is described by
the [Rosetta Code Addition chains task](https://rosettagit.org/tasks/addition-chains/)
and the [OEIS addition-chain length entry](https://oeis.org/A003313). Rosetta
Code describes its contribution terms as GNU Free Documentation License 1.2
on its [copyright page](https://rosettagit.org/drafts/rosetta-code-copyrights/).
The local contract and code were written independently; no task prose, code,
examples, fixtures, or tests were copied. Only the mathematical algorithm and
standard terminology are used.
