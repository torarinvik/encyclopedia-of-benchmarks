# Rights and provenance

This package is a clean-room implementation of min-plus repeated squaring
described in Tadao Takaoka, “All Pairs Shortest Paths via Matrix
Multiplication,” *Encyclopedia of Algorithms*, DOI
`10.1007/978-1-4939-2864-4_12`.

The chapter and summarized research remain copyrighted. This package copies
no chapter prose, source code, or figures and asserts no license over the
source material. The bounded matrix size, positive integer edge domain,
sentinel, and distance-only output are benchmark-profile choices.
