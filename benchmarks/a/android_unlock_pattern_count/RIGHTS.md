# Rights and provenance

The public Codewars title “Screen Locking Patterns” and its tags in the
[Algorithms + Graph Theory listing](https://www.codewars.com/kata?tags=Algorithms%2CGraph+Theory)
were used for algorithm discovery only. No Codewars problem text, examples,
tests, submissions, or code were read or copied.

The bounded rule contract follows the independently published Android unlock
pattern descriptions in Uellenbeck et al., [“Quantifying the Security of
Graphical Passwords: The Case of Android Unlock Patterns”](https://doi.org/10.1145/2508859.2516700),
and Lee et al., [“A Visibility-Based Lower Bound for Android Unlock Patterns”](https://doi.org/10.1587/transinf.2016EDL8196). Per-length reference counts
are cross-referenced with [OEIS A163889](https://oeis.org/A163889). No source
implementation, paper wording, figures, or protected examples are reused.

All ten language ports, both reference models, the workload, and package
documentation are independently written for this repository.
