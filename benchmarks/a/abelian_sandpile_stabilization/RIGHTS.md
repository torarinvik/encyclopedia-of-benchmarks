# Rights and provenance

The mathematical model is based on Deepak Dhar, “Self-Organized Critical State
of Sandpile Automaton Models,” *Physical Review Letters* 64(14), 1613–1616
(1990), available from the author's institutional repository at
https://repository.ias.ac.in/9280/1/311.pdf. The paper's general integer
toppling-matrix formulation is specialized here to a rectangular square grid
with threshold four and an open dissipative boundary. RosettaGit's
https://rosettagit.org/tasks/abelian-sandpile-model/ was a title-only discovery
index; its community task content and code were not reused.

Only the algorithm idea, standard grid toppling rule, and Abelian stabilization
property were used. All language implementations, reference methods, fixture
values, and explanations were independently authored for this repository. No
third-party source code, task prose, examples, or tests are included.
