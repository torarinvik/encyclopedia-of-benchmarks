# Source and rights note

Sources: Shiri Chechik, “Additive Spanners,” *Encyclopedia of Algorithms*,
DOI 10.1007/978-1-4939-2864-4_562; and Mathias Bæk Tejs Knudsen, “Additive
Spanners: A Simple Construction,” *SWAT 2014*, pp. 277–281,
DOI 10.1007/978-3-319-08404-6_24.

This package independently implements a bounded deterministic 2-spanner
completion profile from the published algorithm description. No source code,
prose, figures, examples, or test data are copied. Pair ordering and shortest
path tie-breaking are local profile choices.
