# Rights and provenance

The profile was independently implemented from NIST's descriptive entry for
[linear hashing](https://xlinux.nist.gov/dads/HTML/linearHashing.html) and the
algorithm description in Litwin, [“Linear Hashing: A New Tool for File and
Table Addressing”](https://www.vldb.org/dblp/db/conf/vldb/Litwin80.html). No third-party
source code, tests, examples, or prose were copied. NIST's dictionary is used
for algorithm identification and attribution only.
