# Provenance and rights

Algorithm source: NIST Digital Library of Mathematical Functions,
§3.2(vi), Eqs. 3.2.21–3.2.22:
<https://dlmf.nist.gov/3.2.vi>. The DLMF was consulted for the symmetric
Lanczos recurrence, coefficient definitions, and projected tridiagonal
interpretation.

The reference implementation and independent Krylov-basis construction were
written clean-room from those mathematical definitions. No source code,
comments, examples, test cases, or prose were copied. Workload fixtures are
derived independently from small supplied matrices. This file records
provenance and makes no claim that the DLMF is a software license.
