# Rights and attribution

This package is an independently written implementation of the bounded
one-step lookahead LZ78 parsing profile described in Travis Gagie and
Giovanni Manzini, “Dictionary-Based Data Compression,” *Encyclopedia of
Algorithms*, DOI `10.1007/978-1-4939-2864-4_108`, summarizing the method of
Matias and Sahinalp (SODA 1999).

The book chapter and cited paper remain copyrighted. No license to redistribute
their text, figures, or source code is asserted. The ports contain no copied
source code or extended prose; they implement the documented bounded profile
clean-room. Retain this attribution when redistributing the package.
