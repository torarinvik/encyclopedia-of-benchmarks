# Rights and provenance

The LCIS problem definition and algorithm descriptions are supported by the
cited scholarly papers. The Algovault README index was used only for title
discovery; no Algovault implementation code, examples, or text were reused.

STACS paper is licensed CC BY; only its matching-pair partial-order idea is
used here.
