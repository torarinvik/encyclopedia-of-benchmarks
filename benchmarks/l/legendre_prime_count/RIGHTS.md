# Rights and provenance

The benchmark contract is based on the [Library Checker Counting Primes task](https://judge.yosupo.jp/problem/counting_primes). The algorithm description refers to [Legendre's Formula at MathWorld](https://mathworld.wolfram.com/LegendresFormula.html), which defines the partial-sieve count and its prime-counting specialization.

Only the mathematical operation, formula, and input bound are used as references. No implementation code or explanatory prose was copied. The ten language ports, fixtures, workload, and both oracles were written independently for this repository. The direct-sieve oracle is an independent verification method, not a port of the Legendre recurrence.
