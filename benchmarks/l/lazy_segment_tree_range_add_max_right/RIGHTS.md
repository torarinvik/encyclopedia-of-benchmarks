# Rights and provenance

This package is a clean-room implementation of lazy range addition combined
with a sum-monoid `max_right` search. Its semantics are based on the public
[AtCoder Library lazy segment-tree documentation](https://atcoder.github.io/ac-library/production/document_en/lazysegtree.html)
and the corresponding [`lazysegtree.hpp`](https://github.com/atcoder/ac-library/blob/master/atcoder/lazysegtree.hpp).
AtCoder Library is distributed under CC0 1.0 Universal. This package uses the
published algorithm semantics only; it contains no copied upstream source,
prose, tests, or fixtures. The ports, references, and workload are original
repository material and follow the repository's license.
