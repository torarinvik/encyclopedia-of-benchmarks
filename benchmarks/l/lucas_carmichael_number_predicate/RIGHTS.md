# Rights and provenance

This package is a clean-room implementation of a mathematical predicate. The
definition is taken from the public descriptions in [OEIS A006972](https://oeis.org/A006972)
and [MathWorld](https://mathworld.wolfram.com/Lucas-CarmichaelNumber.html): a
Lucas–Carmichael number is squarefree and composite, and each prime divisor `p`
satisfies `p + 1 | n + 1`. The [pinned RosettaCodeData popular-title index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks)
is cited only as discovery provenance.

No RosettaCode task wording, implementation, published code, tests, or sample
program output was copied. The workload's known positive values are sequence
members independently listed by OEIS and MathWorld. All native ports and both
references were written specifically for this bounded benchmark profile.
