# Rights and provenance

This package is a clean-room implementation of the bounded Landau–Vishkin
approximate-substring endpoint operation. It uses the algorithmic ideas in:

- G. M. Landau and U. Vishkin, “Fast String Matching with k Differences,”
  *Journal of Computer and System Sciences* 37(1), 1988, 63–78,
  [DOI 10.1016/0022-0000(88)90045-1](https://doi.org/10.1016/0022-0000(88)90045-1).
- G. M. Landau and U. Vishkin, “Fast Parallel and Serial Approximate String
  Matching,” *Journal of Algorithms* 10(2), 1989, 157–169,
  [DOI 10.1016/0196-6774(89)90010-2](https://doi.org/10.1016/0196-6774(89)90010-2).
- G. Navarro, “Approximate String Matching,” *Encyclopedia of Algorithms*,
  2nd edition, Chapter 363,
  [DOI 10.1007/978-1-4939-2864-4_363](https://doi.org/10.1007/978-1-4939-2864-4_363).

The references above are cited as research provenance; this repository does
not include copied source code, prose, figures, sample data, or tests from
them. The contract, fixtures, and implementation structure are original to
this package. No license for the cited works is asserted or implied.
