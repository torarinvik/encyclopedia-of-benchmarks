# Provenance and rights

The operation and official limits are described by the Library Checker
[`log_of_formal_power_series` task](https://github.com/yosupo06/library-checker-problems/blob/master/polynomial/log_of_formal_power_series/task.md),
its [`info.toml`](https://raw.githubusercontent.com/yosupo06/library-checker-problems/master/polynomial/log_of_formal_power_series/info.toml),
and the repository [license](https://github.com/yosupo06/library-checker-problems/blob/master/LICENSE), which declares Apache-2.0.

This benchmark uses task metadata and the mathematical definition for
discovery. The bounded contract, fixtures, oracles, documentation, and ten
language ports were written independently. No upstream source code, prose,
test cases, or expected output files were reused. Local artifacts follow this
repository's license.
