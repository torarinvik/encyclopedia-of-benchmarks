# Rights and provenance

This package is an independently authored bounded implementation of the
mathematical procedure in Levcopoulos and Lingas, “There Are Planar Graphs
Almost as Good as the Complete Graphs and Almost as Cheap as Minimum Spanning
Trees,” *Algorithmica* 8 (1992), 251–256, Algorithm 3.1, [DOI
10.1007/BF01758846](https://doi.org/10.1007/BF01758846). Chapter context is
*Encyclopedia of Algorithms*, Chapter 294, [DOI
10.1007/978-1-4939-2864-4_294](https://doi.org/10.1007/978-1-4939-2864-4_294).

Only the algorithmic ideas, equations, and terminology needed to identify the
method were consulted. No source implementation, copyrighted explanation,
figure, exercise, or published fixture was copied. The package contract,
bounded workload, references, and language ports were written independently.
There are no external code dependencies or third-party implementation licenses
to reproduce.

The original paper is cited for attribution and verification of the method,
not as a license grant for any implementation. This notice applies only to
the clean-room material in this package.
