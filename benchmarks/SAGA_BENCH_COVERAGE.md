# SAGA-Bench algorithm coverage

Source audit is pinned to [`abasak24/SAGA-Bench`](https://github.com/abasak24/SAGA-Bench/tree/de61f442b39ffecd8630adc4cb1e39569d0d90cc), commit `de61f442b39ffecd8630adc4cb1e39569d0d90cc`. The README lists six algorithms with incremental and recomputation modes. This crosswalk covers the six SAGA incremental entry points only; their source operates on prior graph state after each inserted edge batch. The package fixes a deterministic single-thread schedule, bounds the graph to eight vertices and 28 edges, returns the final property vector, and is registered in the byte-output suite.

SAGA's README says most recomputation implementations are borrowed from GAP Benchmark Suite. Those full-recompute routines are not copied or reimplemented here; local GAPBS/GBBS static graph packages are recorded above as related baselines. The SAGA root license is the Simplified BSD 2-Clause license and is reproduced in full in the package. Only the SAGA incremental source paths are used for behavior attribution.
