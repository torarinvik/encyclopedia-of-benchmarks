# Rodinia source coverage

This crosswalk inventories the benchmark directories in the CUDA/OpenCL/OpenMP source trees and tracks their disposition against bounded local packages. A package captures the named operation and its documented deterministic profile; it does not reproduce the Rodinia harness, dataset size, device execution, or benchmark score. `Distinct candidate` means the core is not represented locally and remains backlog work. `Duplicate` means the same core algorithm is already represented, even where a Rodinia variant uses different dimensions, boundary handling, or a parallel implementation. `Excluded` marks broad application pipelines for which no compact standalone kernel has been selected. `Package ready` means the bounded profile, nine ports, rights, and workload artifacts are in place while suite registration is queued. `Suite wired` identifies profiles with local ports and benchmark-runner integration.

The current package uses the `utcs-scea/rodinia` source snapshot at commit [`f30e63663cfb114939a15c7ffc4ae112055ae6a8`](https://github.com/utcs-scea/rodinia/tree/f30e63663cfb114939a15c7ffc4ae112055ae6a8). Source-specific rights notices and attribution are recorded in each package.
