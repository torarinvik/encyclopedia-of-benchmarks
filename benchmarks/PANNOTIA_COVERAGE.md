# Pannotia graph-kernel coverage

This crosswalk inventories all application-level algorithm variants in the
[Pannotia v0.9 repository](https://github.com/pannotia/pannotia), pinned to
commit [`16c1f0964516babc13a60f21c74644e28f3651b1`](https://github.com/pannotia/pannotia/tree/16c1f0964516babc13a60f21c74644e28f3651b1).
It compares source operations and selection/update rules, not filenames. The
full AMD license text is retained in each Pannotia-derived package. This is a
static source and package inventory, not a runtime correctness claim.

priority vector. The profile preserves the source's strict comparisons and
round barriers; the README records the source's degree-one comparison guard and
why those inputs are outside the bounded domain.
