# Rights and provenance

The package is a clean-room implementation of the branch-and-search algorithm
described in “Vertex Cover Search Trees,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_462. Ports, oracle, fixtures, and documentation were
written independently. The chapter is attribution, not a source-code license;
no book text, figures, or pseudocode blocks were copied. Repository code remains
subject to applicable repository terms.
