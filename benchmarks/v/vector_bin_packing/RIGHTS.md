Algorithms*, DOI `10.1007/978-1-4939-2864-4_495`. The chapter is used only to
identify the problem model and algorithm profile. The nine implementations,
oracles, workload, and documentation in this package are independently written
clean-room work; no chapter text, figures, or code have been copied.
