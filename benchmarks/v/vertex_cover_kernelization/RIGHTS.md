# Rights and provenance

The package is a clean-room implementation of the degree-based vertex-cover
preprocessing described in “Vertex Cover Kernelization,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_460. The ports, fixtures, oracle,
and documentation were written independently; no book prose, figures, code,
or pseudocode blocks were copied. The chapter is attribution, not a source-code
license. This notice makes no claim or grant concerning the underlying
algorithmic idea; repository code remains subject to applicable repository
terms.
