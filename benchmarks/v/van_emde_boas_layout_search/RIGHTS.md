# Rights and provenance

The van Emde Boas memory-layout method is attributed here to the static layout described in Michael A. Bender, Erik D. Demaine, and Martin Farach-Colton, “Cache-Oblivious B-Trees,” §2.1, DOI 10.1137/S0097539701389956, [paper PDF](https://erikdemaine.org/papers/CacheObliviousBTrees_SICOMP/paper.pdf).

The paper carries its own publication copyright and no open-source code license is relied upon. The package contains a clean-room implementation of the published recurrence. No paper code, prose, figures, examples, or test fixtures are copied. The workload cases are independently pinned for this bounded profile. The dynamic predecessor benchmark `veb_tree` is cited only to distinguish contracts and is not a source for this package.
