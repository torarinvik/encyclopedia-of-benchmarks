# Rights and provenance

This package is a clean-room implementation of the uniform-random assignment
algorithm described in “Vector Scheduling Problems,” *Encyclopedia of
Algorithms*, DOI 10.1007/978-1-4939-2864-4_504. The package uses caller-supplied
machine choices as an explicit deterministic projection. No book prose,
figures, pseudocode blocks, or implementation source were copied. The chapter
is attribution, not a code license; repository code remains subject to
applicable repository terms.
