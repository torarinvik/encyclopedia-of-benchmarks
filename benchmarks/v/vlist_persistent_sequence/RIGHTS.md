# Provenance and rights

The primary algorithm reference is Phil Bagwell, *Fast Functional Lists,
Hash-Lists, Deques and Variable Length Arrays* (EPFL technical report, 2002),
available at <https://lampwww.epfl.ch/papers/techlists.pdf>. Sections 2.1, 2.3,
and 2.5 inform the geometric block chain, `(block,offset)` root, `LastUsed`
extension rule, cdr traversal, indexing, length traversal, and factor-two
growth used by the bounded profile.

RosettaGit's [VList title page](https://rosettagit.org/tasks/vlist/) was used
only for title-index discovery. No Rosetta submissions, task prose, examples,
tests, or code were used. No source implementation, source comments, or figures
are copied. The EPFL report's source license was not identified; it is cited for
algorithm provenance only. The references, workload, and ten native ports are
new clean-room material.
