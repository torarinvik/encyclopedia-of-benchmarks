# Valid Parentheses

This benchmark checks whether a sequence of ASCII bracket code points is properly nested. Inputs contain 0 to 256 values from `()[]{}`. The ABI returns 1 for a valid sequence, 0 for an invalid sequence, and -1 for an unsupported value or an input longer than 256.

The pinned upstream candidates are [TheAlgorithms/C LeetCode 20](https://github.com/TheAlgorithms/C/blob/e5dad3fa8def3726ec850ca66a7f51521f8ad393/leetcode/src/20.c), [TheAlgorithms/Java ValidParentheses](https://github.com/TheAlgorithms/Java/blob/e43ec3897e48f23843972d02cd05a5bb1b6864a2/src/main/java/com/thealgorithms/stacks/ValidParentheses.java), [Dart `balanced_brackets.dart`](https://github.com/TheAlgorithms/Dart/blob/73da8ab4ea413eee9bf29aa2263157d86060f871/data_structures/Stack/balanced_brackets.dart), [Java `BalancedBrackets.java`](https://github.com/TheAlgorithms/Java/blob/e43ec3897e48f23843972d02cd05a5bb1b6864a2/src/main/java/com/thealgorithms/stacks/BalancedBrackets.java), and [C# `BalancedParenthesesChecker.cs`](https://github.com/TheAlgorithms/C-Sharp/blob/96e2905cab7bc6b33ac0a34ee5bb82ddccbcbb6c/Algorithms/Stack/BalancedParenthesesChecker.cs). Dart and Java match on the shared three-pair alphabet; the Java source's angle-bracket support is outside the contract. C# requires nonempty input, while the shared benchmark also defines empty input.

The nine portable implementations use the `i64_array_scalar` ABI and reside in the `v` folder of each language. The verifier exhausts all bracket strings through length six, checks maximum-length and invalid-input cases, and adds deterministic randomized inputs.

Build with `python3 benchmarks/build_abi.py --family i64_array_scalar --algorithm valid_parentheses --language LANGUAGE` and record with `python3 benchmarks/run_i64_array_scalar.py --algorithm valid_parentheses`. Verify ports with `python3 benchmarks/verify_valid_parentheses.py --elisa-compiler ../Elisa-compiler/bin/elisac-stage1`.
