# Provenance

Vitter's paper describes skip-based reservoir sampling and Algorithm X in
[*Random Sampling with a Reservoir*](https://doi.org/10.1145/3147.3165) (1985).
NIST DADS provides a concise description of the skip-based distinction:
https://xlinux.nist.gov/dads/HTML/reservoirSampling.html.

Only the algorithmic idea and skip distribution were consulted. All code,
the finite integer draw-tape contract, references, and fixtures are original.
No upstream source code, prose, examples, or tests were copied.
