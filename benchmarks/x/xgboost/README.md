# Embench xgboost bounded inference profile

This package exercises source-shaped boosted-tree inference, not model training. It accepts exactly 64 byte-valued features and evaluates a fixed bounded forest of six binary trees grouped into three classes (two trees per class). Each tree has three internal nodes and four leaves. Internal nodes use feature-index/threshold comparisons; leaf IDs use the high bit, as in the pinned source's array representation. Leaf values accumulate into class votes; the result is the lowest class index with the largest total.

The compact model is synthetic and source-shaped, not copied from the pinned MNIST model. Its exact `feature_index`, `threshold`, `left_child`, `right_child`, and `leaf_values` arrays are embedded in `workload.json`; the ports and oracle use those arrays verbatim. The model is intentionally fixed so all nine ports measure the same bounded traversal and vote-aggregation operation. It does not include Embench's embedded MNIST data, original 40 trees per class, training/model-generation, 128-sample accuracy loop, repeat scaling, or harness. This is a source-specific inference profile, distinct from the repository's single-tree decision-tree training examples and its squared-error gradient-boosting regressor.

Input is 64 signed 64-bit values in `[0,255]`; other lengths or values return `-1`. Output is a class index in `[0,2]`, with ties resolved toward the lowest index. The oracle is `benchmarks/xgboost_oracle.py`; fixtures are in [`workload.json`](workload.json).
