# Algorithm Archive chapter method crosswalk

Chapter descriptions were used for discovery; code, examples, tests, and chapter prose are not reused. The Archive states that its code examples use MIT terms and its text uses CC BY-SA 4.0 ([license notice](https://www.algorithm-archive.org/)).

## Confirmed addition: quantum spectral energy expectation

The audit's sole high-confidence gap, `quantum_spectral_energy_expectation`, is
implemented in all ten supported languages with package metadata, provenance,
primary radix-2 and independent direct-DFT references, fixtures, and
`i64_array_float64` suite integration. Its bounded Q8 contract and complexity
are recorded in [the package guide](q/quantum_spectral_energy_expectation/README.md).
The candidate is distinct from state evolution by the split-operator method.
Only the Archive's algorithm description informed the clean-room implementation;
no code, examples, tests, fixtures, or prose were reused. Static review only;
project execution remains intentionally unrun.
