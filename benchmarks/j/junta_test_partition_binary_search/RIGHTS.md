# Rights and provenance

The algorithmic source is Eric Blais, [“Testing Juntas Nearly Optimally,” §3.1/Figure 1](https://www.cs.cmu.edu/~eblais/papers/TestingJuntas.pdf), STOC 2009. The Encyclopedia of Algorithms entry [Chapter 709](https://doi.org/10.1007/978-1-4939-2864-4_709) provides the book crosswalk context. These sources are cited for algorithm identification and mathematical ideas only.

All package code, contract wording, encodings, deterministic replay rules, fixtures, and references were written independently. No source code, prose, examples, or tests were copied. The randomized partition and query sampling are supplied as input, and this package does not claim the paper's tester guarantee for a fixed replay.
