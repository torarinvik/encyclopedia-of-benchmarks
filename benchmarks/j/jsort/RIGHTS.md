# Rights and provenance

The algorithm description comes from the [NIST Dictionary of Algorithms and
Data Structures JSort entry](https://xlinux.nist.gov/dads/HTML/JSort.html),
modified 19 January 2021 and accessed 16 November 2026. The entry identifies
Jason Morrison and links [Pat Morin's Java implementation](https://cglab.ca/~morin/misc/sortalg/JSortAlgorithm.java);
Morin's source index was consulted for algorithm identification.

No source code or prose from the linked Java implementation was copied. The
ten ports are clean-room implementations of the DADS sequence: partial
heap-ordering passes in opposite directions, followed by insertion sort.
