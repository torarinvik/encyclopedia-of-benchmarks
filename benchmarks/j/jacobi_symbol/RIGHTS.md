# Rights and provenance

The package uses the mathematical definition of the Jacobi symbol and the
quadratic reciprocity rules described in Ben Lynn's Stanford notes and
Victor Shoup's *A Computational Introduction to Number Theory and Algebra*,
§12.3.

Only mathematical statements and algorithm ideas are used. The source ports,
oracles, fixture data, and documentation were written independently; no
published source code or prose was copied. Referenced publications and
websites retain their own copyright and license terms.
