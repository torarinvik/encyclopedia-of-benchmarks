# Rights and provenance

The operation follows the syntax and evaluation rules in IETF RFC 6901,
published under the IETF Trust Legal Provisions. RFC 6901 says code components
extracted from the document must include Simplified BSD terms. This package
contains no extracted code component: its ports, references, fixtures, and
descriptions are independently written from the standard's behavioral rules.

The RosettaCodeData popular-task index was used only to identify a candidate
title. Its task content, solutions, code, comments, tests, examples, and prose
were not accessed or reused. The package cites the RFC as its normative
contract and treats the community index as an idea index only.
