# Jacobi iteration method

This benchmark follows the pinned [TheAlgorithms/Python `jacobi_iteration_method.py`](https://github.com/TheAlgorithms/Python/blob/e1a2a8b016001309a73d5fec4818c35cca139795/linear_algebra/jacobi_iteration_method.py) routine's simultaneous Jacobi updates. Each iteration computes every new coordinate from the previous vector using `(bᵢ - Σⱼ≠ᵢ Aᵢⱼxⱼ) / Aᵢᵢ`, then replaces the vector after all rows are complete. It returns the vector after exactly the requested number of iterations.

Input is `[dimension, iterations, row-major coefficient matrix, rhs vector, initial vector]`. Dimension is 2–4, iterations are 1–8, matrix and vector values use thousandths, coefficient entries are 0–4, and vector values are -2 through 2. The diagonal must be strictly greater than the sum of off-diagonal entries in each row. Nonnegative coefficients preserve the pinned helper's signed-sum check while ensuring diagonal dominance. Output is a little-endian binary64 vector with at most four coordinates (32 bytes); the workload reserves that full capacity by default. Invalid inputs return -1; a null output buffer or insufficient output capacity returns -2. Runtime oracle: `jacobi_iteration_method_oracle.py`.
