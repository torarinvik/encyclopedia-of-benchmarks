A matching name alone is not evidence of coverage. “Exact local semantic match” means the local package implements the same core operation for its supported input domain. “Partial/related” records an inspected overlap with a material contract or algorithm difference. “Partially implemented” means a bounded source subroutine is present while the full launcher workload remains outside the package. “Newly implemented in this batch” means a local package and source-backed contract are present; this document does not claim runtime validation.
