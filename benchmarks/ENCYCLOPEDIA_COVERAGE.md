# Encyclopedia of Algorithms coverage

This index reconciles the chapter inventory in the user-supplied *Encyclopedia of Algorithms* EPUB with the local benchmark catalog. The four letter-range crosswalks contain 633 DOI-backed chapter entries (632 `AChap` resources and one additional chapter-level EPUB resource). Chapter identifiers use the DOI suffix for `10.1007/978-1-4939-2864-4`.

“Package” means a distinct bounded profile has a local benchmark package. “Existing” means the named algorithm behavior is already represented by a matching local contract. “Related-but-distinct” records a nearby implementation with a specific semantic or model difference; it does not claim coverage. “Not a bounded benchmark” and “not ported” record chapter-specific source, model, or variant reasons that prevent selecting one portable deterministic operation for this suite. All dispositions are based on static source and catalog inspection and do not claim runtime correctness.
