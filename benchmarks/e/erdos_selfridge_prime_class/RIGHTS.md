# Rights and provenance

The package contains clean-room implementations of the Erdős–Selfridge class
recurrence. No code, task prose, examples, or tests were copied. The
RosettaCodeData popular-task index was used only for title discovery.

Mathematical and historical references:

- OEIS [A126433](https://oeis.org/A126433/internal), plus-class recurrence.
- OEIS [A126805](https://oeis.org/A126805/internal), minus-class recurrence.
- RosettaCodeData, pinned [popular-tasks index](https://github.com/acmeism/RosettaCodeData/blob/1d475861d7141ef2fafff293d9339f56e4b0f5db/popular-tasks), discovery only.

The OEIS recurrence definitions and mathematical descriptions were used to
specify the profile. Workload inputs and expected outputs are hand-derived
fixtures. All native source ports are independently written.
