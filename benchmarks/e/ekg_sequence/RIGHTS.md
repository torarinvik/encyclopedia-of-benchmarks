# Rights and provenance

The benchmark uses the mathematical EKG recurrence defined by Jeffrey C.
Lagarias, Eric M. Rains, and Neil J. A. Sloane in [“The EKG Sequence”](https://arxiv.org/abs/math/0204011),
also catalogued as [OEIS A064413](https://oeis.org/A064413). The public
[RosettaGit task-title index](https://rosettagit.org/tasks/) was used only for
algorithm discovery. No RosettaGit task
content, OEIS program text, examples, tests, or submitted code was copied.

The bounded contract, workload, references, and all language ports are
independently written for this repository. The package measures the finite
prefix-generation algorithm and does not assert unproved asymptotic behavior.
