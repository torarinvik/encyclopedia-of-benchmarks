# Rights and provenance

The benchmark implementations and reference code in this package are newly written for this repository. They do not copy source code from the cited library. The algorithm attribution is to the two-heap lazy-cancellation technique described by [NyaanNyaan Library](https://github.com/NyaanNyaan/library/blob/master/data-structure/erasable-priority-queue.hpp). The workload, interface, and checksum are original benchmark design choices.
