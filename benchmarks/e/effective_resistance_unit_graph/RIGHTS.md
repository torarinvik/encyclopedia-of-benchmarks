# Provenance and reuse

The [CP-Algorithms matrix-tree article](https://cp-algorithms.com/graph/kirchhoff-theorem.html)
is the source used to identify the Laplacian-minor formula for effective
resistance. Its site identifies its text as CC BY-SA 4.0. This package uses
the mathematical relationship as an idea; its input contract, code, reference,
and workload were written independently, without copying the article's text,
code, or examples.

The existing local spanning-tree package uses a single cofactor to count
trees. This profile evaluates two minors and reduces their quotient for a
specified terminal pair, so the measured computation and result differ.
