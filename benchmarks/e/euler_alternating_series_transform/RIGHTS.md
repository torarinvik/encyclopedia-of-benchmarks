# Rights and provenance

The mathematical method is specified from NIST's [Digital Library of
Mathematical Functions §3.9(ii)](https://dlmf.nist.gov/3.9#E2), which gives
Euler's alternating-series transformation and the forward-difference formula.
This package contains an original bounded integer/rational contract,
metadata, fixtures, references, and native implementations. No source code,
task text, prose, figures, examples, or tests are copied.
