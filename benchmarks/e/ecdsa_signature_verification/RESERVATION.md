# ECDSA signature verification reservation

Implement ECDSA verification over the single bounded prime-field curve
`y^2 = x^3 + 2x + 2 (mod 17)`, with base point `(5,1)` and prime group order
`n=19`. The curve has 18 affine points plus infinity; its group has prime
order 19, so every finite non-infinity point is generated by the base point.
This fixed toy domain keeps every native intermediate safely inside signed
64-bit arithmetic and makes no security claim.

The `i64_array_bytes_output` input is exactly
`[p,a,b,gx,gy,n,qx,qy,z,r,s]`. The first six values must be exactly
`[17,2,2,5,1,19]`. `Q=(qx,qy)` must be a finite point on the fixed curve;
`z` is the already-converted 5-bit digest integer in `0..31`; `r` and `s`
are in `1..n-1`. The implementation validates the fixed curve/base parameters,
nonsingularity, point equations and subgroup order, then performs modular
inversion, double-and-add scalar multiplication, and the ECDSA verification
equation. A valid signature writes byte `1`; an invalid signature writes byte
`0`. Malformed input returns `-1`; null or short output returns `-2` without
writing. The maximum valid input length is 11 signed 64-bit words and the
maximum parseable frame is 12 words (to reject a trailing value); workspace
is bounded to 512 bytes.

Primary method context: [NIST FIPS 186-5](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.186-5.pdf)
and [NIST SP 800-186](https://csrc.nist.gov/pubs/sp/800/186/final). Only the
algorithmic procedure and validation requirements are used. The toy curve is
independently selected and finite-field counted; no standard test vectors or
source code are reused.
