# Rights and provenance

The profile was specified from the NIST Dictionary of Algorithms and Data
Structures entry for [extendible hashing](https://xlinux.nist.gov/dads/HTML/extendibleHashing.html)
and the cited paper by Fagin, Nievergelt, Pippenger, and Strong, “Extendible
Hashing – A Fast Access Method for Dynamic Files,” ACM TODS 4(3), 315–344
(1979), [DOI 10.1145/320083.320092](https://doi.org/10.1145/320083.320092).

The DADS page and paper are algorithm references. No implementation code,
comments, examples, fixture data, or protected problem statements were copied.
The source paper's publication notice does not identify a software license;
no source-code license is claimed. The ports and fixtures are original
clean-room work implementing the bounded profile in `README.md`.
