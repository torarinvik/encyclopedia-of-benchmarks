# Rights and provenance

This clean-room benchmark is based on the algorithm description in Tim A. C.
Willemse and Maciej Gazda, “Parity Games,” *Encyclopedia of Algorithms*,
Chapter 591, DOI
[10.1007/978-1-4939-2864-4_591](https://doi.org/10.1007/978-1-4939-2864-4_591),
and on the cited constructive recursive method originating with Robert
McNaughton, “Infinite Games Played on Finite Graphs,” DOI
[10.1016/0168-0072(93)90036-D](https://doi.org/10.1016/0168-0072(93)90036-D).

The cited publications remain under their publishers' copyrights. This
repository uses algorithm descriptions only. The ten implementations,
references, workload, and metadata are original to this repository. No source
code, prose, figures, or example data were copied. The bounded input and output
contract, including owner IDs, minimum-priority convention, edge limits, and
partition mask, is defined independently here.
