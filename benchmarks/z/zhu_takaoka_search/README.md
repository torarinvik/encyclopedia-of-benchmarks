# Zhu–Takaoka string search

This bounded first-match profile searches a finite-alphabet text for one
pattern. It uses Boyer–Moore's right-to-left comparison and strong good-suffix
shift, with Zhu–Takaoka's two-dimensional bad-character table indexed by the
last pair of text symbols in each candidate window. The search advances by
the larger of those two shifts.

The input is `[text_length, pattern_length, text_symbols..., pattern_symbols...]`.
Text length is 0–256, pattern length is 2–16, and symbols are in 0–15. The
packed input length must be exact and at most 274. The function returns the
first zero-based match offset, `-1` if absent, and `-2` for invalid input.
Empty text and patterns longer than the text are valid and return `-1`.

For a bounded implementation, the strong good-suffix table is generated by
checking candidate shifts directly; preprocessing is `O(m^3 + σ²)` for the
pattern length `m` and alphabet size `σ`. The Zhu–Takaoka pair table takes
`O(m + σ²)` to build. Search is `O(nm)` in the worst case and uses
`O(m + σ²)` auxiliary storage. This profile returns the first match, so it
stops when the first matching window is found.

`primary_oracle.py` uses the pair-shift and strong-good-suffix tables.
`independent_oracle.py` tests every candidate window directly without either
shift table. `check_inventory.py` checks only package metadata, fixtures, and
source-file presence; it does not launch language ports.

The search variant is distinct from [`berry_ravindran_search`](../berry_ravindran_search/README.md): Berry–Ravindran looks at a two-symbol pair after the current window, while Zhu–Takaoka selects a pair bad-character shift from the final two symbols within the current window.
