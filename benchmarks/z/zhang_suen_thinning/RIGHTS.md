# Rights and provenance

The algorithm name and high-level two-subiteration description were discovered
through RosettaGit's [Zhang-Suen thinning algorithm task](https://rosettagit.org/tasks/zhang-suen-thinning-algorithm/),
whose site identifies task content as GFDL-1.3-or-later. The task is cited as
algorithm provenance only. No task prose, examples, expected outputs, or
community code were copied. This package's contract, source files, references,
fixtures, and documentation were authored independently from the standard
algorithm description.

The primary algorithm is the Zhang-Suen two-subiteration thinning method. The
independent reference uses row tuples and phase-by-phase rebuilt grids. The
RosettaGit page is not a code license for these new implementations.
