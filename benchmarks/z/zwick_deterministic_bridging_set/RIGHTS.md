# Rights and provenance

The algorithmic source is Uri Zwick, “All Pairs Shortest Paths using Bridging
Sets and Rectangular Matrix Multiplication,” Section 6, Figures 10–11 and
Lemma 6.6, *Journal of the ACM* 49(3), 289–317 (2002),
[DOI 10.1145/567112.567114](https://doi.org/10.1145/567112.567114). Chapter
context is *Encyclopedia of Algorithms*, Chapter 12,
[DOI 10.1007/978-1-4939-2864-4_12](https://doi.org/10.1007/978-1-4939-2864-4_12).

Only the mathematical algorithm and bibliographic facts are used. This
package contains independently written bounded references and ports; it does
not reproduce paper code, protected prose, figures, examples, or tests. The
lowest-ID tie rule is a documented deterministic refinement of the source's
greedy hitting-set step.
