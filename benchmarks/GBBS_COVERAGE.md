# GBBS benchmark coverage

This crosswalk reviews the benchmark source tree of [ParAlg/gbbs](https://github.com/ParAlg/gbbs)
at commit [`dbd1dcad582c0a316c5ba0d5524319d596dd82da`](https://github.com/ParAlg/gbbs/tree/dbd1dcad582c0a316c5ba0d5524319d596dd82da), dated 2026-10-11. The repository license is MIT. Rows cover every top-level source family under `benchmarks/`; dispositions compare algorithm cores and observable operations, not filenames alone. This is a static source and package inventory, not a runtime correctness claim.

The GBBS README also advertises Graph HAC, but the pinned `benchmarks/` tree has no `GraphHAC` implementation directory, so it is recorded as a README-only item rather than a source kernel.

## Remaining source inventory dispositions

Every distinct source-backed kernel in the pinned `benchmarks/` tree now maps
to a local package. README-advertised Graph HAC and k-Truss have no corresponding
source directories at this commit. Yoshida maximal matching maps to the
existing recursive MIS-query kernel over a line graph, and wBFS maps to the
existing Dial/Dijkstra family; neither is added as a duplicate package.
