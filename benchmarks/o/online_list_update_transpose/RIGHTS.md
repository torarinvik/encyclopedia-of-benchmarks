# Rights and provenance

This package is an independently written bounded implementation of the
Transpose (`Trans`) online list-update policy described in Shahin Kamali,
“Online List Update,” *Encyclopedia of Algorithms*, DOI
10.1007/978-1-4939-2864-4_266. The chapter is used for algorithm attribution,
not as a source-code license. No book prose, figures, or code were copied.
These clean-room implementations are subject to the repository terms.
