# Rights and provenance

This package uses the algorithm descriptions in Zhang and Shasha's 1989
ordered tree-edit-distance paper and Tai's 1979 tree-correction paper. The
papers are cited in [README.md](README.md); their text, source code, examples,
figures, and test data are not reproduced here. The ten language ports,
references, workload, and documentation are independently written.

The cited publications are copyrighted by their publishers/authors. Citation
does not grant rights to redistribute their material. This note records
algorithm provenance; it is not a license grant for the publications.
