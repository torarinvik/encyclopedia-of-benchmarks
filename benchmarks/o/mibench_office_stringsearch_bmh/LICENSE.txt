MiBench `office-stringsearch` case-sensitive Boyer-Moore-Horspool stage

The pinned `bmhsrch.c` source states:

  Case-sensitive Boyer-Moore-Horspool pattern match
  public domain by Raymond Gardner 7/92

This package ports the `bmh_init` and `bmh_search` behavior from that source.
The pinned source comment also records a 32767-byte combined pattern/text
limit; this bounded package uses smaller explicit limits. Raymond Gardner's
attribution is retained here and in the package README and port comments.
