# Rights and provenance

The profile is based on the algorithm description in Maurizio Patrignani,
“Bend Minimization for Orthogonal Drawings of Plane Graphs,”
*Encyclopedia of Algorithms*, Chapter 651,
[DOI 10.1007/978-1-4939-2864-4_651](https://doi.org/10.1007/978-1-4939-2864-4_651).
The chapter describes the minimum-cost integral-flow model and its relation
to the number of bends. This package uses that mathematical idea only.

All ten ports, bounded input contract, workload fixtures, and Python
references are clean-room work. No book code, third-party implementation,
challenge text, or copied fixture set is included. This file records source
provenance; it does not assert a license for the book's prose or figures.
