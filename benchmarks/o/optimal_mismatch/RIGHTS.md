# Rights and provenance

This clean-room benchmark is based on Sunday’s Optimal Mismatch description in
[NIST DADS](https://xlinux.nist.gov/dads/HTML/optimalMismatch.html) and the
[Charras–Lecroq exact string matching reference](https://www-igm.univ-mlv.fr/~lecroq/string/node28.html).
Those sources are used for the algorithm description only. No source code,
example text, or examples are copied.

The profile uses a bounded ASCII byte alphabet and returns the earliest exact
match. All benchmark implementations and fixtures in this package are original
clean-room work; no external implementation license is reused.
