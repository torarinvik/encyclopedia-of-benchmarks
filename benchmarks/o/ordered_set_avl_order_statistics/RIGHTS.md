# Rights and provenance

This package is a clean-room implementation of a bounded dynamic ordered-set
operation profile. The official Library Checker task is used for its operation
definitions and input semantics only. No upstream source code, examples, test
cases, generated data, or prose has been copied.

The Library Checker repository identifies its contents as Apache-2.0. The
local AVL balancing, subtree-size augmentation, workload, oracle modules, and
language ports were authored independently. The implementation method is
chosen for this benchmark profile and is not claimed to be the official
problem's required solution.
