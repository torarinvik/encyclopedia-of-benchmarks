# Encyclopedia of Algorithms chapter dispositions: T–Z

Static source audit of the T–Z chapters in the supplied *Encyclopedia of Algorithms* EPUB. DOI suffixes follow each chapter's DOI `10.1007/978-1-4939-2864-4_<suffix>`. Package links identify local clean-room profiles; the root task owns shared suite and catalog integration.

| Chapter | DOI suffix | Disposition |
|---|---:|---|
| Table Compression | 418 | Package: [table_compression_optimal_contiguous_partition](t/table_compression_optimal_contiguous_partition/README.md) implements the chapter's contiguous-column partition dynamic program with an explicit byte-pair RLE cost model. It is the exact optimum under that selected compressor, not a claim about gzip/LZ/BWT costs. Local symbol-stream compressors do not optimize the table partition, and [columnar_transposition](c/columnar_transposition/README.md) is a separate column permutation. |
| Tail Bounds for Occupancy Problems | 419 | Not a benchmark kernel: the entry proves probabilistic bounds, not a deterministic input/output algorithm. |
| Technology Mapping | 420 | Package: [technology_mapping_minimum_area_tree_cover](t/technology_mapping_minimum_area_tree_cover/README.md) implements the chapter's exact minimum-area tree-cover DP over a bounded ordered tree and five fixed INV/NAND2 patterns. This is a source-defined tree-only profile; it does not claim DAGON's DAG partitioning heuristic, Boolean matching, or delay/power objectives. |
| Teleportation of Quantum States | 421 | Not a classical benchmark kernel: the operation is a quantum communication protocol. |
| Temperature Programming in Self-Assembly | 670 | Not a standalone bounded kernel: the entry studies tile-system construction and assembly behavior, including physical model assumptions. |
| Testing Bipartiteness in the Dense-Graph Model | 702 | Package: [dense_graph_bipartiteness_tester](d/dense_graph_bipartiteness_tester/README.md) now includes the source's outer procedure: partial Fisher–Yates selection from supplied uniform-range draws, all induced-pair adjacency queries over full-graph row masks, then BFS recognition. It reports both the verdict and query count. This is distinct from exact whole-graph [is_graph_bipartite](i/is_graph_bipartite/README.md); the fixed sample size has no epsilon-to-query guarantee. |
| Testing Bipartiteness of Graphs in Sublinear Time | 701 | Package: [sublinear_bipartiteness_walk_tester](s/sublinear_bipartiteness_walk_tester/README.md) preserves the bounded-degree lazy incidence-walk parity-collision test with supplied starts and transition draws. It differs from both exact full-graph recognition and the dense-model induced-sample tester; the chapter's probability/query-complexity guarantee remains outside this fixed-trace profile. |
| Testing if an Array Is Sorted | 700 | Covered by [check_if_array_is_sorted_and_rotated](c/check_if_array_is_sorted_and_rotated/README.md) only for the related rotated-sorted predicate; ordinary sortedness also exists as [is_sorted](i/is_sorted/README.md). The chapter's linear scan is an exact behavior overlap. |
| Testing Juntas and Related Properties of Boolean Functions | 709 | **Not ported.** The chapter surveys several oracle testers (dictator/1-junta, k-junta, and tests by implicit learning) but gives query bounds and proof sketches rather than a complete query-generation procedure. The k-junta theorem depends on randomized dimension reduction and a specific query tester whose details are delegated to cited papers; the function oracle and epsilon-distance promise are also part of the model. A fixed query transcript would only replay one arbitrary execution and cannot represent the stated soundness guarantee, so no chapter-faithful bounded kernel is packageable from this chapter alone. |
| Text Indexing | 422 | **Partial:** [suffix_array_lcp_search](s/suffix_array_lcp_search/README.md) covers only the chapter's detailed Manber–Myers LCP-enhanced exact lower/upper searches over a suffix array (`n<=32`, pattern length `<=16`), with bounded suffix-array/LCP preprocessing. The chapter is a broader survey of ordered-key dictionaries, dynamic/self-adjusting indexes, suffix trees/arrays, and approximate matching; those other approaches are not claimed as covered, and no unpinned cited-paper algorithms are included. The local [suffix_array](s/suffix_array/README.md) only constructs suffix order and does not implement this endpoint-LCP recurrence. |
| Three-Dimensional Graph Drawing | 656 | Package: [three_dimensional_moment_curve](g/three_dimensional_moment_curve/README.md) implements the chapter's explicit non-crossing construction, placing vertex i at (i,i²,i³). It is a source-defined drawing profile, not volume optimization. |
| Thresholds of Random k-SAT | 423 | Not a benchmark kernel: this is an asymptotic threshold/phase-transition analysis. |
| Topology Approach in Distributed Computing | 424 | Not a standalone kernel: the chapter is a mathematical framework for impossibility and solvability proofs in distributed systems. |
| Trade-Offs for Dynamic Graph Problems | 425 | Survey/theory entry; it compares dynamic graph data structures rather than defining one bounded operation. |
| Transactional Memory | 607 | Not a portable sequential kernel: transactional semantics depend on concurrency and a memory model. |
| Traveling Sales Person with Few Inner Points | 426 | Package: [tsp_few_inner_points](t/tsp_few_inner_points/README.md) implements the first fixed-parameter algorithm (enumerate inner-point orders, then use the source's two-endpoint DP) with supplied convex-hull order and integer-rounded thousandth Euclidean edge costs. Because rounding can perturb the global optimum, the profile reports the optimum within the hull-order-preserving family rather than claiming the exact unrounded Euclidean optimum. It is distinct from unrestricted Held–Karp and metric-TSP tree doubling; convex-hull construction is outside the profile. |
| Tree Enumeration | 726 | Covered by [parentheses_generator](p/parentheses_generator/README.md): an ordered rooted tree with `n` vertices corresponds to one Dyck word with `n−1` pairs, exactly the family emitted by the canonical open-first recursion (including the one-vertex empty word). Its byte serialization differs from the tree-package encoding, but the enumeration algorithm and family are identical. This does not overlap Prüfer code for labeled unrooted trees. |
| Treewidth of Graphs | 431 | Packages: [treewidth_exact_elimination_order](t/treewidth_exact_elimination_order/README.md) enumerates all elimination schemes and returns the exact minimum width for n≤8; it is not the cited Fomin–Villanger implementation. [treewidth_min_degree_elimination](t/treewidth_min_degree_elimination/README.md) and [treewidth_min_fill_elimination](t/treewidth_min_fill_elimination/README.md) separately preserve the chapter's greedy heuristics and report upper bounds. |
| Trial and Error Algorithms | 789 | Not one benchmark kernel: the chapter presents a general algorithm-design paradigm rather than one concrete operation. |
| Triangulation Data Structures | 589 | Not a standalone kernel: the entry describes representations and navigation operations for triangulations, without a single selected workload operation. |
| Truthful Mechanisms for One-Parameter Agents | 436 | Not a single benchmark kernel: truthfulness is an economic constraint across a family of allocation and payment rules. |
| Truthful Multicast | 437 | **Not ported.** The chapter names Algorithms 1 and 2, but their procedure depends on the chapter's LCPT/PMST construction and payment expressions; the payment equations are embedded as image-only math and the cited subroutines are not fully specified in the chapter text. Without those rules, ties and payments cannot be reproduced exactly from a bounded graph/workload contract. This is a source-detail gap, not a claim that truthful multicast lacks algorithms. |
| TSP-Based Curve Reconstruction | 440 | **Not ported.** The chapter's concrete method solves a fixed-endpoint TSP subtour-LP using min-cut separation (or the ellipsoid method), then relies on a sampling condition for an unknown benign curve to guarantee a unique integral reconstruction. A small Hamiltonian-path enumeration would collapse to the already represented TSP core and would not reproduce the chapter's LP/separation method; a faithful LP profile would need exact rational optimization and the geometric sampling predicate, neither of which is specified as a bounded suite input. |
| Two-Dimensional Scaled Pattern Matching | 444 | Covered by [two_dimensional_scaled_pattern_matching](t/two_dimensional_scaled_pattern_matching/README.md), a fixed supplied-rational-scale profile that uses the chapter's geometric pixel-center mapping and reports all placements; it does not search continuously over every real scale. |
| Two-Interval Pattern Problems | 445 | Covered by [two_interval_precedence_chain](t/two_interval_precedence_chain/README.md), an exact maximum-cardinality chain profile for the chapter's precedence-only 2-interval model; nesting/crossing variants are outside this package. |
| Undirected Feedback Vertex Set | 450 | Covered by [undirected_feedback_vertex_set](u/undirected_feedback_vertex_set/README.md), a bounded iterative-compression profile over vertex prefixes, with partitioned candidate `X/Y` and exhaustive bounded `S` compression checks; distinct from local vertex-cover and cycle-detection operations. |
| Unified View of Graph Searching and LDFS-Based Certifying Algorithms | 685 | Covered by [ldfs_ordering_certificate](l/ldfs_ordering_certificate/README.md), which computes a bounded deterministic LDFS ordering and emits witnesses for the chapter's four-vertex characterization; its separate cocomparability minimum-path-cover application is outside this profile. |
| Uniform Covering of Rings and Lines by Memoryless Mobile Sensors | 594 | Package: [ring_exact_covering_protocol](r/ring_exact_covering_protocol/README.md) profiles `RingCoveringExact` with common orientation, known unit target gap, visibility 2, an integer ring of circumference n, and a supplied serial activation trace. The activation trace is one bounded asynchronous execution; fairness/convergence over arbitrary schedules is not claimed. |
| Unique k-SAT and General k-SAT | 680 | Package: [ppsz_k_sat_trace](p/ppsz_k_sat_trace/README.md) executes a bounded 3-CNF PPSZ trace with supplied permutation and guess bits. Its t-implied closure uses exhaustive checks for t=floor(log₂ n) clauses and fixed deterministic tie-breaking; this fixed trace does not claim the randomized success probability or running-time bound. |
| Universal Sequencing on an Unreliable Machine | 543 | Package: [universal_sequencing_doubling](t/universal_sequencing_doubling/README.md) implements the chapter's deterministic backward doubling sequence through exact 0/1 knapsack subproblems. Its bounded integer profile requires total weight to be a power of two (≤32), so the displayed `floor(log W)` top level covers all jobs; it does not simulate machine failures or evaluate realized schedules. |
| Upward Graph Drawing | 653 | Related core covered by local [bipartite_matching_hopcroft_karp](b/bipartite_matching_hopcroft_karp/README.md) and [dinic_maxflow](d/dinic_maxflow/README.md): the chapter's upward-planarity angle assignment reduces to a bipartite capacity-flow feasibility problem. The complete embedding-to-angle-constraints pipeline is not a single bounded profile here, so no duplicate matching package is added. |
| Utilitarian Mechanism Design for Single-Minded Agents | 454 | Not a single benchmark kernel: the entry studies allocation mechanisms under valuation and incentive assumptions. |

| Visualization Techniques for Algorithm Engineering | 464 | Not a benchmark kernel: this is a visualization and experimental-methods overview. |
| Voltage Scheduling | 466 | **Not ported.** The chapter's target is Li–Yao's continuous-time, finite-speed MEDDVS algorithm: it partitions jobs through forward/reverse EDF schedules, tight-boundary gap expansion, and then interval-commits a two-speed schedule for each level. The current partial implementation instead exhaustively enumerated integer time slots and therefore does not implement that algorithm. A faithful profile needs exact rational interval operations and their degeneracy/tie rules across every port; the source chapter and cited paper's compact pseudocode do not provide a complete bounded schedule contract for this suite. The partial slot-profile ports were removed rather than presented as coverage. |
